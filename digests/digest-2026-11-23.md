## 📄 Research Papers — Top Picks
- **Epistemic Guard: Out-of-Process MCP Receipt Proxying, Post-Turn Prose Supervision, and Provenance-Gated Memory for Tool-Using Autonomous Agents** — Sean Maxwell · https://arxiv.org/abs/2611.27095
  MCP receipt proxy: stops agents from narrating tool side effects that never happened. Epistemic Guard is an open-source Python library and out-of-process stdio MCP proxy. It signs tool receipts with Ed25519 keys held outside the agent, logs them in RFC 6962 Merkle logs, and gates what enters durable memory. It targets action fabrication, provenance collapse and syndicated echo amplification without needing GPU-based LLM judges. **Why it matters:** Gives MCP agents a cheap, verifiable record of what tools actually did.
- **SkillPrivus: Uncovering PRIVacy of USe Harms in Agentic Skills** — Mariana Fernandez-Espinosa, Ivoline Ngong, Keerthiram Murugesan, Karth… · https://arxiv.org/abs/2611.26747
  SkillPrivus audits agent skills for privacy harms before install. A static audit framework that extracts data operations from skill code and instructions and applies Contextual Integrity. On 726 real marketplace skills (563 handling personal data) it flags at least one potential violation in 307 (54.5%), agreeing with three blind human annotators. **Why it matters:** Over half of audited skills carry privacy risk, so vetting skills before install matters.
- **SkillForgeBench: Evaluating Agent Reliability Grounded in Agent Skill Specifications** — Zhengxi Li, Junyi Zhou, Qiyuan Zhang, Chuhan Wu, Fuyuan Lyu, Le Tian, … · https://arxiv.org/abs/2610.14918
  SkillForgeBench: benchmark built from agent skill specs. Uses agent skills as execution blueprints across resource preparation, skill-driven task synthesis and evaluation. This aims to combine the domain breadth of crowdsourced benchmarks with the procedural rigor of expert-curated ones. **Why it matters:** Measures whether agents strictly follow procedurally complex skill requirements.
- **Declarative Skills for AI Agents in Knowledge-Grounded Tool-Use Workflows** — M. Danish Lim, I. Danial Bin Sharudin, Wen Han Chen, Cedric Lim, Laura… · https://arxiv.org/abs/2606.06923
  Declarative skill files vs state-machine orchestration for tool-using agents. Compares a declarative agent reading natural-language skill files, an imperative state-machine agent and an unscaffolded baseline in customer-service workflows across five models and two retrieval regimes. Averaged over conditions, orchestration does not improve task success; skill files are neutral-to-negative with perfect retrieval and neutral-to-positive with embedding retrieval. **Why it matters:** Skill files help depending on retrieval quality, not universally.
- **HookEvo: A Framework for Coordinated Plugin Evolution on Hook-Enabled Agent Runtimes** — Shengze Huang, Yanyu Mao, Xiaofei Yu, Baoshen Guo, Xiaorui Wang, Zhiwe… · https://arxiv.org/abs/2611.27294
  HookEvo evolves agent harness plugins via lifecycle hooks. A separate improver diagnoses failures from execution traces and proposes candidate harness edits (plugin handlers plus shared state) on a hook-enabled runtime. Candidates are tested against the current harness on matched tasks. With a frozen Qwen3-4B executor it reaches 95.41% on ALFWorld. **Why it matters:** Shows harness-level self-repair can lift small models without retraining.
- **Actions Speak Louder than Words: Stateful Privacy Sniffing of LLM Agents via Behavioral Covert Channels in Web Interactions** — Ruichao Liang, Wenzhong Deng, Jing Chen, Yuqing Li, Kaixuan Li, Cong W… · https://arxiv.org/abs/2611.27046
  Agents leak private context through which web pages they choose to visit. Describes a stateful attack where an adversary actively recovers fine-grained private context from an agent's benign browsing decisions, with no explicit transmission of sensitive content, bypassing content-level defenses. **Why it matters:** Content filters alone do not stop behavioral side channels in web agents.
- **Learning When to Ask: Advisor-Aware Post-Training for SLM Agents** — Aasheesh Singh, Vishal Vaddina · https://arxiv.org/abs/2611.27443
  ADAPT teaches small-model agents when to ask a stronger advisor. An advisor-executor post-training recipe learned from the policy's own rollouts with outcome supervision. Naive wiring of an SLM to an advisor fails out of the box; ADAPT teaches cost-aware advice-seeking and following advice across steps. **Why it matters:** Cheap SLM agents can cut cost while borrowing strong-model reasoning.
- **AgentArk: Distilling Multi-Agent Intelligence into a Single LLM Agent** — Yinyi Luo, Yiqiao Jin, Weichen Yu, Mengqi Zhang, Srijan Kumar, Xiaoxia… · https://arxiv.org/abs/2602.03955
  AgentArk distills multi-agent debate into a single LLM agent. Moves multi-agent interaction cost from inference to training via reasoning-enhanced fine-tuning, trajectory-based augmentation and process-aware distillation, across models, tasks and scales. **Why it matters:** Multi-agent-level reasoning at single-agent inference cost.
- **Task-Specific Agent Memory For Continual Learning** — Yezhou Cheng, Runjia Du, Zeming Liu, Qibai Chen, Hang Lyu, Yankai Zeng… · https://arxiv.org/abs/2609.29144
  Task-specific agent memory avoids cross-task interference in continual learning. Skills proposed by the agent are checked with execution tests, stored by task family and retrieved only for that family. On a 12-round code-repair benchmark this raises average performance from 0.713 to 0.816 with proposals and acceptance held fixed. **Why it matters:** A simple memory-partitioning rule improves agent self-improvement.
- **AhaBench: Do Agents Turn Experience into Reusable Insights? A Long-Horizon Benchmark for Continual Learning** — Zerui Cheng, Jiawei Xu, Huacan Chai, Jiayang Sun, Pramod Viswanath, Ma… · https://arxiv.org/abs/2609.05435
  AhaBench tests whether agents turn experience into reusable insight. Simulates three long human-AI collaboration patterns (puzzle, Euler computation, a year of vending business) while holding the later test fixed and varying prior experience. The learning mechanism is open: memories, skill libraries or weight updates. **Why it matters:** Targets the gap between a one-shot tool and a collaborator that improves.
- **Search-RSI: Expanding Search Worlds Along Multimodal Agents' Capability Frontier** — Chengchao Lv, Yin Wang, Chunzheng Zhu, Wanli Chang · https://arxiv.org/abs/2611.27780
  Search-RSI expands the searchable world for multimodal search agents. Training recipes treat the retrieval backend as fixed, so unreachable evidence penalizes the policy unfairly. Search-RSI has the policy diagnose partially mastered regions of the task space and expands the search world along that frontier each round. **Why it matters:** Removes false negatives when training search agents.
- **Can Vision-Language Models Synthesize Executable Game-Playing Programs?** — Yao Tong, Jiaxin Qi, Dingyu Zhang, Jianqiang Huang · https://arxiv.org/abs/2611.27741
  PlayScriptBench: can VLMs write executable game-playing programs? Instead of step-by-step VLM calls, the benchmark asks a VLM to synthesize a script that plays the game, avoiding per-step inference latency and cost. **Why it matters:** Script synthesis is a cheaper deployment path for visual agents.
- **Right On Q: Recovering Reasoning under Quantization via Self-Generated Trajectories** — Boyuan Zheng, Jing Xiong, Chenwei Wu, Hui Shen, Zesen Zhao, Hei Ting U… · https://arxiv.org/abs/2610.29378
  Right On Q: recovering reasoning in quantized LLMs with self-generated trajectories. Argues fixed-response QAT supervision causes trajectory divergence and distribution misalignment in low-bit students, so they fail to terminate within the token budget. Trains on the student's own trajectories to close the gap. **Why it matters:** Makes low-bit reasoning models more practical.
- **Self-Distilled Reasoner: On-Policy Self-Distillation for Large Language Models** — Siyan Zhao, Zhihui Xie, Mengchen Liu, Jing Huang, Guan Pang, Feiyu Che… · https://arxiv.org/abs/2601.18734
  On-Policy Self-Distillation: one LLM as both teacher and student. OPSD lets a single model act as teacher (conditioned on ground-truth reasoning traces) and student, giving dense token-level supervision without a separate larger teacher. **Why it matters:** Cheaper on-policy distillation for reasoning.
- **TrojanMaxxing: One-shotting VLM Backdoors with Weight-Space Programming** — Ahaan Dabholkar, Harshvardhan Patel, Michalis Polychronakis, Saurabh B… · https://arxiv.org/abs/2611.27425
  TrojanMaxxing: LLM agents backdoor VLMs by editing weights directly. Reframes backdoor insertion as weight-space programming: agents inspect VLM weights, apply targeted edits and co-design an imperceptible visual trigger, with no training or optimization. **Why it matters:** Agentic weight editing is a new supply-chain threat for open models.
