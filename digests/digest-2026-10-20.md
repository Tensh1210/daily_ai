## 📄 Research Papers — Top Picks
- **ToolOPD: Credit-Aware On-Policy Distillation for Tool-Use Agents** — Chu Zhao et al. · https://arxiv.org/abs/2610.25693
  Shows that in long-horizon tool-use trajectories, credit concentrates on a few critical actions, so standard on-policy distillation's uniform supervision is miscalibrated. ToolOPD summarizes each finished trajectory into a hindsight skill, measures how that skill shifts the teacher's probability of each student action, and uses this as outcome-aware credit to reweight the distillation loss jointly with RL. **Why it matters:** A cleaner recipe for distilling strong tool-using teachers into small agent models.
- **OpenVLHarness: Real World Visual Agentic Tool-Use with Multimodal Memory** — Yu Zhou et al. · https://huggingface.co/papers/2610.26860
  A multimodal agent harness with a capability layer (task-level tool interfaces + evidence rendering), persistent multimodal memory of images/data/web refs, and a coding interface for computing over stored artifacts. Across 22 benchmarks and eight backbones it adds 9.7–12.6 points over matched no-tool baselines, while simply raising inference budget gave only modest gains. **Why it matters:** Evidence that harness design, not more thinking tokens, is the lever for grounded visual reasoning.
- **Standing on the Shoulders of Giants: Enhancing LLM Agents for Automated Fact-Checking with Human Expert Skills** — Xinwen Chen et al. · https://arxiv.org/abs/2610.25777
  Distills AFP Fact Check's public guidelines into a modular Professional Fact-Checking Skill and builds SkillCheck, which loads it at inference time for evidence retrieval and verification. On AVeriTeC it gains 2.2–4.8 pp accuracy over skill-free baselines; GPT-4o-Mini with the skill beats GPT-4o without it at ~61% lower cost. **Why it matters:** Concrete proof that packaging human expert procedure as an agent skill can substitute for a bigger model.
- **CodeSkill: Latent Skill Abstraction for Long-Horizon Code Agents** — Song-Li Wu et al. · https://arxiv.org/abs/2609.33243
  A teacher distills successful and failed code-agent trajectories into multi-level textual abstractions, which temporal variational inference + RL map into continuous latent skills. These are injected into a frozen LLM policy as latent prefixes, with an adaptive boundary gating skill transitions on execution feedback. **Why it matters:** Moves code-agent RL from token-level exploration to experience-level reasoning, easing sparse-reward credit assignment.
- **COPEX: Benchmarking LLM Robustness to Adversarial Context Across Model Context Protocol (MCP) Layers** — Nahom Birhan et al. · https://arxiv.org/abs/2610.04378
  Isolates the model as an MCP client by fixing the agent stack and varying only the tool-selecting model, across 25 attack types / 125 scenarios on four surfaces (model, client, server/tool, transport). Over nine models and 3,375 trials the mean attack success rate is 64.4%; combined input + context scanning cuts it by 49.6% on a defense subset. **Why it matters:** A controlled, open benchmark for MCP security that separates model susceptibility from system exposure.
- **Toward Agentic Retrieval-Augmented Generation for Enterprise Retail Workflows over Heterogeneous Data Sources** — Jeonghwan Choi et al. · https://arxiv.org/abs/2610.25096
  Introduces RetailBridge, a compositional benchmark requiring agents to chain evidence across structured order/product records and unstructured reviews, plus RetailRAG with auto-schema briefing, source-routed plan chaining and diagnostic plan revision. Across ten backbones, multi-source chaining is the dominant bottleneck regardless of provider or scale. **Why it matters:** Reliable enterprise agents need explicit cross-source orchestration, not just bigger models.
- **ATTUNER: Recomputation-Free Agentic Context KV Reuse** — Xinghao Chen et al. · https://arxiv.org/abs/2609.36722
  Finds the quality loss of position-independent KV caching for reusable agent artifacts (skills, docs, memory) lies in attention when selecting among artifacts, not in positional mismatch. ATTUNER adds query-side LoRA (<0.05% of params) distilled from full-prefill attention, so cached KV is reused unchanged with no recomputation. **Why it matters:** Cheap path to caching skill/memory blocks across agent requests without accuracy loss.
- **Toollery: Scaling LLM Agents to Thousands of Skills and Tools** — Xiangxi Tian, Ran Guan · https://arxiv.org/abs/2609.22218
  Training-free candidate compression: generates user-intent queries from each skill/tool spec and indexes them, so real requests map to a compact top-K set before the LLM decides. Evaluated on the ~79K-capability SkillRouter benchmark, BFCL-V4 and a 220-tool cockpit dataset, it improves recall over plain spec retrieval and holds BFCL AST accuracy. **Why it matters:** Practical drop-in for agents whose tool/skill libraries outgrow the context window.
- **Selm: Self-Evolving Library Management for Multi-Skill Agent Optimization** — Mengxi Hu et al. · https://arxiv.org/abs/2610.24630
  Treats skill evolution as library management: tracks confidence and utility per skill, uses utility-aware retrieval, Map-Reduce-generated targeted updates, and lifecycle controls to retain or prune skills. Outperforms baselines in most settings on four agent benchmarks. **Why it matters:** Addresses skill-library rot as agents accumulate self-generated skills across domains.
- **Are Self-Evolving Agents Continual Learners?** — Xiaoyin Chen et al. · https://arxiv.org/abs/2610.25858
  Tests ReasoningBank, GEPA and Meta-Harness on four drifting task streams (BIRD, BFCL, ScienceWorld). Self-evolution helps aggregate performance, but self-modifying methods overwrite earlier knowledge with global edits, and memory retrieval suffers collisions when similar queries need conflicting workflows. **Why it matters:** A sober check on "agents that rewrite their own harness": plasticity still trades off against stability.
- **Editing as Language: Teaching LLM Agents a Grammar for Native Context Editing** — Yunlong Deng et al. · https://arxiv.org/abs/2610.25550
  Encodes context-editing operations as special tokens so agents edit their own context natively during generation, trained on iteratively built trajectory segments. On Terminal-Bench 2.0 and three SWE-bench variants it lifts success by 4.5–5.6 pp while cutting token use 15–36%. **Why it matters:** Context management as a learned model capability rather than an external harness tool.
- **AURA-Eval: Evaluation Framework for Acting Under Risk Awareness in LLM Agent Trajectories** — Ruoxi Shang et al. · https://arxiv.org/abs/2609.06783
  Truncates tool-use trajectories at safety-critical points and varies six risk mechanisms (harm, scale, reversibility, oversight, etc.), with paired scenarios that do or don't offer a safe path. Across 20 models, frontier unsafe-action rates jump from 5–7% to 27–40% when no safe fulfillment path exists. **Why it matters:** Shows agents' main failure is acting unsafely when cornered, not failing to notice risk.
- **Doing Less with More: A First-Principles Exploration of the Suitability of Agentic Computing over Alternative Architectural Choices** — Ritvik Garimella et al. · https://arxiv.org/abs/2610.23921
  Compares native function calls, REST, SOAP, MCP microservices, direct LLM answers and MCP-tool agents on 1,000 arithmetic expressions. Deterministic methods hit 100% with negligible latency; the best MCP agent reaches 99.9% but at ~1,000,000× baseline latency. **Why it matters:** A useful reality check and decision framework for when not to reach for an agent.
- **MobilePA-Bench: Benchmarking Mobile Planner Agents on Complex Real-World Tasks** — Yi Zhu et al. · https://arxiv.org/abs/2608.23035
  1,705 tasks over 212 mobile tools in a stateful sandbox, profiling tool use, memory, skill usage and sub-agent collaboration with per-task evidence-aligned checkers and capability-gated scoring. Separates retrieval/procedural-compliance failures from execution errors; an RL-trained Qwen baseline shows the environment is trainable. **Why it matters:** Grades whether agents follow prescribed procedure, not just whether the task ended "done".
- **Where Natural Language Ends in Agents: Executable Skill Composition with MetaSkill** — Meng Shu et al. · https://arxiv.org/abs/2610.24723
  Keeps Agent Skill packages in natural language but formalizes the boundaries between them (invocation order and output handoffs) as an executable DAG runtime. On 20 multi-skill artifact tasks, blinded judgments favor MetaSkill over NL procedures, prompt-visible graphs and AgentSkillOS, with all planned nodes and precedence constraints satisfied. **Why it matters:** A pragmatic middle ground for composing many skills reliably without over-specifying them.
