## 📄 Research Papers — Top Picks
- **MedClaw: Heuristic Agent Harness for Long-Horizon Surgical Video Reasoning** — Fan, Du, Zhu et al. · https://arxiv.org/abs/2608.14015
  Tens-of-minutes surgical video breaks one-shot VLMs, which compress the procedure and lose the detail "before/after" questions depend on. MedClaw splits reasoning from perception: a text-only orchestrator plans which evidence to gather and emits an auditable sequence of tool calls, while frozen vision-language sub-agents execute each call over pixels. Improvement comes from evolving context rather than optimizing weights, so no training data is needed. **Why it matters:** A training-free harness pattern — planner + frozen perception tools + auditable trace — that generalizes past surgery to any long-video reasoning task.
- **AtomBridge: Agentic VLA Inference Plugin for Long-Horizon Tasks in Scientific Experiments** — Pang, Zhou, Li et al. · https://arxiv.org/abs/2602.09430
  VLA policies handle atomic robot skills but fail when those skills are reordered into composed long-horizon lab procedures, because the terminal state of one skill falls outside the valid initial-state distribution of the next. AtomBridge attaches at inference time to an already fine-tuned VLA and bridges that skill-chaining gap without retraining. Target domain is autonomous robotic laboratories running continuous experiments. **Why it matters:** Inference-time patching beats retraining for composition failures — the same fix pattern applies to any skill-chained agent.
- **Adaptive Stopping for Multi-Turn LLM Reasoning** — Zhou, Nguyen, Yu et al. · https://arxiv.org/abs/2604.01413
  Adaptive RAG and ReAct-style agents iterate until a heuristic or a fixed turn budget says stop, with no guarantee the answer is still covered. The authors apply conformal prediction to multi-turn reasoning to get formal coverage guarantees on when to halt, extending LLM-CP methods beyond the single-model single-call setting. Framed around high-stakes finance and healthcare, where extra turns cost money and early stops cost correctness. **Why it matters:** Turn budgets are the dominant agent cost knob; this replaces guesswork with a statistical stopping rule.
- **Demystifying Agent Skills: Why They Work — Until They Don't** — Jiang, Huang, Xing et al. · https://arxiv.org/abs/2608.14036
  Skills (structured knowledge packages injected at inference) are usually evaluated only by aggregate task success. This work isolates the actual causal factors — representation, outcome annotation, retrieval difficulty, cross-framework robustness — across multiple benchmarks, harnesses, and LLMs. It normalizes 8,135 trial records and 238 labels from paired trajectory analysis to identify concrete failure modes. **Why it matters:** First systematic account of when skill packages help versus silently degrade agent behavior — directly relevant to anyone shipping skill libraries.
- **P2Skill: Privacy Preserving Skill Distillation for Cloud-Local LLM Inference Systems** — Ryu, Park, Lee et al. · https://arxiv.org/abs/2608.14094
  Hybrid cloud-local setups must strip PII before requests leave the device, but masking and perturbation distort semantics and fine-tuning needs training. P2Skill has a local small model perform decomposition, PII-aware routing, paraphrasing, and reconstruction purely by following skill prompts. The cloud LLM iteratively refines those skills from execution failures, letting the local model generalize past memorized PII patterns. **Why it matters:** Prompt-level skill distillation as a training-free privacy boundary between on-device and cloud inference.
- **MobileMem: Learning from a Year of Mobile Experiences** — Deng, Xue, Ru et al. · https://arxiv.org/abs/2608.13606
  Persistent personal assistants need long-term memory over heterogeneous, multimodal, evolving user data, which current benchmarks do not capture. MobileMem builds a benchmark and framework from a year-scale collection of real mobile experiences, using knowledge-grounded synthesis to produce temporally consistent long-horizon trajectories from user-app sessions. It covers both text and multimodal settings. **Why it matters:** Gives on-device agent memory a realistic year-scale evaluation target instead of synthetic short dialogs.
- **ARC: Fair Relative Advantage Comparison in Open-Ended Real-World Interaction** — Tong, Faith, Marcus et al. · https://arxiv.org/abs/2608.13622
  In open-ended interaction an agent may answer, clarify, report progress, or confirm — all valid, which breaks group-based RL's assumption that rollouts in a group are comparable. Reward-model style preferences then distort relative advantage and push optimization toward reward-preferred rather than context-appropriate behavior. ARC restores fairness via strategy-conditioned rollout grouping plus hybrid rewards and entropy regularization. **Why it matters:** Names and fixes a concrete reward-hacking vector in GRPO-style training of interactive agents.
- **From Passive Delegates to Strategic Negotiators: SocialRL for Small Language Models** — Hua, Huang, Payne et al. · https://arxiv.org/abs/2608.13787
  Agents acting for users routinely face counterparts with conflicting goals, and the traits that make a model pleasant make it a bad delegate — leaking the principal's private info and conceding immediately. SocialRL trains social reasoning directly in a 4B model across six domains (Deal-or-No-Deal, CaSiNo, Craigslist, Job Interview, Calendar, Marketplace), each trained in-domain then evaluated on all six. **Why it matters:** Shows helpfulness alignment is actively harmful in adversarial delegation, and that a 4B model can be trained out of it.
- **Agentic Transaction: Towards ACID-Compliant Agent Systems** — Sun, Wang, Li · https://arxiv.org/abs/2608.13900
  Agents running long-horizon tasks over persistent workspaces hit the same problems databases solved: reliable execution, consistent outcomes, safe concurrency, durable state. The paper defines the "agentic transaction" and reinterprets ACID as four semantic guarantees — Semantic Atomicity, Consistency, Isolation, Durability. It proposes these as a design foundation for reliable agent systems. **Why it matters:** Gives agent infrastructure a vocabulary and correctness model borrowed from 50 years of transactional systems work.
- **Ontology-Grounded Project Memory for Coding Agents** — James Adam · https://arxiv.org/abs/2608.13662
  MOOSEDev gives coding agents structured project memory: architectural decisions, lessons, constraints, and rationales stored in a knowledge graph exposed over MCP. Records carry lifecycle status, provenance, and supersession links, queried through a neurosymbolic engine that treats the symbolic layer as the primary reasoning substrate. Against a production vector-memory tool on 835 typed records it returned the expected answer set essentially in full. **Why it matters:** Symbolic, supersession-aware memory beats vector recall for the "why was this changed" questions coding agents actually need.
- **TimeSage-EV: A Live Benchmark for Agentic Time Series Analysis in Evolving Environments** — Yao, Kong, Nie et al. · https://arxiv.org/abs/2608.14270
  Time-series QA benchmarks use fixed snapshots, so they never test whether an agent respects data cutoffs or temporal validity. TimeSage-EV tracks 60 real institutional scenarios across 6 domains with 1,485 scenario-period QA pairs from Feb 2023 to May 2026, at monthly through irregular release cadences. Agents get data plus source reports per period, and the withheld next release is ground truth for state identification, summarization, and outlook reasoning. **Why it matters:** A live, cutoff-aware benchmark closes the contamination loophole that static time-series evals leave open.
- **Evolve Vision-Language-Action Model into an Agent with On-the-fly Tool-use** — Ding, Yu, Dai et al. · https://arxiv.org/abs/2608.14047
  ART tunes any VLA model to call off-the-shelf tool modules for low-level vision, high-level affordance, and embodiment enhancement instead of solving everything in one continuous action space. Shrinking the action solution space via tool-use improves cross-task generalization and cuts data dependency. The team trained on 30K tool-use trajectories, far fewer than baselines require. **Why it matters:** Tool-calling as an action-space reduction technique — an order-of-magnitude data saving for robot policies.
- **SkillSight: Calibrating Generic Content Bias for Skill Retrieval** — Xiao, Li, Li et al. · https://arxiv.org/abs/2607.18785
  As skill libraries grow, picking the right skill becomes the bottleneck, yet retrievers treat skill docs as ordinary text and ignore their highly regular structure. Shared descriptive boilerplate inflates dense relevance scores, creates a query-document energy gap, and hides the discriminative signal against structurally similar hard negatives. SkillSight is training-free and calibrates that shared background in both semantic and lexical space. **Why it matters:** Directly targets the failure mode every large skill/tool catalog hits — retrieval collapse from boilerplate similarity.
- **Does a Language Server Save Tokens for Coding Agents?** — Pengcheng Xu · https://arxiv.org/abs/2608.13568
  The claim that LSP-based semantic retrieval is more token-efficient than grep is asserted widely and measured almost nowhere. This paper defines a single metric (tokens-to-success), specifies a five-arm ablation isolating semantic retrieval from confounds, and maps three pre-stated failure modes to measurable variables. It reports a preliminary Python/TypeScript study against frontier coding models. **Why it matters:** Grep-vs-LSP is a live architecture decision in every coding agent; this is the first attempt to actually measure it.
- **Not All Tokens Are Equal: Inflation-Aware Routing for Agentic LLM Systems** — Fu, Lin, Xie, Xiong · https://arxiv.org/abs/2608.13571
  Retries make real workflow cost diverge from per-token price; the authors call the ratio "token inflation" and measure up to 4.25× for a 7B model on multi-hop QA. Routers like FrugalGPT price on single calls and can underestimate true cost by more than 2× on hard tasks. InflationAgent is a four-stage router using CoT Branching Entropy, a pre-execution difficulty signal computed from local inference. **Why it matters:** Cheap models are not cheap once retries are counted — routing must price the whole workflow.
