## 📄 Research Papers — Top Picks
- **ArenaFlow: From Trajectory Ranking to Hierarchical Credit Propagation for Open-Ended Agent RL** — arXiv cs.CL · https://arxiv.org/abs/2609.21378
  RL for LLM agents works in verifiable domains but struggles on open-ended tasks where scalar rewards are unreliable. ArenaFlow uses tournament-style relative ranking of trajectories to derive rewards, then attaches structured feedback to each comparison so credit can be propagated down to decisive intermediate steps rather than collapsed into one trajectory-level number. Successful behaviors are consolidated into reusable skills. **Why it matters:** Step-level credit from pairwise comparisons is a practical route to training agents on tasks without ground-truth checkers.
- **CIPL: A Channel-Aware Framework for Recoverable Privacy Leakage in LLM Agents** — arXiv cs.AI · https://arxiv.org/abs/2609.21686
  Privacy leakage in agents is usually measured inside single components (memory, retrieval, tool-use), which conflates internal exposure with what an outside observer can actually recover. CIPL models the path from sensitive source through selection, assembly, execution, observation and extraction, and evaluates black-box recoverability under one shared protocol. Experiments across memory-, retrieval- and tool-mediated targets plus a BrowserUse live-agent case study show storage labels alone do not predict recoverability. **Why it matters:** Gives agent builders an end-to-end leakage metric instead of per-component checks that miss real attacker recovery.
- **Staying on the Attack Path: Structured State for Long-Horizon Automated Penetration Testing** — arXiv cs.AI · https://arxiv.org/abs/2609.07344
  LLM pentest agents suffer context forgetting and intent drift on long tasks, losing early facts and wandering into repetitive exploration. Intentest externalizes long-horizon state into a persistent fact-intent DAG outside the context window, where verified network states and intents constrain the next action and cut invalid transitions. Evaluated on web-application penetration testing as a representative long-tail security task. **Why it matters:** Externalized, graph-structured state is a reusable pattern for any long-horizon agent, not just security tooling.
- **LiteMedCoT-VL: Parameter-Efficient Adaptation for Medical Visual Question Answering** — arXiv cs.AI · https://arxiv.org/abs/2605.09384
  Compact 2–4B VLMs fit on portable clinical devices but lack multi-step reasoning, and standard distillation transfers answers without the reasoning. LiteMedCoT-VL distills chain-of-thought from a 235B teacher into 2B students via LoRA fine-tuning on explanation-enriched data, with inference done directly on images (no captioning). **Why it matters:** Shows reasoning-trace distillation, not just answer distillation, is what closes the gap for small on-device multimodal models.
- **MemoryArena: Benchmarking Agent Memory in Interdependent Multi-Session Agentic Tasks** — arXiv cs.CL · https://arxiv.org/abs/2602.16313
  Existing memory benchmarks test recall or single-session action in isolation, but real agents acquire memory while acting and then depend on it later. MemoryArena is an evaluation gym of human-crafted agentic tasks with explicitly interdependent subtasks across sessions in a Memory-Agent-Environment loop. **Why it matters:** First benchmark that couples memorization and downstream action, which is what long-running assistants actually need.
- **MemAudit: Auditing Long-Term Agent Memory via Hidden User-State Recovery** — arXiv cs.CL · https://arxiv.org/abs/2606.24595
  Long-term memory is usually judged indirectly via downstream answers or personalization; the memory artifact itself goes unaudited. MEMPROBE has a memory-equipped agent assist simulated users carrying hidden taxonomy-anchored state banks across leak-controlled tasks, then measures what structured user state can be reconstructed from the memory left behind. **Why it matters:** Treats memory as an auditable artifact, which is the right framing for both quality and privacy review.
- **An Interpretable Memory Decision Controller for LLM Agents Based on Three-Signal Complementarity** — arXiv cs.CL · https://arxiv.org/abs/2609.22043
  Memory systems optimize retrieval but rarely decide whether retrieved memories should be trusted; with conflicting memories, plain RAG amplifies hallucination above a memory-free baseline. The Memory Decision Layer is a zero-parameter controller between retrieval and generation that fuses relevance, reliability and task risk via a three-signal orthogonal encoder. **Why it matters:** A cheap gate on memory injection directly targets the failure mode of agents that accumulate contradictory context.
- **Designer-RSI: Evolving Procedural Memory from User Traffic for Agentic Graphic Design** — arXiv cs.AI · https://arxiv.org/abs/2609.22086
  A frozen frontier model drives professional design software through 230+ tools while an external procedural memory of natural-language skills grows and refines itself from experience. Memory widens by adding procedures for uncovered subtasks and deepens by revising procedures against their own successes and failures, with a replay gate admitting only changes that fix failures without regressing. Five rounds over 1,406 real user briefs and 1,869 graded trajectories, no weight updates. **Why it matters:** Concrete evidence that skill-file style procedural memory can self-improve a tool-using agent in production without fine-tuning.
- **Verify, Don't Trust: Agentic Model Development for Video Discovery Retrieval at Scale** — arXiv cs.AI · https://arxiv.org/abs/2609.21257
  Autoresearch loops work on minutes-scale self-contained programs, but online autoresearch spans asynchronous systems and weeks-long campaigns where a completed run can still yield invalid conclusions (no-op code changes, data leakage, evaluator drift, mismatched serving funnels). EvoPilot is a human-gated method where role-specific agents run each round via a versioned domain skill and typed adapter, with durable records and deterministic checks enforcing recorded lessons, studied over a 37-day retrieval campaign. **Why it matters:** A field report on making agent-driven experimentation trustworthy at product scale.
- **BI-Agent and BI-Bench: Towards Automating End-to-End Business Intelligence** — arXiv cs.CL · https://arxiv.org/abs/2609.20886
  BI workflows require finding tables, transforming data and building joins before a question can be answered. The authors harvest real-world BI projects and extract question/ground-truth pairs from real dashboards to build BI-Bench, then study whether LLM agents can answer end-to-end without manual preparation. **Why it matters:** Realistic multi-step data benchmark for enterprise analytics agents, beyond single-query text-to-SQL.
- **MIRAGE: Multi-Perspective Creative Language Model Reasoning with Reinforcement Learning Guidance** — arXiv cs.CL · https://arxiv.org/abs/2609.21554
  Inference-time framework inspired by human perspective switching: a Selector prioritizes conceptual perspectives (algebraic, probabilistic, ...) and a Reasoner solves sequentially until confident, otherwise aggregating perspectives. Outperforms Chain-of-Thought and diverse-prompting baselines on GSM8K, MATH500, MMLU-Pro and Game-of-24. **Why it matters:** Structured perspective selection is a lightweight alternative to brute-force sampling for hard reasoning.
- **Collaborative Memory for Multi-Agent VLM Systems** — arXiv cs.AI · https://arxiv.org/abs/2609.17921
  In multi-agent VLM settings, agents inspect different regions, frames or representations, so collaboration means distributed perception, not just distributed reasoning. The paper frames memory hierarchy, cross-agent sharing and consistency mechanisms around reconciling interpretations and updating dependent reasoning, with shared visual memory preserving dependencies among observations. **Why it matters:** Defines the shared-context problem that multi-agent multimodal systems will hit as soon as they scale past one viewpoint.
- **PlaceReasoner-Beta: Reasoning-Driven Macro Placement and Benchmarking** — arXiv cs.AI · https://arxiv.org/abs/2609.21263
  Reformulates VLSI macro placement as closed-loop reasoning instead of one-shot proxy optimization: a VLM planner proposes placements from the floorplan image and specs, a geometric verifier enforces legality and expert rules, and a physical verifier feeds downstream results back. **Why it matters:** Planner + verifier loops with VLMs are reaching hard engineering domains with real physical feedback.
- **Knowledge-Graph Based Augmentation versus Retrieval Augmented Generation for Cultural-Related Question Answering** — arXiv cs.CL · https://arxiv.org/abs/2609.18317
  Benchmarks Graph-RAG against standard RAG on LatamQA, a culturally grounded multiple-choice set over eight categories, with graphs built automatically from Wikipedia via KGGen and no manual curation. G-Retriever is competitive with RAG and reduces error on long-tail facts. **Why it matters:** Practical evidence on when structured graph retrieval beats text RAG for underrepresented knowledge.
- **Playing log(N)-Questions over Wikipedia Abstracts: How Per-Round Errors Compound Under Information Asymmetry** — arXiv cs.CL · https://arxiv.org/abs/2609.19113
  Six frontier models play a two-agent binary-question game (N = 4 to 1024 candidates) where a questioner must identify a secret target in exactly log2 N questions answered by a same-provider agent. Across 408 games, win rate decays as p^(log2 N) with p ≈ 0.93; per-round failure is flat, so errors compound because more rounds must succeed, not because rounds get harder. **Why it matters:** Clean quantification of how multi-turn agent-to-agent communication degrades with horizon length.
