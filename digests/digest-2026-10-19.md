## 📄 Research Papers — Top Picks
- **Tool Recommendation for Multi-Step Agents: Finding Every Tool a Task Needs** — Sam Partee et al. · https://arxiv.org/abs/2610.23707
  A deployed gateway system that exposes ~8,200 tools to an agent through a fixed interface of just three tools, executing every call under the end user's credentials and per-service consent checks. On ToolRet it places every needed tool in the top ten 57% more often than BM25, and in paired multi-step workflows its first recommendation covered all required tools in 93% of cases. **Why it matters:** Shows a production-tested way to scale agents past the tool-list context limit of a typical MCP server without losing auth/consent control.
- **TokenEconomizer: Experience-Driven Black-Box Cost Control for Coding Agents** — Aaron J. Li et al. · https://arxiv.org/abs/2610.22732
  Evaluates coding agents over sequences of realistic tasks and finds recurring, environment-dependent token costs. TokenEconomizer is an external controller that injects operational micro-skills, prunes persistently irrelevant tools, and interrupts unproductive failure loops. Across Claude Code, Codex and GitHub Copilot CLI it cuts average token cost 18.4–30.9% at comparable task success. **Why it matters:** Directly actionable cost lever for teams running coding agents continuously on real repos.
- **Explore Separately, Adopt Selectively: Execution-Guided Tool Use over Large Tool Libraries** — Anna Mazhar et al. · https://arxiv.org/abs/2610.22688
  BRIA (Branch-Inspect-Adopt) isolates the investigation of each candidate tool in a separate branch that retrieves and executes tools; the main task agent inspects the execution evidence and adopts only useful results. Evaluated on PlanBench-XL and MCP-Atlas with a shared pool of 1,897 tools across three models, it matches or beats the strongest retrieval baselines. **Why it matters:** Keeps failed tool trials from polluting the main trajectory — a simple pattern for large-library tool use.
- **LoongSage: A Production-Grade, High-Efficiency Agentic RL Framework for Frontier LLMs with Validated Recipes** — LoongSage Team et al. · https://arxiv.org/abs/2610.16352
  LoongSage is an agent-native, fully asynchronous RL framework with a ~14K-line core built on Megatron and SGLang, centralizing orchestration in one controller process with GPU components as Ray actors. Its AgentFlow paradigm orchestrates both white-box and black-box agents, and sliding-window strategies bound trajectory staleness during async training. **Why it matters:** A lean, production-grade option for agentic RL post-training as existing frameworks grow unwieldy.
- **Code Skill Server: A Large-Scale Search Engine for Code Generation Skills** — Xiaoyong Li et al. · https://arxiv.org/abs/2610.23186
  Code Skill Server is a search engine that incrementally collects and indexes publicly available code-generation agent skills from heterogeneous sources (993 skills in the studied corpus). Experiments across retrieval methods and code-generation benchmarks compare how well retrieved skills help target tasks. **Why it matters:** Points toward skill registries/search as infrastructure as the number of reusable agent skills explodes.
- **Robust Function Calling for LLM Agents Under Interface Drift** — Aniruddha Chattopadhyay et al. · https://arxiv.org/abs/2610.23342
  Studies 'interface drift' — post-deployment changes to tool descriptions, schemas and candidate lists — as a function-calling failure mode. The training-free SchemaShield-Lite layer (schema validation, candidate-set retry, one-shot constrained repair) lifts Qwen3.5-9B from 0.717 to 0.813 on DICE-300 and 0.580 to 0.805 on BFCL-200. Distractor tools in the candidate set cause most of the damage. **Why it matters:** Cheap validation-and-repair wrapper that hardens tool-calling agents against changing APIs without retraining.
- **DLite: History-free Speculative Decoding for Agentic AI** — Jiaming Xu et al. · https://arxiv.org/abs/2610.23787
  Existing draft models lose up to 80% acceptance length on agentic workloads with long, evolving multi-turn contexts, and keeping their KV cache adds overhead. DLite reuses the target model's contextual hidden states for local speculative prediction without maintaining historical context, with a lightweight sequential head restoring intra-block causality. **Why it matters:** Speculative decoding tuned for agent workloads, where standard drafters break down.
- **SAFE-Mem: Secure Agentic Memory with Fine-Grained Authority and Governance-Aware Retrieval** — Haoming Li et al. · https://arxiv.org/abs/2610.22959
  SAFE-Mem labels each memory claim with kind, authority and scope, then uses governance-aware retrieval and a governance-enabled memory graph so untrusted external claims cannot later act as authorized preferences, policies or permissions. It targets blocking unauthorized influence while retaining legitimate memory use. **Why it matters:** Addresses memory-poisoning risk in persistent-memory agents with finer control than content filtering.
- **Before Retrieval Begins: Safety and Tool-Use Decisions in LLM Agents** — Aditya Nawal et al. · https://arxiv.org/abs/2610.23071
  Examines the upstream decision of whether an agent admits (calls) a tool for a harmful request. Across seven open-weight models, the average harm rate after admitted harmful requests is 74.5%; written refusal accompanies only 33.6% of admitted harmful calls, and a linear 'admission' direction influences held-out behavior in four of seven models. **Why it matters:** Shifts agent safety upstream to the tool-admission decision.
- **RedDarwin: Evolving Jailbreak Skills against Frontier LLMs** — Zhouyuan Ma et al. · https://arxiv.org/abs/2610.23726
  RedDarwin evolves executable jailbreak 'attack skills' rather than individual prompts: 47 base skills are autonomously revised, composed, executed and selected using target-model feedback. It yields 65 evolved skills, raising mean ASR on AdvBench from 18.8% to 47.3%, and transfers to held-out StrongREJECT and unseen frontier LLMs. **Why it matters:** Skill-based evolution lets automated red teaming keep pace as safeguards change.
- **PRIME: Towards Verifiable Evidence-Grounded Reasoning in LLM Agents** — Hamed Khosravi et al. · https://arxiv.org/abs/2610.22426
  PRIME pre-commits evidence routes for each conclusion before an agent checks records against requirements; a separate ledger program refuses conclusions the recorded checks do not justify and points to checks that could support stronger ones. Evaluated on 480 public-record cases such as vulnerability-report readiness. **Why it matters:** Makes agent compliance verdicts auditable and prevents premature or weakened conclusions.
- **AuditKIT: A Unified Evaluation Spine for Benchmarking, Judging, and Comparing Large Language Models and Agentic Systems** — Shreeyans Arora et al. · https://arxiv.org/abs/2610.22511
  AuditKIT is a source-available evaluation library that records benchmark accuracy, judge scores, runtime, tool-use behavior and retrieval quality in one result representation with direction-aware metric contracts and config fingerprints. For agents it offers turn-aware tool-call matching and marks unobservable evidence as unscored rather than failed. **Why it matters:** One evaluation spine for models, RAG and agents reduces hidden failures from mismatched metrics.
- **MultiAgent-OPD: End-to-End Training of Hierarchical Multi-Agent Systems with On-Policy Distillation** — Yuhan Sun et al. · https://arxiv.org/abs/2610.23234
  MultiAgent-OPD jointly trains a shared-parameter Leader–Searcher–Answerer team by combining RL with on-policy distillation: a frozen Teacher scores Searcher tokens for local process supervision while the Leader learns from team success. Across seven datasets it reaches 38.68% macro avg@4, beating a trained cascaded MAS+RL system by 2.61 points. **Why it matters:** A practical recipe for end-to-end training of hierarchical multi-agent systems.
- **AgentOdyssey: Open-Ended Long-Horizon Text Game Generation for Test-Time Continual Learning Agents** — Zheyuan Zhang et al. · https://arxiv.org/abs/2606.24893
  AgentOdyssey procedurally generates open-ended, long-horizon text games to evaluate test-time continual-learning agents. Beyond game progress, it diagnoses world-knowledge acquisition, episodic memory, exploration, action diversity and model cost across diverse agent paradigms on six generated games. **Why it matters:** Benchmark for agents that must learn during deployment, not only at training time.
- **GlobeBench: Evaluating Text-Based World Model Capabilities for Scalable Environment Simulations** — Nicholas Saban et al. · https://arxiv.org/abs/2610.22708
  GlobeBench offers 1,632 tasks across five domains and nineteen simulation skills, testing whether text-based world models can predict an environment's response to an action given the full agent trajectory. Among 20 LLMs and specialized world models, GPT-6 Astra tops at 49.57% success; accuracy drops as actions affect more of the environment. **Why it matters:** First standardized benchmark for LLMs as environment simulators for agent RL.
