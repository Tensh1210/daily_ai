## 📄 Research Papers — Top Picks
- **TROVE: Adaptive Agent Skill Orchestration via Trace-Grounded Route Validation and Editing** — Wang, Zhao, Huang, Xu, Niu, Liu, Wu (arXiv cs.AI) · https://arxiv.org/abs/2609.05019
  Agents usually commit to a plan before runtime evidence arrives, so when an intermediate step invalidates the plan they either execute stale steps or replan from scratch. TROVE distills evaluated workflow-search traces offline into atomic and composite skills plus an outcome-conditioned transition graph, then at runtime edits only the part of the route that observed evidence actually invalidates. The result is localized repair instead of full replanning. **Why it matters:** Most agent failures are recovery failures — repairing the invalidated suffix instead of restarting is the cheapest reliability win available today.

- **EVOHARNESSBENCH: Can Your Agents Keep Pace with an Evolving Harness?** — Ke, Patil, Shi, Li, Liu, Koul, Yavuz, Bansal, Joty (arXiv cs.CL) · https://arxiv.org/abs/2609.04280
  Existing continual-learning benchmarks vary the task stream while holding the agent's tools fixed. EVOHARNESSBENCH inverts this: the harness itself — tools, reusable skills, and specialist sub-agents — evolves across three controlled axes while tasks stay comparable. This isolates whether an agent notices and adopts newly available capabilities rather than reusing stale procedures. **Why it matters:** Real deployments add tools and skills constantly, so "does the agent adapt to its own harness changing" is the benchmark axis that matches production reality.

- **CoSkill: Joint Reinforcement Learning of Reasoning and Meta-Skill Agents for Hierarchical Skill Evolution** — Feng, Li, Chen, Gao, Chen, Wang, Pu (arXiv cs.AI) · https://arxiv.org/abs/2609.04865
  Existing agentic RL setups either evolve skill libraries separately from policy optimization or freeze meta-skills into fixed workflows, treating skills as passive artifacts to manage. CoSkill recasts the meta-skill workflow as a learnable Meta-Skill Agent and trains it jointly with the reasoning agent in one multi-agent RL framework. Skills therefore co-adapt with the policy that invokes them. **Why it matters:** Skill libraries stop being a static cache and become part of what training optimizes — the difference between reuse and actual improvement.

- **Trace2Tower: Transition-Aware EigenTrace Induction of Multi-Level Skills for LLM Agents** — Sun, Yang, Yuan, Li, Peng (arXiv cs.AI) · https://arxiv.org/abs/2609.05261
  Current trace-reuse pipelines retrieve shallow trajectories and flatten them into unstructured skill summaries, discarding temporal order and which steps actually caused success. Trace2Tower abstracts step-level interactions into canonical events and builds a graph governed by semantic compatibility, transition dynamics, and outcome evidence, then applies contrastive spectral analysis to induce a multi-level skill hierarchy. **Why it matters:** Skill quality is bounded by how traces are abstracted, and outcome-conditioned topology beats flat summarization for anything multi-step.

- **From Interaction Traces to Persistent Skills: Online Evolution for Computer-Use Agents** — Hu, Liang, Zhu (arXiv cs.AI) · https://arxiv.org/abs/2609.04869
  Computer-use agents typically discard procedural knowledge after each rollout, so the same GUI workflow is rediscovered every time. This work converts interaction trajectories and evaluator feedback into a persistent, versioned skill library that updates online. It also measures the longitudinal value of skills relative to the identical agent running without them. **Why it matters:** The incremental-value-over-time measurement is the part most skill-library papers skip, and it is what decides whether the library is worth maintaining.

- **CUA-Universe: A Scalable and Dynamic Environment for Hybrid GUI+CLI Agents** — Shi, Wang, Fang, Liang, Jin, Zhao, Liu, Chen, Wang (arXiv cs.AI) · https://arxiv.org/abs/2609.05374
  Computer-use agents benchmarked on OSWorld and AndroidWorld act almost entirely through the GUI, producing long inefficient trajectories for work a shell command would finish instantly. CUA-Universe provides a scalable environment where agents coordinate GUI inspection and CLI execution over shared application state, without hand-engineering each application. It targets the gap where CLI-native agents lack visual perception and GUI agents lack throughput. **Why it matters:** Real computer work is hybrid, and an agent that can drop to the shell when the GUI is the bottleneck is strictly more useful.

- **Does Your Agent's Memory Survive a Model Upgrade? A Controlled Study of Memory Portability** — Goyal, Ray (arXiv cs.CL) · https://arxiv.org/abs/2609.05339
  Swapping the underlying model can silently break an agent's memory: a new model reads old notes differently, mixed embedding versions break retrieval, and repair fails without the original evidence. The study holds history constant and compares four representations — verbatim long-context, chunked RAG, model-compressed notes, and a fixed-schema knowledge graph — across 48 synthetic histories with exact scoring on two open-weight models. **Why it matters:** Model upgrades are routine and memory migrations are not, so how you store agent memory determines whether the next upgrade quietly amnesias your system.

- **Persistent Teacher Anchoring for Tool-Using Agents** — Park, Song, Lee, Chang (arXiv cs.CL) · https://arxiv.org/abs/2609.04773
  In on-policy knowledge distillation the student explores states the teacher would never visit, and the teacher-student gap compounds along the rollout. For tool use this is worse than usual because a student-written call executes and its observation contaminates every later prefix before supervision arrives. The paper anchors the teacher persistently through generation rather than only scoring after the fact. **Why it matters:** Tool calls have side effects, so distillation for agents has to correct drift before execution, not after.

- **Search-G1: Grounded Search Agents via Representation-Based Intrinsic Rewards** — Cheng, Ma, Zhang, Zhang, Duan, Xia, Wang, Lu, Shi, Ma (arXiv cs.CL) · https://arxiv.org/abs/2608.07531
  Outcome rewards scale but cannot tell grounded retrieval apart from redundant searching, while process rewards need expensive annotation or judge inference during training. Confidence-style internal rewards (entropy, likelihood, information gain) are cheap but measure certainty rather than evidence grounding. Search-G1 derives intrinsic rewards from internal representations to reward genuine grounding in retrieved evidence. **Why it matters:** Cheap, dense signals for "did the agent actually use what it retrieved" are the missing piece for training search agents at scale.

- **DCFA: Dual-view Causal-inspired Attribution for Failure Reasoning in LLM-based Multi-agent Systems** — Wang, Wang, Jin, Chen, Xiao (arXiv cs.AI) · https://arxiv.org/abs/2609.04749
  Debugging a multi-agent run means finding the decisive error — the earliest action whose correction would have reversed the failure. Existing attribution methods surface shallow deviations like incomplete retrievals or formatting slips that downstream verification would have caught anyway. DCFA takes a dual-view causal-inspired approach to trace natural-language interactions to the actually decisive step. **Why it matters:** Without decisive-error attribution, multi-agent debugging degenerates into blaming whichever agent spoke last.

- **GRACE: Graph-Grounded Reflective Agent Copilot Engine for Expert-in-the-Loop Knowledge Expansion** — Yi, Minot, Lee (arXiv cs.CL) · https://arxiv.org/abs/2609.04442
  Standard RAG retrieves isolated passages without tracking how evidence across documents relates or quantifying uncertainty, so plausible-but-ungrounded claims survive. GRACE decomposes a response into atomic claims and grounds each against trusted priors in a weighted bipartite graph, using weighted centrality to classify claims by groundedness. Experts stay in the loop for the claims that fall outside the priors. **Why it matters:** Claim-level grounding scores give a usable gate for high-stakes deployment, which document-level retrieval scores never did.

- **Evidence Integration in Large Language Models** — Kawada, Kellis (arXiv cs.CL) · https://arxiv.org/abs/2609.04290
  LLMs now receive evidence from tools, retrieval, other agents, and users, but how that evidence shifts an answer the model has already begun forming is poorly characterized. The authors present a distributional theory where evidence tilts the receiver's prior over candidate answers, yielding testable predictions: candidates the receiver already finds probable are more persuasive, and models integrate their own characteristic errors more readily than errors from a different source. **Why it matters:** Multi-agent pipelines propagate errors preferentially between similar models — a concrete argument for cross-family verifiers.

- **Reviewer Capability Governs Rejection Targeting, Not Repair Skill: Evidence from LLM Execute-Review-Revise Pipelines** — Tanveer (arXiv cs.CL) · https://arxiv.org/abs/2609.04270
  Multi-agent pipelines routinely assign execution and verification to different capability tiers because running a flagship model at every stage is expensive. This study varies reviewer capability all the way down to models that cannot solve the problems at all, measuring the outcome of every individual rejection across 100 olympiad math problems. The finding is that reviewer capability controls which answers get rejected, not how well the pipeline repairs them. **Why it matters:** You can economize on the reviewer's fixing ability but not on its judgment about what to reject — that is what decides whether verification helps or hurts.

- **La Agente Óptima: Towards Agentic Self-Driving Laboratories** — Müller, Bai, Gottstein, Mandal, Savino, Kang, Bernales, Aspuru-Guzik (arXiv cs.AI) · https://arxiv.org/abs/2609.04564
  Self-driving labs still depend on human specialists to translate scientific goals into executable closed-loop campaigns and to adjust them as conditions change. La Agente Óptima is an agentic framework that constructs and supervises Bayesian optimization campaigns across both computational and experimental systems while maintaining persistent optimization state. Separating LLM reasoning from campaign execution lets the optimizer run repetitively without the model in every loop. **Why it matters:** Keeping the LLM at the campaign-design layer and out of the inner loop is the right architecture for any long-running optimization an agent supervises.

- **Diffusion Language Models for Mobile Edge Agentic AI: Foundations, Applications, and Challenges** — Li, Min, Niyato, Ni (arXiv cs.AI) · https://arxiv.org/abs/2609.04778
  Diffusion language models generate by iteratively denoising tokens rather than decoding left to right, so they can update several uncertain tokens in parallel and use bidirectional context throughout generation. For edge agents this enables partial refinement, early exit, and constraint-guided correction — quality/latency trade-offs that fixed sequential decoding cannot express. The survey maps the foundations, mobile-edge applications, and open challenges. **Why it matters:** On-device agents are latency-bound, and non-autoregressive decoding is the main architectural lever left for cutting response delay.
