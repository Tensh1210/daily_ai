## 📄 Research Papers — Top Picks
- **MCPDisCo: Seesaw-Mitigated Tuning for MCP-Native Agents** — Du et al. · https://arxiv.org/abs/2610.14956
  An ecosystem-scale RL framework for MCP-native agents trained on real-server, long-horizon interactions across 70 MCP servers and 527 tools in six domains. It models reasoning, routing, execution and termination as a Thought-MDP and identifies a 'reasoning-tool seesaw' where improving one objective hurts the other. Token-masked reward attribution plus bidirectional gradient surgery mitigate the interference. **Why it matters:** One of the first large-scale RL training studies run directly on real MCP servers.
- **Dive into Claude Code: The Design Space of Today's and Future AI Agent Systems** — Liu et al. · https://arxiv.org/abs/2604.14228
  Analyzes Claude Code's architecture from public source and compares it with OpenClaw and Hermes Agent. The core is a simple model-then-tools while-loop; most code lives around it: a seven-mode permission system with an ML classifier, a five-layer context compaction pipeline, and four extension mechanisms (MCP, plugins, skills, hooks) plus subagents. **Why it matters:** A detailed map of the design choices behind a production coding agent, usable as a reference architecture.
- **Davinci-Tool: Scaling Agentic Tool-Use Supervision with Verifiable Executable Environments** — Yuan et al. · https://arxiv.org/abs/2610.16867
  Introduces a 30B tool-use model and Davinci-ToolData, which stores restorable states, execution traces, outcomes and verifiers together. Two pipelines (execution-grounded task synthesis and executable environment synthesis) yield 30,395 verified trajectories across single and coordinated domains. **Why it matters:** Scales tool-use training data with executable verification instead of LLM-judged success.
- **ClawLoop: Self-Improving Agents via Harness-Native Training Loop** — Yang et al. · https://arxiv.org/abs/2610.14118
  Targets agents that operate in sandboxed harnesses with file systems and shells. ClawLoop runs a self-sustaining cycle of task synthesis, training and evaluation feedback without any external teacher model, replacing one-shot, teacher-dependent pipelines. **Why it matters:** Teacher-free self-improvement for harness-based (Claude Code-style) agents.
- **Evaluating LLMs as Agentic Workflow Executors in Real-World Customer Support Skills** — Laskar et al. · https://arxiv.org/abs/2610.14346
  Builds a benchmark by mining recurring workflows from real support transcripts and converting them into structured skill descriptions with MCP-compatible mocked tools. Evaluates 17 models (closed plus 1.7B-14B open-weight) with five LLM judges and a rule-based checker for tool coverage, hallucinated tool calls and unsupported claims. **Why it matters:** Realistic, skill-scoped evaluation of how well small open models run bounded enterprise workflows.
- **Frustratingly Easy Agentic RAG via Portable Skills: A Case Study in Customer Support** — Bako et al. · https://arxiv.org/abs/2610.14428
  A deployment case study replacing complex chunking/re-ranking RAG pipelines with a portable skill: a natural-language instruction, lightweight tools (retrieval API, format checkers) and an LLM-generated 'Wikipedia-style' navigation index over the corpus. It takes 1-2 engineer days to build and ports across agentic harnesses. **Why it matters:** Evidence that a skill plus a navigation layer can replace bespoke RAG infrastructure.
- **Decoupling Search from Reasoning: A Vendor-Agnostic Grounding Architecture for LLM Agents** — Boateng et al. · https://arxiv.org/abs/2606.18947
  Decoupled Search Grounding moves web grounding out of the model into an MCP-compatible gateway with provider routing, fallback, retrieval-depth control and caching. On SimpleQA it nearly matches native search accuracy (86.1% vs 87.7%) at 91% lower search cost with a 99.4% warm-cache hit rate; native search still leads on recency-heavy FreshQA. **Why it matters:** A practical pattern for controlling search cost and output format in production agents.
- **ActionOPD: Distilling Decisions, Not Tokens** — Yuan et al. (HF trending) · https://huggingface.co/papers/2610.19820
  Proposes action-level on-policy distillation for agents: at student-visited states it samples actions from both the student and a black-box teacher and rewards semantic agreement. This avoids needing teacher token probabilities or a shared tokenizer. **Why it matters:** Makes distilling closed-model agents into small students feasible with black-box access only.
- **SEAR: Self-Evolving Agentic Robotics** — Wang et al. · https://arxiv.org/abs/2610.18792
  A framework and benchmark testing whether LLM agents genuinely learn when improving robots, in code-as-policy, agent-as-policy, or auto-research (fine-tuning a VLA) modes. Controls separate retained experience from extra attempts and luck across seven frontier models, 330 simulated and five physical tasks. **Why it matters:** Rigorous controls for the 'is the agent actually learning?' question in self-improving systems.
- **Google Earth AI Geospatial Reasoning Agent: Capabilities and a Systematic Evaluation** — Slonim et al. (Google) · https://arxiv.org/abs/2610.15750
  Presents Google Earth AI's Gemini-powered Geospatial Reasoning agent, which organizes data sources, foundation models and tools into modular domain skills with upfront planning. Releases dev splits of two benchmarks: expert-curated GeoExpertQueries with golden workflows and a tool-agnostic autorater, and templated GeoKTools with deterministic solvers. **Why it matters:** A large-lab example of skill-based agent design plus a recipe for evaluating multi-workflow tasks.
- **ActICL: Post-Training for Agentic Multimodal In-Context Learning** — Li et al. · https://arxiv.org/abs/2610.19475
  Trains an MLLM agent to acquire its own in-context demonstrations through tool-augmented reasoning: it identifies information gaps, retrieves candidates, then filters or refines its context iteratively. **Why it matters:** Turns demonstration retrieval for multimodal ICL into a learned agentic skill.
- **GeoSkill: Experience-Driven Hierarchical Skill Learning with Collaborative Revision for Geospatial Agents** — Luo et al. · https://arxiv.org/abs/2609.13667
  A hierarchical skill bank (planning skills plus tool-usage constraints) distills past geospatial executions into reusable procedural knowledge, using collaborative revision instead of unreliable pure self-reflection. **Why it matters:** A structured alternative to naive self-reflection memory for long tool-chain agents.
- **f-OPD: Stabilizing Long-Horizon On-Policy Distillation with Freshness-Aware Control** — Chen et al. · https://arxiv.org/abs/2605.17862
  Decomposes asynchronous on-policy distillation error into rollout drift and supervision drift and introduces a per-sample freshness score to down-weight stale samples. It matches synchronous performance on reasoning, tool-use and coding-agent tasks while keeping async throughput. **Why it matters:** Makes async distillation of long-horizon agents stable without sacrificing training speed.
- **P2Skill: Privacy Preserving Skill Distillation for Cloud-Local LLM Inference Systems** — Ryu et al. · https://arxiv.org/abs/2608.14094
  A local small model runs four prompt-based skills to strip PII before requests go to a cloud LLM, and the cloud model iteratively refines those skills from failures. It needs no privacy-specific fine-tuning and leaks fewer identifiers than prior methods that send text to the cloud. **Why it matters:** A training-free pattern for using frontier cloud models on sensitive data.
- **RCR-Router: Efficient Role-Aware Context Routing for Multi-Agent LLM Systems with Structured Memory** — Liu et al. · https://arxiv.org/abs/2508.04903
  An execution-time layer that routes only role-relevant shared-memory items to each agent under token budgets, using role-conditioned relevance scoring and iterative memory updates. **Why it matters:** Cuts redundant token usage in multi-agent orchestration.
