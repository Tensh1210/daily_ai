## 📄 Research Papers — Top Picks
- **Harness Engineering for Software Engineering via Modular Executable Dev-Primitives** — Haibo Jin, …, Haohan Wang · https://huggingface.co/papers/2610.07832
  Terminal-equipped coding agents are brittle on long-horizon work because they keep reconstructing program state scattered across files, configs, tests, and runtime behavior. Dev-Primitives pair each repository artifact with a resident LLM, giving it an agent-native interface grounded in its own implementation and dependencies. Components can then reason in natural language, communicate with each other, and self-modify locally. **Why it matters:** A concrete harness design that fights context explosion by distributing repo state across component-level agents.
- **One Step at a Time: Trading LLM Autonomy for Process Predictability** — Hans Schabert, Christoph Peters · https://arxiv.org/abs/2610.07817
  Instead of putting an SOP into the system prompt, an MCP server releases the procedure one step at a time and each step returns a structured step_output. The execution path is fixed before the run and the step records form an auditable, machine-readable log. Evaluated on 15,475 trials across 13 SOP-Bench domains with four open-weight executors (Kimi K2.5 to Ministral 3 8B). **Why it matters:** A simple MCP pattern for making agent-run business processes predictable and auditable.
- **Persistent Memory in Multi-Agent LLM Inference: What It Costs, What It Buys, and When You Can Tell** — Hochan Son et al. · https://arxiv.org/abs/2610.07782
  Decomposing long-context inference across agents cuts peak KV working set to 14.3 MiB vs ~35 MiB for single-pass and RAG baselines. But the persistent reasoning-trace memory tier adds cache cost and yields no detectable accuracy gain across eight controlled dataset pairs. The authors argue the null is structural to single-question benchmarks, and it took four measurement corrections (three of which inflated the benefit) to reach it. **Why it matters:** A rigorous warning that agent-memory gains reported on standard benchmarks may be measurement artifacts.
- **ReFold: Training-Free Reversible Inter-Turn Context Folding for Long-Horizon Agents** — Yupeng Su et al. · https://arxiv.org/abs/2610.07863
  ReFold is a rendering layer that keeps the full interaction history but compresses what the model sees: already-displayed content becomes a stub, and turns the agent marks finished fold into one-line notes. Rendering is chunked so the cached prefix is rewritten only every few steps, and every removal is reversible. No auxiliary predictor or training is needed. **Why it matters:** Context compression for long agent sessions that preserves prefix caching and never loses information.
- **Agentic AutoRAG: RAG Pipeline Optimization through Reasoning-Driven Agents** — Lasse B. Strand et al. · https://arxiv.org/abs/2610.08452
  Treats RAG configuration (chunking, embedder, reranker, generator) as multi-objective hyperparameter optimization driven by LLM agents. After each trial a Diagnoser attributes each failure to retrieval or generation, and a Proposer grounded in model rankings and pricing picks the next config, weighing accuracy against cost. **Why it matters:** Failure-attributed search is a smarter alternative to score-only tuning when choosing RAG pipeline components.
- **Confidence Reasoning Graphs: Structured Confidence Estimation for LLM Agents** — Brendan King et al. · https://arxiv.org/abs/2610.07948
  CRGs estimate the probability an agent succeeded from a single trajectory, with no privileged model access or training data. The success claim is decomposed into sub-claims grounded in trajectory evidence, each scored and then combined. **Why it matters:** Practical calibrated trust signals for deciding when to intervene on closed-model agents.
- **Large Language Model Orchestration under Heterogeneous Preferences via Explicit Persona Inference** — Shuqing Shi, …, Yali Du · https://arxiv.org/abs/2610.07587
  HARP moves an orchestrator's beliefs about agents' hidden preferences out of the prompt into one numeric posterior per agent, updated in closed form by Bayes' rule. The LLM supplies only actions and per-candidate likelihoods, so early belief errors get corrected instead of propagating. **Why it matters:** Explicit belief state is a cleaner orchestration primitive than prompt-text "memory" of other agents.
- **POLAR: Ontology-Guided Risk Prevention for Tool-Calling LLM Agents** — Yunju Kang et al. · https://arxiv.org/abs/2610.08082
  POLAR scores each tool call's reversibility by deriving a candidate inverse sequence via a two-layer ontology, and prunes calls below a threshold before execution. On τ²-bench it improves airline reward for four of six agents, but only 8 of 18 model–domain cells improve overall and stronger agents often regress. **Why it matters:** An auditable pre-execution guardrail, honestly reported with its utility trade-offs.
- **Quantization Effects on Tool-Failure Recovery Vary Across Prompts and Evaluation Designs** — Yuhe Hu · https://arxiv.org/abs/2610.07781
  Compares 8-bit vs 4-bit Llama-3.1-8B and Qwen2.5-7B on recovery from transient tool failures across 20 tasks and 5 prompts. The direction of the 8-bit/4-bit difference flips with prompt and with evaluation target (e.g. +17.5 for 4-bit, 0, or +28.3 for 8-bit on the same Llama setup). **Why it matters:** Quantized-agent robustness claims are fragile; evaluation design alone can reverse conclusions.
- **Hiding Tool Latency in On-Device Cascaded Voice Agent through Speculative Execution** — Kyudan Jung et al. · https://huggingface.co/papers/2610.07641
  A Predictor anticipates tool calls from partial ASR hypotheses and executes them while the user is still speaking, caching results for injection into the LLM prompt. Rule-based validation drops stale results after user self-corrections, and the LLM can still call tools directly, so latency is bounded by the serial baseline. **Why it matters:** Speculative tool execution is a cheap latency win for voice agents.
- **Leveraging a four-quadrant approach for evaluating Redpine Science** — Filip Dorm, Leonora Vesterbacka · https://arxiv.org/abs/2610.07937
  Evaluates Redpine Science, a peer-reviewed-literature service exposed via MCP and API, on chunk relevance and downstream answer quality. With it an agent gets 94.4% of SciFact claims right vs 87.6% without retrieval, and states 80.1% vs 70.2% of required claims on an expert set compared to web-search-only. **Why it matters:** Evidence that a curated MCP literature source beats web search for science-grounded agents.
- **UNREAL: Unifying Retrieval and Long-Context with a Single Model** — Edan Kinderman, …, Daniel Soudry · https://arxiv.org/abs/2610.08463
  UNREAL derives chunk encodings and retrieval queries from a frozen LLM's internal representations, adding under 500K trainable parameters. On a 21M-chunk Wikipedia index it beats retriever-reranker systems (HotpotQA recall 49.1% → 73.2%), and the same mechanism filters distractors in long contexts (NoLiMa 1.0% → 24.8%). **Why it matters:** One model-native mechanism for both RAG retrieval and long-context evidence selection.
- **Self-Retrospection Distillation: Turning Post-hoc Experiences into Prior Foresight** — Haoxiang Zhang et al. · https://arxiv.org/abs/2610.08077
  When all RLVR rollouts get equal reward, group-relative signals vanish; SRD instead distills hindsight from completed trajectories into the policy's pre-action foresight. Foresight is only a training target and need not be generated at inference. Tested across 10 tool-integrated reasoning and long-horizon agentic tasks. **Why it matters:** Extracts learning signal from agent rollouts that standard group-relative RL throws away.
- **Towards In-Parameter Memory Augmentation for Large Language Models** — Haoyu Huang et al. · https://huggingface.co/papers/2610.08630
  A survey of plugging memory-bearing parameter objects (adapters etc.) into the forward pass at inference, as an alternative to in-context memory. Methods are organized by parameter placement (embedding, attention, FFN, hybrid) and by how the parameters are acquired. **Why it matters:** Maps the design space for agent memory that doesn't consume the context window.
- **Dual-Modality Multi-Stage Adversarial Safety Training: Robustifying Multimodal Web Agents Against Cross-Modal Attacks** — Haoyu Liu et al. · https://arxiv.org/abs/2603.04364
  DOM injections can consistently corrupt both the screenshot and accessibility-tree channels of web agents, and attacks with a visual component far outperform text-only ones on MiniWob++. DMAST co-trains agent and attacker as a Markov game via imitation learning, oracle-guided SFT, and adversarial RL. **Why it matters:** Text-only safety training leaves multimodal web agents exposed to cross-modal injection.
