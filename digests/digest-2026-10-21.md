## 📄 Research Papers — Top Picks
- **EGI-BENCH: An Enterprise General Intelligence Benchmark Suite** — Zhiwei Liu et al. · https://arxiv.org/abs/2610.27234
  Consolidates eight enterprise-facing agent benchmarks — CRM ops, heterogeneous-document retrieval, personal data understanding, multi-turn planning, tool use/function calling, long-horizon research and long-context SWE — into one suite with a shared runner and scoring conventions. The goal is to make cross-benchmark comparison meaningful and clarify what an aggregate number represents. **Why it matters:** A single harness for judging whether an LLM is actually ready for enterprise agent workloads.
- **SPEM: Structure-Aware Procedural Memory for Efficient Skill Use in LLM Agents** — Ran Zhou et al. · https://arxiv.org/abs/2610.26995
  Large skill libraries are costly to load in full, while flat semantic retrieval ignores dependencies, execution order and data flow between skills. SPEM keeps an Atomic Skill Memory for individual skills plus a Skill-DAG Memory of reusable compositions mined from successful executions, and reuses these structures for new tasks. **Why it matters:** Directly relevant to scaling large skill catalogs without blowing up context.
- **More Memory, Worse Agents: Error Reproduction and Anti-Persistence in LLM Agents** — Ruhan Wang et al. · https://arxiv.org/abs/2610.27406
  Studies agents that store not only trajectories but also inferred rules, summaries and skills in external memory. Errors in those stored abstractions propagate through retrieval and reuse, shaping new trajectories that then reinforce the bad abstractions. **Why it matters:** A cautionary result for self-improving agent memory — more stored "lessons" can make agents worse.
- **AutoRedClaw: Automated Red-Teaming for Claw-Style Agents** — Hao Li et al. · https://arxiv.org/abs/2610.27244
  Persistent assistants like OpenClaw keep config files (e.g. AGENTS.md), long-term memory and reusable skills that are reloaded every session, so a single poisoning becomes a persistent cross-task threat. AutoRedClaw automates red-teaming of these systems, replacing manually built test cases and environments that quickly go stale. **Why it matters:** Config/memory/skill poisoning is a real attack surface for any agent setup that persists state.
- **Evolving Self-tuning Benchmarks for Long-Horizon Tool Use** — Hyunji Alex Nam et al. · https://arxiv.org/abs/2610.27307
  TURTLE uses Unsupervised Environment Design to evolve existing tool-use tasks with three LLM agents: a proposer rewarded for difficult tasks, a solver, and a feedback generator. It targets assistants operating apps like Gmail, Venmo and Slack without relying on human supervision for data generation. **Why it matters:** Scalable, self-hardening tool-use training/eval data instead of static hand-written suites.
- **MMedAgent-Plus: Scaling Multimodal Medical Agents across Modalities, Tasks and Workflows** — Ruoxin Wang et al. · https://arxiv.org/abs/2610.27233
  A vision-language planner orchestrates 18 specialist medical models spanning 12 tasks and 8 modalities through a unified tool interface, selecting and chaining specialists and synthesizing grounded answers. The planner is instruction-tuned on ~209K samples from 32 public medical benchmarks covering single- and multi-tool, multi-round interactions. **Why it matters:** A strong template for planner + specialist-tool agents in high-stakes domains.
- **MMEnterprise-Bench: Evaluating Enterprise Agents over Evolving Multimodal Records** — Seohyun Lee et al. · https://huggingface.co/papers/2610.27911
  1,613 questions grounded in multimodal workplace records (documents, chats, figures) from simulated collaboration projects, where information is shared, corrected and revised over time. Agents must resolve cross-source and temporal conflicts and recognize when evidence is insufficient. **Why it matters:** Tests the "which version is current?" problem that breaks naive enterprise RAG.
- **ChartEvo: Self-Evolving Agent Harnesses for Long-Tail Chart Reasoning** — Qi Wang et al. · https://arxiv.org/abs/2610.28282
  MLLMs handle common charts well but drop sharply on long-tail chart types. ChartEvo is a recursive self-improvement framework that lets chart agents adapt their own strategies and tools rather than relying on hand-engineered tooling for each chart family. **Why it matters:** Another data point that self-evolving harnesses beat manual tool engineering on long tails.
- **VisualEvolve: A Skill Self-Evolution Framework for Visual Reasoning** — Jiawei Wang et al. · https://arxiv.org/abs/2610.28386
  Represents visual operations and tool-use strategies as external skills that VLMs refine via self-evolution without weight updates. It explicitly addresses regressions from skill refinement and "evolution evidence overload" from inspecting accumulated trajectories plus skill history. **Why it matters:** Practical guardrails for skill self-evolution, a pattern spreading fast across agent frameworks.
- **PROVISO: Provenance-Informed Action Selection for Secure LLM Agents** — Bo Yan et al. · https://arxiv.org/abs/2610.27115
  A controller between action proposal and execution that tracks whether action content comes from the user or from external sources (tool outputs, third-party skills), and judges the proposed action against an available alternative instead of in isolation. This aims to break the usual security-vs-utility trade-off of action filters. **Why it matters:** Provenance tracking is a principled defense against prompt injection via tool outputs.
- **Unsupervised Tool Evolution for Coding Agents in Data-Lake Analytics** — Yuqing Yang et al. · https://arxiv.org/abs/2610.27327
  Coding agents answering data-lake questions redo discovery, cleaning and joins from scratch each time. TEAL evolves a library of reusable tools and usage skills for a worker agent without labels, with two agents proposing tools from prior work. **Why it matters:** Amortizes analytics-agent work across queries without needing expert ground truth.
- **PORA: Learning When More Reasoning Pays Off for LLM Agents** — Bo Yan et al. · https://arxiv.org/abs/2610.27119
  Under a fixed total reasoning budget, agents must decide before each action whether to think short or long. PORA learns this by comparing paired short- vs long-reasoning outcomes to estimate the downstream value of extra reasoning. **Why it matters:** Budget-aware thinking allocation directly cuts agent cost and latency.
- **Recoverability and Verifier Strength: Two Measured Preconditions for Unattended Agent Self-Improvement** — De Wang, Peng Qi · https://arxiv.org/abs/2610.27465
  Proposes two measurable quantities for platforms that let agents auto-improve from traces: verifier strength (agreement of an LLM-judge verifier with a trusted reference) and recoverability (how cheaply a bad change can be rolled back). A self-improvement step should only run unattended when both are adequate. **Why it matters:** A concrete safety gate for agents that ship their own changes.
- **SAPD: Learning from Agent Experience without Environment Interaction** — Juncheng Diao et al. · https://arxiv.org/abs/2610.27847
  Step-Advantage Policy Distillation refines an agent policy from existing offline trajectories without revisiting executable environments, avoiding SFT's catastrophic forgetting and online RL's need for live interaction. **Why it matters:** Lowers the infrastructure cost of scaling agent training.
- **ECHO: An Auditable Dual-Path Memory System for Long-Horizon Agents** — Yu Qian et al. · https://arxiv.org/abs/2608.21755
  A fast path captures immutable events for multi-route recall, while async workers consolidate experience into revisable state and rebuild indexes; source provenance, temporal authority and answer realization are explicit boundaries. It supports evidence-use checks on original-source packets. **Why it matters:** An auditable memory design addressing staleness and provenance in long-running agents.
