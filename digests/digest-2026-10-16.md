## 📄 Research Papers — Top Picks
- **MLExpert: Towards a Generalist Agentic Model for Autonomous Machine Learning Engineering** — Shangheng Du et al. · https://huggingface.co/papers/2610.22344
  MLExpert targets autonomous ML engineering, where a long run contains many costly experiments whose feedback reflects several preceding decisions. It trains a generalist agentic model to organize experiments and adapt strategies from execution feedback over long horizons, framed as a step toward AI-for-AI and recursive self-improvement. **Why it matters:** Long-horizon credit assignment over experiments is the core blocker for agents that do real ML work.
- **Librarian Agents: Training LLMs to Curate Long-Context Workspaces that Anticipate Future Queries** — Anikait Singh et al. · https://arxiv.org/abs/2610.22273
  Librarian Agents train LLMs to proactively reorganize unstructured corpora into a file workspace before queries arrive, instead of reacting at inference time. The approach exploits the fact that agentic harnesses like Claude Code navigate existing file structures well, so up-front curation serves diverse future queries efficiently. **Why it matters:** Shifts long-context work from reactive retrieval to anticipatory, harness-friendly workspace curation.
- **Incentivizing Tool-Use Reinforcement Learning for Post-Arrival Emergency Care Prediction** — Pengfei Hu et al. · https://arxiv.org/abs/2610.21449
  TIR-EC finds LLMs lag tree models on EHR prediction because they pick uninformative features and misread numeric risk. It exposes EHR feature groups as callable tools and trains with tool-integrated RL rewards for emergency-department outcome prediction. **Why it matters:** Shows tool-use RL can close the gap between LLMs and classic ML on structured clinical data.
- **CoWorld Reasoner: Agentic Multimodal Reasoning with the Evolving Video World Model-Driven Harness** — Dongjie Cheng et al. · https://arxiv.org/abs/2610.21910
  CoWorld Reasoner is an agentic framework that uses a video world model as a flexible visual-reasoning tool, generating task-relevant imagined content as extra evidence. It replaces fixed pipelines like novel-view synthesis with agent-chosen forms of visual imagination for spatiotemporal reasoning. **Why it matters:** World models as callable tools for VLM agents is a promising route to better spatial/temporal reasoning.
- **Skill-Decoupled On-Policy Expert Distillation for Unified Vision-Language Models** — Yuqi Xiong et al. · https://huggingface.co/papers/2610.22217
  SCOPED trains capability-specific VLM experts with RL, then extracts explicit skills via reward-guided reflection. During on-policy distillation those skills guide expert supervision but are hidden from the unified student, pushing it to internalize procedures while avoiding cross-capability gradient conflicts and reward-hacking bias. **Why it matters:** A clean recipe for merging many RL-trained specialties into one VLM without interference.
- **DocPilot: Interactive Agent Orchestration and Training for Long Visual Document Understanding** — Zhuowen Liang et al. · https://arxiv.org/abs/2610.21327
  DocPilot is an agentic framework for long multimodal document QA with expressive orchestration and fine-grained actions, plus training for the agent. It targets sparse cross-page evidence that single-pass VLMs and rigid-workflow document agents miss. **Why it matters:** Long visual documents are a top enterprise use case; finer-grained agent actions are what has been missing.
- **RSIFlow: Adaptive Self-Improvement Workflows with an Evolving Meta-Agent** — Huan Zhang et al. · https://arxiv.org/abs/2610.21791
  RSIFlow uses an evolving meta-agent to adapt self-improvement workflows to the current performance bottleneck, improving orchestration from execution feedback. It extends recursive self-improvement to the improvement mechanisms themselves. **Why it matters:** Meta-level optimization of agent self-improvement loops rather than fixed loops.
- **SSR: Structural Signal Retriever for Scalable Agent Discovery in LLM-Orchestrated Multi-Agent Systems** — Giancarlo Maldonado C\'ardenas et al. · https://arxiv.org/abs/2610.21113
  SSR is a deterministic, training-free retriever for Agent Card discovery in large multi-agent registries, using structural signals to keep the orchestrator's candidate context compact. It frames the problem as candidate-context scalability: each extra candidate raises cost, latency and context-overflow risk. **Why it matters:** Agent/tool discovery at scale is the same problem large MCP tool registries face.
- **MMSearch-OPD: Easy Made Hard, Hard Made Learnable for Long-Horizon Multimodal Search Agents** — Huanyao Zhang et al. · https://huggingface.co/papers/2610.22240
  MMSearch-OPD builds harder long-horizon multimodal search training data by controllably expanding reasoning chains from simple image-question pairs. It trains with joint RL and on-policy distillation, using answer rewards and lightweight behavior penalties. **Why it matters:** Addresses the data and process-feedback scarcity limiting deep-search agents.
- **Learning Self-Orchestration in Decentralized Agent Swarms** — Guowei Xu et al. · https://huggingface.co/papers/2610.22322
  Market-based post-training (MPT) jointly learns action policies and self-orchestration in decentralized agent swarms: agents bid to participate, bids decide who acts, and collective outcomes yield local credit. Individual capabilities and participation patterns co-adapt instead of being trained inside fixed structures. **Why it matters:** Learned, decentralized orchestration as an alternative to hand-designed multi-agent topologies.
- **Do Agents Need a New Kind of Paper? SPRA: Structured Paper Representation for Agents** — Yutong Leng et al. · https://arxiv.org/abs/2610.21424
  SPRA is a structured paper representation for agents: typed Problems, Contributions, Components, ExperimentSetups, Measures and Findings, with citation relations and source locations for verification. It is instantiated across 1M+ AI papers with ~20M research units. **Why it matters:** Agent-native scientific knowledge bases could make research agents far more reliable than reading PDFs.
- **From Long Context to Selective Memory:A Survey of Memory-Centric Compression for Large Language Models** — Chaogui Gou · https://arxiv.org/abs/2610.21165
  This survey reframes long-context compression as memory management for inference-time resources, unifying prompt compression, KV-cache management, efficient serving, retrieval augmentation and agent memory. It distinguishes compute-active memory from other tiers. **Why it matters:** A useful map of the fragmented long-context and agent-memory literature.
- **SkillNEO: Non-Elitist Evolutionary Optimization of Agent Skills** — Enze Ma et al. · https://arxiv.org/abs/2610.20926
  SkillNEO applies non-elitist evolutionary optimization to agent skills, letting lower-reward skill versions keep evolving because useful repairs often need several interdependent edits. It uses execution evidence to decide what to preserve and repair next. **Why it matters:** Directly relevant to self-improving skill libraries for agents.
- **AlphaDiana: A Measurement System for Agents in Verifiable Reasoning Tasks** — Zhanke Zhou et al. · https://arxiv.org/abs/2610.20675
  AlphaDiana is a measurement system for agents on verifiable reasoning tasks with modular dataset/agent/environment/scorer interfaces. It preserves harness-native control loops while separately controlling file reuse and memory retention, enabling matched interventions on tools, skills and memory. **Why it matters:** Controlled ablations of harness components are badly needed to understand agent performance.
- **Beyond Retrieval Failure: Understanding Why LLMs Miss Evidence in Multi-Hop RAG** — Jiaqi Wei et al. · https://arxiv.org/abs/2610.21184
  Holding retriever, corpus and generator fixed, the authors show much apparent multi-hop RAG retrieval failure is actually search drift: the agent stops querying for an unanswered sub-question. ExecutionRAG, a training-free requirement register that tracks open sub-questions, mitigates it. **Why it matters:** Reframes RAG debugging: the query policy, not the retriever, is often the culprit.
