## 🚀 Product & Breakthroughs
- **Testing ads in ChatGPT** — OpenAI · https://openai.com/index/testing-ads-in-chatgpt
  OpenAI has started testing advertising inside ChatGPT as a way to fund continued free access to the assistant. The company says ads will be clearly labeled, kept separate from the model's answers so responses stay independent, and paired with privacy protections and user controls. This is a monetization experiment rather than a full rollout. **Why it matters:** The first serious attempt to put an ad layer inside a mainstream chat assistant sets the norms every other assistant vendor will be measured against.
- **Daybreak models are now available on AWS** — OpenAI · https://openai.com/index/daybreak-models-are-now-available-on-aws
  OpenAI's Daybreak cybersecurity models are now offered through Amazon Bedrock, putting them inside AWS's managed model surface. The target use case is enterprise security workflows — triage, analysis, and defensive automation — run within an existing cloud account rather than through a separate OpenAI integration. **Why it matters:** Distribution through Bedrock lowers the procurement barrier for security teams already standardized on AWS.

## 📄 Research Papers — Top Picks
- **Euclid-MCP: A Model Context Protocol Server for Deterministic Logical Reasoning via Prolog** — Bartolomeo Bogliolo · https://arxiv.org/abs/2607.21412
  Euclid-MCP is an open-source MCP server that hands multi-step logical reasoning to SWI-Prolog instead of the LLM. It defines Euclid-IR, an engine-agnostic Horn-clause intermediate representation that is readable by humans, easy for an LLM to emit, and compilable to Prolog or other backends. The tool interface supports a translate-run-inspect-repair loop, so the client keeps full access to proof traces and derivation logs, evaluated on an IT security and compliance use case. **Why it matters:** Turns bespoke neuro-symbolic glue into a standard MCP tool any agent can call for auditable, deterministic inference.
- **The Periodic Table of LLM Reasoning: A Structured Survey of Reasoning Paradigms, Methods, and Failure Modes** — Anand, Ramesh, Mittal et al. · https://arxiv.org/abs/2606.11470
  A survey organizing 300+ recent papers into nine reasoning paradigms — chain-of-thought, multi-hop, mathematical, commonsense, visual/temporal, code, retrieval-augmented, tool-augmented/agentic, and RL-based. For each it reviews prompting, architectural interventions, SFT, verifier-guided inference, reward modeling, retrieval, tool interfaces, agentic workflows, and benchmark design, and catalogs characteristic failure modes. The core claim: LLM reasoning is not one emergent capability but a family of scaffolded behaviors. **Why it matters:** A usable map for picking the right reasoning scaffold instead of assuming a bigger model fixes reasoning.
- **Frontier AI performance across the business disciplines: a case-grounded benchmark of knowledge work and analytical reasoning** — Patel, Hosanagar, Krishnan, Callison-Burch, Lakhani · https://arxiv.org/abs/2607.16057
  Existing benchmarks mostly test recall, narrow QA, math, code, and tool use, leaving analytical white-collar knowledge work unmeasured — synthesizing complex information, judging under uncertainty, adversarial multi-stakeholder thinking, weighing trade-offs. BusinessCaseBench uses the business-school case method: hundreds of questions drawn from cases across eighteen disciplines, each with a rubric derived from the case itself so subjective output can still be graded. **Why it matters:** Gives a defensible way to measure the knowledge work companies actually want to automate, not the proxies benchmarks currently score.
- **SearchArt: Training Long-Horizon Search Agent with Scalable Synthetic and Verified Task** — Mei, Yu, Chen et al. · https://arxiv.org/abs/2607.24850
  SearchArt builds training data for long-horizon search agents by synthesizing information-seeking QA pairs and matching search trajectories from web documents plus automatically generated evidence graphs. A verification pipeline jointly checks QA consistency, trajectory quality, and relevance of retrieved evidence before trajectories enter a multi-stage post-training pipeline. This attacks both bottlenecks at once: scarcity of long-horizon tasks and the difficulty of grading intermediate tool-use steps. **Why it matters:** Verification-driven task synthesis is a practical path to training deep-research agents without hand-labeled trajectories.
- **SkillZip: Evaluation-Free Skill Compression for Self-Evolving Agents by Discovering Reusable Structure** — Bai, Lin, Liu et al. · https://huggingface.co/papers/2608.11079
  Self-evolving agents grow skill files by appending fixes and branches until the same rule is restated many times and common action sequences are copied rather than reused, making skills costly to inject and hard to maintain. Generic prompt compression fails because a skill is structured — name/description gate applicability, workflow controls execution, tool and output contracts constrain validity, and rare exceptions may still matter. SkillZip compresses by finding the shortest faithful structural explanation: state a repeated rule once at its proper scope, factor repeated sequences into shared procedures — with no rollouts or evaluation set. **Why it matters:** Skill bloat is the practical ceiling on self-evolving agents; compressing without rollouts makes maintenance affordable.
- **SPIEval: Evaluating Large Language Models as Mobile Assistants over Scattered Personal Information** — Ye, Sheng, Liu et al. · https://arxiv.org/abs/2608.10692
  SPIEval is a human-curated benchmark for mobile assistants that must stitch together personal information spread across apps, grounded in five cognitive capabilities: reasoning, disambiguation, integration, preference inference, and multi-intent decomposition. It contains 250 tasks over 4,335 personal records across 10 apps, with multi-turn interaction through 21 tools and verifiable outcomes. Across nine models the best, GPT-5.5 (xhigh), reaches only 57.3% accuracy while the weakest hits 16.4%. **Why it matters:** Quantifies how far personal-assistant agents still are from reliably using a user's own scattered data.
- **LLM Agents Factory: Retrieval of Domain-Specific LLM Agents** — Belov, Sosedka, Sakhovskiy et al. · https://arxiv.org/abs/2608.09934
  Instead of designing an agent on the fly for each request — costly and unstable — this framework retrieves from a base of 20K+ predetermined, Wikipedia-grounded agent profiles. It supports semantic-search retrieval of a profile or distillation into a compact model that generates the agent directly. On MMLU, BIG-bench, and BIG-bench Hard it beats non-agent baselines and matches AutoGen quality with a 120B backbone at substantially lower inference cost. **Why it matters:** Retrieval from a structured agent repository is a cheaper, more controllable alternative to generating agent roles per request.
- **Test-Time Self-Evolving GUI Visual Grounding via Reflection-Guided On-Policy Self-Distillation** — Shiyu Xuan, Zechao Li · https://arxiv.org/abs/2608.11191
  GUI agents normally freeze their grounding model after deployment and cannot adapt to unseen interfaces; test-time RL variants also can't reflect on failed exploration. This framework closes a loop of Exploration, Evaluation, Reflection, and Internalization: the agent predicts coordinates on new interfaces, an MLLM Reflector judges results and produces reasoning reflections, and Reflection-Guided On-Policy Self-Distillation converts that high-level reasoning into dense token-level supervision via a conditioned self-teacher. No human-annotated ground truth is required. **Why it matters:** Lets deployed GUI agents keep improving on the interfaces they actually encounter.
- **Bayesian-Agent: Posterior-Guided Skill Evolution Across LLM Agent Harnesses** — Wu, Yang, Liu et al. · https://arxiv.org/abs/2606.08348
  Self-evolution pipelines usually update prompts, tools, memory, SOPs, and skills via heuristic reflection or raw success counts, which is brittle when trajectories are sparse and expensive. Bayesian-Agent treats reusable skills as Bayesian evidence objects: it records verified trajectories, maintains posterior beliefs over skill reliability and failure modes, and converts those beliefs into auditable skill actions and model-facing guardrails. It matches or beats empirical-rate controls on RealFin-Bench, and incremental repair lifts SOP-Bench from 80% to 95%. **Why it matters:** A finite-sample-sound way to decide which agent skills to trust, replacing success-count heuristics.
- **Poise: Position-Aware One-Instruction Skill Injection for Silent Execution on LLM Agents** — Hao, Min, Zhang et al. · https://arxiv.org/abs/2606.07943
  Agent skill files have an open format, which enables skill poisoning: a tampered skill makes the agent run an attacker command while still completing the user's task. The authors define Attack Success Rate to require both a postcondition-validated sandbox action and a passing task verifier in the same trial, then show a reliability-visibility trade-off between conspicuous YAML frontmatter and the longer skill body. Poise uses context-aware generation to place exactly one benign-looking command-bearing instruction at a structurally feasible body position, reaching 89.3% ASR with codex+gpt-5.2 — 28 points above random body placement. **Why it matters:** Concrete evidence that shared agent-skill files are an underdefended supply-chain surface.
- **DSAgentBench: Can Agents Automate End-to-End Data-Science Workflows in Real Computer Environments?** — Rahman, Islam, Mahbub, Laskar, Joty, Hoque · https://arxiv.org/abs/2608.10366
  Existing benchmarks miss the multi-stage, multi-tool nature of real data science, which spans wrangling, exploration, modeling, visualization, and validation across notebooks, IDEs, terminals, browsers, and databases. DSAgentBench provides 275 tasks covering the full life-cycle inside real computer environments, each requiring decisions grounded in intermediate outputs and coordinated tool use. Deterministic evaluators verify analytical correctness, visual outputs, and model performance rather than surface text. **Why it matters:** Moves data-science agent evaluation from toy notebooks to the messy tool coordination real work requires.
- **DistilVDR: A Compact End-to-End Visual Document Retriever via Dual-Student Distillation** — Liu, Wang, Zhang, Xiao · https://arxiv.org/abs/2608.10636
  Visual document retrieval is dominated by multi-billion-parameter models that are slow to index and expensive to serve; prior compression either trains a small multi-vector encoder from scratch or distills only the query side. DistilVDR is a 524M end-to-end system distilled bilaterally from a single 8B vision-language teacher under a pointwise cosine alignment loss, so all supervision comes from the frozen teacher's embedding space — no relevance labels, negative sampling, or contrastive term. An asymmetric student concentrates visual capacity on the document side while keeping the query encoder at 70M, with a HiRes variant reaching 61.74 average. **Why it matters:** Label-free distillation makes document-image RAG cheap enough to index at corpus scale.
- **ComBodied Agents: a New Paradigm of Human-Centric Agentic AI** — Ding, Wang, Feng et al. · https://huggingface.co/papers/2608.10915
  Digital agents change software state and embodied agents change physical state, but neither models the person — why an older adult missed a dose, whether they were confused, had side effects, or refused. Combodied Agents makes the human state trajectory the primary object of modeling, prediction, and evaluation, using software tools, sensors, wearables, robots, and human services as action channels rather than goals. The loop combines event-based multimodal perception, longitudinal correctable memory, and Personal World Models. **Why it matters:** Reframes personal-assistant and health agents around modeling the user, not just executing tasks.
- **FlexSQL: Flexible Exploration and Execution Make Better Text-to-SQL Agents** — Pham, He, Nie, Xu et al. · https://arxiv.org/abs/2605.02815
  Most text-to-SQL systems retrieve schema once upfront and only revisit the database for post-hoc repair, so early mistakes are hard to recover from. FlexSQL lets the agent explore schema, inspect data values, and run verification queries at any point during reasoning, generating diverse execution plans to cover multiple query interpretations and implementing each in SQL or Python as appropriate. A two-tiered repair mechanism backtracks from code-level errors to plan-level revisions; on Spider2-Snow with gpt-oss-120b it scores 65.4%, beating baselines built on larger models. **Why it matters:** Shows interaction design, not model size, is the binding constraint for analytics agents.
- **Living-Harness Is an Interactive-Agent Evolver** — Du, Wang, Xu et al. · https://arxiv.org/abs/2607.26598
  Agents may recover from a failure within an episode, yet the same failure recurs later because post-episode feedback rarely revises the persistent harness. Living-Harness converts each completed trajectory and its evaluator signals into posterior evidence for bounded harness updates, guided by a domain-level Evolution-SOP. It writes two forms of procedural knowledge: episodic memory recording trigger conditions, failure patterns, and recovery actions, and a state graph of state nodes, repair edges, and transition rules, retrieved on later runs. **Why it matters:** Targets the harness — tools, context, memory, workflow — as the thing that should learn, not just the model.
