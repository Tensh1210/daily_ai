## 📄 Research Papers — Top Picks
- **SkillForge: Co-Evolving Skills and Agents via Dynamic Skill Lifecycles** — Yuyao Ge, Yiwei Wang et al. · https://huggingface.co/papers/2610.09832
  An agentic RL method that manages a skill library through a fitness-driven lifecycle: trial → active → stable → retired. Low-fitness skills are pre-retired using base-model rollouts, the filtered library seeds SFT, and during RL the library keeps being retired, stabilized, and mutated by an LLM. It reaches the best aggregate success rate across interactive agent benchmarks (up to 7.8% relative gain). **Why it matters:** Skill libraries go stale or turn harmful when they only grow, and this shows a principled way to prune them while training.
- **APEX: Active Protection at Execution Boundaries for LLM Agents** — Xinran Zheng et al. · https://arxiv.org/abs/2610.06966
  A defense against indirect prompt injection that does not try to recognize attack patterns. It enforces safety at the execution boundary, where agent state becomes an external action or output. An authorization contract compiled from the trusted task, before any untrusted execution, decides whether each effect is authorized and whether the runtime data feeding it is endorsed. **Why it matters:** As agents combine Tools, MCP servers, and Skills, injection carriers multiply, and a single boundary check holds up better than pattern matching.
- **Practice Makes Unsafe: Skill Misevolution in Self-Improving LLM Agents** — Xutao Mao et al. · https://arxiv.org/abs/2608.12851
  Defines "skill misevolution": an unsafe procedure from a past task is saved into a reusable skill and later repeated during benign tasks. The authors release SkillMisevo-Gym and SkillMisevo-Bench (525 tasks). All 21 agent/evolution-method combinations wrote unsafe skills, and 15 carried the harm into new sessions. **Why it matters:** Self-improving skill memory is a persistent attack surface that outlives the session where the malicious prompt appeared.
- **WebFovea: When the Model Is Right but the Click Is Wrong** — Jiangang Han · https://huggingface.co/papers/2610.03036
  A vision-based web agent that placed 2nd (57/100) in the WebRetriever Challenge 2026 on live websites. Many failures came from the harness, not the model: a coordinate-space mismatch put every click at 3/4 of its target, and actions on dropdowns, iframes, and text boxes failed silently. The paper describes how to make each model→browser round trip reliable. **Why it matters:** For computer-use agents, harness engineering can matter as much as model capability.
- **An Empirical Study of Agent Skills' Downstream Utility** — Yu Cheng et al. · https://arxiv.org/abs/2610.08875
  Measures how much Skills actually help on 87 SkillsBench tasks across nine model–harness configurations, drawing on a corpus of 37,596 marketplace Skills. On 36.78% of tasks, the same Skills help some configurations and hurt others. Execution traces show that the recommended guidance often goes unused. **Why it matters:** "Add a relevant Skill" is not reliably positive, so Skills need evaluation against each specific harness and model.
- **Training Advisors for LLM Agents from Task Outcomes (Caddie)** — Sergei Polezhaev et al. · https://arxiv.org/abs/2610.09858
  Trains a natural-language critic with RL, using only whether the agent eventually succeeds after receiving advice, while the base model stays frozen. A Qwen3-4B critic raises success rates across four base models, including three it never trained with. On MuSiQue it adds more than 25 points to Qwen3-4B and beats Kimi K3 running without a critic. **Why it matters:** A small, transferable advisor model is a cheap way to boost frozen agents without step-level labels.
- **MIMESIS: Learning User Simulators as Training Environments for Interactive Agents** — Hoang Phan et al. · https://arxiv.org/abs/2610.09484
  A 9B user simulator trained on human conversations with reasoning supervision and 13 realistic behavioral patterns. It beats Claude-Opus-5 on behavioral fidelity (+13.4) and Turing distance (−3.6). Agents trained against it are then evaluated. **Why it matters:** Off-the-shelf assistant LLMs make overly cooperative fake users, and realistic simulators produce better agent training environments.
- **GraphOPD: Graph-Augmented On-Policy Distillation for LLM Agents** — Bohan Lin et al. · https://arxiv.org/abs/2610.08959
  Shows that on-policy distillation which targets the highest-divergence steps does no better than random selection on multi-turn agent tasks, because early drift contaminates later context. GraphOPD builds a dependency graph of which steps enabled later ones and directs teacher guidance to the steps that matter causally. **Why it matters:** It addresses a specific failure of distillation for long-horizon agents.
- **SKT: Skill-Use Training at Scale via Verified Synthetic Data Generation** — Zelin Tan et al. · https://arxiv.org/abs/2608.02287
  A pipeline that synthesizes skill-grounded tasks and keeps only verified trajectories that actually use every required skill. From 2,000 public skills it produces 4,000 task packages and 27,164 trajectories, and it also introduces the SkillEval held-out benchmark. SFT on this data improves skill use across models and harnesses. **Why it matters:** Models need training to use Skills well, and this provides scalable data and a benchmark for that.
- **Hidden in Plain Sight: Benchmarking Agent Safety Against Decomposition Attacks with DECOMPBENCH** — Vikhyath Kothamasu et al. · https://arxiv.org/abs/2606.13994
  A benchmark for decomposition attacks, where a harmful task is split into individually benign, executable subtasks inside realistic workflows. Built with a graph-based decomposition framework, it shows that state-of-the-art agents are highly vulnerable. **Why it matters:** Safety checks applied to single steps miss intent that only appears across many tool calls.
- **GeoNatureAgent (GNA): Pre-Production Evaluation of Tool-Using Agents on Geospatial Tasks** — Gabriel Diaz-Ireland et al. · https://arxiv.org/abs/2610.09112
  A fixed 16-tool geospatial interface exposed as an MCP server, so the model is the only variable, plus a 103-task benchmark with deterministic scoring. Across nine LLMs, Claude Sonnet 4 leads (61.7%), followed by DeepSeek V3.2 (57.9%), and no other model exceeds 53%. Capability and per-case cost are reported separately. **Why it matters:** It is a reusable template for evaluating agents against an MCP tool layer before deployment.
- **RECAST: Learning to Compute the Right Context through Adaptive Evidence Routing** — Yilun Hao et al. · https://arxiv.org/abs/2610.10507
  Treats evidence construction as sequential decisions over retrieval and computation operations rather than similarity retrieval alone. A lightweight RouterLM chooses or specifies operations, which a frozen CompilerLM turns into executable code, so evidence can be derived by filtering, aggregation, or computation. **Why it matters:** Many questions have no answer stored in any single chunk, and RECAST extends RAG to evidence that has to be computed.
- **Frozen Models, Evolving Expertise: Learning from Deployment Experience for Multimodal Medical AI** — Yexiao He et al. · https://arxiv.org/abs/2610.09146
  A model-agnostic framework that lets frozen LLMs and VLMs improve from deployment cases through three external stores: a Skill for reasoning and tool use, a Knowledge Memory of verified facts, and a Multimodal Knowledge Base of visual examples. No weight access or fine-tuning is required. **Why it matters:** It brings continual learning to closed models in medicine, a domain where guidelines change.
- **RoboQuest: Generalist Physical Agents that Search, Inspect and Test** — Liu Renhang et al. · https://huggingface.co/papers/2610.10388
  A benchmark of ten mobile-manipulation tasks in which agents must gather missing information through physical interaction (search, inspection, testing) and decide for themselves when to commit. Five frontier multimodal agents and a fine-tuned π0.5 policy were evaluated, and the best succeeds on only 23% of episodes. **Why it matters:** Active information-gathering is a clear weakness for embodied agents.
- **Sequential Probabilistic Uncertainty Estimation for Parallel Multi-Agent Reasoning Systems (SAUCE)** — Tunyu Zhang et al. · https://arxiv.org/abs/2610.08901
  A training-free uncertainty estimator for multi-agent systems where agents solve the same problem over several rounds. It tracks a latent system-level belief by filtering round-level agreement and generation-uncertainty signals. Misclassification detection, selective prediction, and calibration all improve across five backbones and five benchmarks. **Why it matters:** It gives multi-agent debate and ensemble pipelines a usable confidence signal.
