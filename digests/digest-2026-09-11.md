## 🚀 Product & Breakthroughs
- **Introducing the Agents API** — OpenAI · https://openai.com/index/introducing-the-agents-api
  OpenAI launched the Agents API, a managed service for building and running cloud agents. It is powered by the Codex harness and handles orchestration, long-running sessions, and tool use on the server side rather than in the developer's own loop. **Why it matters:** The harness — not just the model — becomes a hosted product, which shifts where agent orchestration logic lives and who maintains it.

- **Build more natural voice experiences with GPT‑Live‑1 in the API** — OpenAI · https://openai.com/index/introducing-gpt-live-1-in-the-api
  GPT‑Live‑1 brings full-duplex voice conversation to the API, with stronger instruction following, custom voices, and telephony support. Full duplex means the model can listen and speak simultaneously instead of strict turn-taking. **Why it matters:** Telephony plus instruction following is the combination needed for production voice agents, not demos.

- **Now everyone can put data to work** — OpenAI · https://openai.com/index/put-data-to-work
  OpenAI introduced the Data agent in ChatGPT Work. It connects to company data sources, surfaces insights, and builds interactive dashboards from natural-language requests. **Why it matters:** An analytics agent bundled into the workplace product competes directly with BI tooling and pushes agent use into non-technical teams.

- **Introducing ChatGPT for Financial Services** — OpenAI · https://openai.com/index/introducing-chatgpt-financial-services
  A vertical ChatGPT offering for financial services that combines built-in financial data with the GPT-6 Astra model for research, modeling, and client-ready materials. It packages domain data access with the model rather than leaving integration to customers. **Why it matters:** Bundled vertical data plus a frontier model is the template for industry-specific agent products.

- **Expanding AI access and cyber defense for federal, state, local, and tribal governments** — OpenAI · https://openai.com/index/expanding-ai-access-us-government
  OpenAI and the US GSA will offer eligible federal, state, local, and tribal governments $0 license fees, 50% off usage, and expanded cyber defense support. The deal extends earlier federal-only pricing down to state and local levels. **Why it matters:** Near-zero pricing for the public sector locks in distribution before competitors and makes government a reference customer for cyber defense.

- **How a researcher uses Codex and ChatGPT to search for new antimicrobial molecules** — OpenAI · https://openai.com/index/using-codex-chatgpt-to-search-for-new-antimicrobials
  César de la Fuente's lab uses Codex and ChatGPT to mine living and extinct genomes for antimicrobial peptide candidates against drug-resistant infections. The agent handles the computational search pipeline while the lab validates candidates. **Why it matters:** Another concrete case of coding agents running scientific discovery pipelines rather than only writing software.

- **Measuring tactical intelligence targeting and conventional weapons capabilities of AI models** — Anthropic Frontier Red Team · https://www.anthropic.com/research/intelligence-targeting-conventional-weapons-capabilities

## 📄 Research Papers — Top Picks
- **Learning What to Retain: Gated-Memory Routing for Efficient Collaboration in Multi-Agent LLM Systems** — Rajib, Zheng, Lou · https://arxiv.org/abs/2609.00237
  Multi-agent orchestration that routes on the query alone cannot react to intermediate progress, while routing on the full execution history bloats cost. Gated-Memory Routing conditions each decision on a learned execution memory: a Memory Write Gate commits only non-redundant reasoning steps, a Retrieval Gate gives each agent a compact relevant subset, and an Adaptive Halting Controller stops once the memory holds enough evidence. Across five reasoning and code benchmarks it beats the strongest baseline by 2.44 points on average while cutting HumanEval inference cost 31.9%. **Why it matters:** Shows that what you let orchestration remember matters more than how much — a learned, gated memory beats both stateless routing and full-history routing.

- **Subagents vs Agent Skills: Executing Reusable Knowledge for Long-Horizon Agentic Tasks** — Piriyakulkij, Lawrence, Curth, Karmalkar, Prasad · https://arxiv.org/abs/2609.09233
  Agent skills are multi-file bundles usually executed by loading their instructions into the main context, which becomes brittle as long-horizon tasks accumulate context. The authors instead invoke skill packages as subagents that spawn fresh context windows per subtask. Subagent execution outperforms in-context skill execution when the skill exposes a clear input-output contract and encodes the needed procedure, at the cost of extra coordination tokens. **Why it matters:** Directly informs how to design skill libraries — the invocation mechanism (in-context vs subagent) is as important as the skill content.

- **Progressive Agent Skill Generation via Reinforcement Learning** — Shen, Zhang, Guo, Cheng · https://arxiv.org/abs/2608.01678
  Skill-α is an RL method that learns a unified policy for progressively generating agent skills from documents or experience, replacing heuristic and pipeline-style consolidation. Each skill is built by repeatedly applying the policy to successive evidence, trained with a rollback reward that compares downstream execution under the original versus edited skill on an anchored query. With a GPT-4o worker it improves downstream success over the strongest baseline by 3.1 points on CL-Bench and 6.7 on tau2-bench. **Why it matters:** Gives skills a learnable supervision signal — skills are judged by whether they change agent outcomes, not by how they read.

- **When Synthetic Data Hurts: On Catastrophic Forgetting in Skill Retrieval for LLM Agents** — Murtaza, Nie, Soni, Wen, Frydenlund · https://arxiv.org/abs/2609.10750
  A production skill router over 34,396 skills is used to study skill retrieval with scarce real supervision plus synthetic data. Fine-tuning on synthetic data improves in-distribution retrieval but causes catastrophic forgetting on real and out-of-distribution skills. Continual-learning mitigations (embedding-anchor regularization, LwF, EWC, L2-init) retain OOD performance and also lift in-distribution retrieval by 13.98% for a 0.6B Qwen retriever and reranker. **Why it matters:** Anyone fine-tuning a skill/tool router on synthetic queries needs a forgetting guard, or real-world routing silently degrades.

- **Overview of the NLPCC 2026 Shared Task 11: Agent-Based Experiment Reproduction from Scientific Papers** — Hong, Li, Luu, Yang, Zhou, Lin · https://arxiv.org/abs/2609.11117
  AgentActionBench is a process-oriented benchmark for agents reproducing experiments from 150 papers (120 ML, 30 AI4Science). An MCP-based Action Recorder captures agent behaviour throughout the reproduction, and traces are scored against paper-specific rubrics — a 10% human-annotated subset plus model-assisted augmentation to over 10,000 rubric items. Current systems remain limited, with execution as the main bottleneck; model-generated rubrics correlate strongly with human ones. **Why it matters:** Process-level scoring via MCP tracing is becoming the standard way to evaluate research agents, and execution — not planning — is where they fail.

- **AgentAudit: An Open, Extensible Framework for Full-Lifecycle Trust Evaluation of AI Agents** — Nag, Sachita, Singh, Goel, Janwar · https://arxiv.org/abs/2609.09875
  AgentAudit scores an agent's entire execution trace across ten dimensions — instruction integrity, planner, memory, tool selection, tool invocation, tool correctness, alignment, tool faithfulness, security, execution integrity — with failure attribution to the responsible stage. It attaches to any LLM agent by reading recorded traces only. Across nine capability and adversarial tasks, Claude Sonnet 5 and GPT-5 score highest (95.1 and 80.6), while several non-frontier models are repeatedly classified as Unsafe_Compliance rather than merely failing. **Why it matters:** Pass/fail benchmarks hide the difference between failing safely and complying unsafely; trace-level auditing surfaces it.

- **Causal Episodic Memory for Feedback-Driven Agent Repair** — Vo, Chu, Dinh, Bui, Quan · https://arxiv.org/abs/2608.05906
  MERIT is a training-free Text-to-SQL repair agent that keeps a dual-polarity memory of oracle-verified corrections and known-bad directions from earlier episodes. A deterministic failure-type classifier conditions a hybrid lexical-dense retriever before the frozen model revises. With Qwen2.5-7B it lifts execution accuracy from 66.34% to 69.79% on Spider and 47.35% to 48.44% on BIRD; negative memory helps only modestly and schema-local experience gives the most consistent gain. **Why it matters:** Honest evidence on when cross-episode repair memory helps and when it does not — schema-local, verified fixes are the reliable part.

- **Self-Evolving Embodied Agents via Skill-Harness Evolution** — Wang, Ma, Chang, Luo, Zhang et al. · https://arxiv.org/abs/2608.11350
  SHAPER keeps the foundation model frozen and instead evolves the non-parametric parts of an embodied agent — reusable skills and a context-code harness — through rollouts in the target environment. The same frozen model serves as planner and optimizer of its own skills and harness. Evaluated on VLABench and ESI-Bench against pure execution, SFT, and test-time-scaling baselines. **Why it matters:** Harness-and-skill evolution is a training-free adaptation path when fine-tuning is unavailable or too expensive.

- **Evaluating Memory Structure in LLM Agents** — Shutova, Olenina, Vinogradov, Sinitsin · https://arxiv.org/abs/2602.11243
  StructMemEval benchmarks whether agents can organize long-term memory into structures — ledgers, to-do lists, trees — rather than only recall facts. Simple retrieval-augmented LLMs struggle; memory agents solve the tasks reliably when prompted how to organize memory, but modern LLMs often fail to recognize the needed structure unprompted. **Why it matters:** Memory frameworks are being judged on recall, while the real gap is unprompted structure selection.

- **OpenResearcher: A Fully Open Pipeline for Long-Horizon Deep Research Trajectory Synthesis** — Li, Jiang, Ma, Zhang, Nie et al. · https://arxiv.org/abs/2603.20278
  OpenResearcher runs the search-and-browse loop fully offline with three primitives (search, open, find) over a 15M-document corpus, removing dependence on proprietary web APIs. Using GPT-OSS-120B as teacher it synthesizes 97K+ trajectories including a long tail with 100+ tool calls; SFT on a 30B-A3B backbone reaches 54.8% on BrowseComp-Plus (+34.0 points). Pipeline, trajectories, checkpoints, and the offline environment are released. **Why it matters:** A reproducible, instrumented environment for training deep-research agents that anyone can run.

- **OpenDiscoveryTrace: Process Traces for Evaluating AI Scientist Workflows** — Bansal, Balaji · https://arxiv.org/abs/2609.09203
  A public dataset of 558 complete AI-scientist agent trajectories over 124 tasks in drug discovery, materials, genomics, and literature analysis, with a 9-field-per-step trace (thoughts, tool calls, observations, errors, revision triggers, confidence). Frontier models reach similar success (84–89%), yet Claude Opus 4.6 logs 30× more errors than GPT-5.4 with a different profile (tool misuse vs reasoning errors). **Why it matters:** Output-only evals hide behavioral differences between models that process traces expose.

- **What Should an Agent Forget? Separating What Is Stored from What Is Used** — Li, Li · https://arxiv.org/abs/2609.10263
  RD-Forget keeps a full source archive but builds a query-conditioned memory view that controls which observations influence each answer. A frozen curator groups facts into semantic slots, suppresses superseded values for current-state questions, and re-enables them for historical queries, guided by a rate-distortion budget. Removing forgetting or query conditioning causes the largest score deficits across conversational memory, knowledge updating, and personalization tasks. **Why it matters:** Separates storage from use so agents can hold contradictory-over-time facts without misleading themselves.

- **Palmyra x6 Technical Report: An Agentic, Tool-Use Model Post-Trained via Anchored Supervised Fine-Tuning** — Du, Kamble, Vasudev, Yang et al. (Writer) · https://arxiv.org/abs/2608.16620
  Palmyra x6 post-trains an MoE base with Anchored SFT on only 626 verified synthetic tool-use trajectories — one epoch, low LR, KL anchor to the frozen base, Muon + Adam hybrid. It scores 0.785 on BFCL Core (highest in its cohort) and the best six-benchmark mean. **Why it matters:** A tiny, conservative post-training recipe can yield a top tool-use model — data quality and anchoring beat volume.

- **Benchmark Radar: A Living Database and Search Engine for AI Benchmarks and Evaluation** — Wu, Zhou, Shang, Wang, Han et al. · https://arxiv.org/abs/2609.11115
  Benchmark Radar continuously discovers benchmark papers, repos, datasets, and releases from 37 sources into a searchable catalog (1,283 records, 12,916 numeric observations on 790 records) with score histories and citations. It ships a dashboard with leaderboards, a score-vs-usage Pareto view, saturation trends, and a CLI for offline queries. **Why it matters:** A maintained index of agentic and tool-use benchmarks makes prior-art search and saturation checks routine.

- **Belief-State Engine: Augmenting LLMs for Principled Planning Under Partial Observability** — Chattopadhayay, Halder · https://arxiv.org/abs/2609.10036
  LLM agents under partial observability commit prematurely and drift as history grows because they are history-conditioned policies with no explicit belief. The Belief-State Engine sits outside the LLM, maintains a Bayesian posterior over POMDP latent states, and exposes only that posterior — never the raw log — making the LLM a sound Markov policy on the belief MDP. On Tiger and a red-team attack-graph task it beats reactive, CoT, ReAct, natural-language belief tracking, QMDP, and POMCP on return, calibration, and consistency. **Why it matters:** A principled fix for a common agent failure mode — hide the history, hand the model a belief.
