## 📄 Research Papers — Top Picks
- **HANDBOOK.md: A Benchmark for Long-Context Agentic Instruction Following** — Panavas, Minus, Monton et al. · https://arxiv.org/abs/2607.25398
  Agents are increasingly deployed with a standing policy document — a system prompt, policy file, or skills doc — trusted to govern every subsequent action. HANDBOOK.md is a 65-task benchmark modeled on employees following company handbooks: each task drops an agent into a self-contained company environment (file workspace with mock email, chat, calendar, issue tracking, commerce) exposed over MCP, governed by an expert-written handbook. It measures whether a long binding document actually constrains behavior over an extended tool-use horizon, not just whether the task completes. **Why it matters:** Directly tests the deployment pattern most production agents use — long policy/skills docs in context — where existing benchmarks are silent.

- **Diagnosing Tool-Selection Reasoning in LLM Agents with Canary Tools** — Atul Anand, Sourav Chattaraj · https://arxiv.org/abs/2608.04719
  Canary tools are diagnostic probes planted in an agent's MCP tool set, each engineered to trigger one specific tool-selection weakness. A six-type taxonomy (semantic decoys, parameter traps, capability mirages, prerequisite blindness, temporal decoys, granularity traps) converts a single "wrong tool" outcome into a multi-dimensional profile of how a model reasons about tools. Eight models across three capability tiers were run on 120 tasks under three canary densities and three seeds (8,640 runs) plus a 2,880-run subtlety ablation, graded by independent judges (Cohen's κ = 0.75). **Why it matters:** Turns opaque tool-selection failures into actionable diagnostics you can run against your own MCP server before shipping it.

- **A Survey of Agent Memory in the Second Half: Towards Self-Evolving and Long-Horizon Agents** — Huang, Zhang, Liang et al. · https://arxiv.org/abs/2602.06052
  Surveys the memory literature that exploded in 2025, framed around the "second half" of AI research where the bottleneck is real utility in long-horizon, dynamic, user-dependent settings — agentic coding, deep research, computer use. It argues memory is the substrate through which agents self-evolve: short-term memory gates which experiences are perceived and abstracted during execution, while long-term memory governs what accumulates and is selectively reused across extended interactions. Organizes hundreds of papers around the context-explosion problem beyond fixed windows. **Why it matters:** The best current map of the agent-memory design space if you're building persistent agents.

- **MemoryCPT: An End-to-End Agent Memory Framework for Cost-Performance Trade-off** — Lei, Ouyang, Ruan et al. · https://arxiv.org/abs/2608.04843
  Existing memory pipelines lean on hand-crafted heuristics and repeated LLM calls, injecting redundant context at high inference cost. MemoryCPT is end-to-end trainable across offline memory construction and online query-conditioned context generation. Query-agnostic Distillation compresses a modular memory-construction pipeline into a compact model via explicit reasoning traces; Query-aware Retrieval and Summarization then fuses reciprocal rank fusion with a LoRA summarizer trained by GRPO under a cost-aware reward. **Why it matters:** Makes the memory layer's token cost an explicitly optimized objective rather than an afterthought.

- **Skills Know Their Neighbors: Cluster-Contrastive Capability Pages for Skill Retrieval** — Wang, Wen, Ji, Qiao · https://arxiv.org/abs/2608.04482
  As skill libraries grow, agents must pick among candidates that share topic and vocabulary but implement different capabilities. The paper formalizes a skill's capability as its *executable region* — the set of queries it can solve — and treats its document as a lossy observation of that region, exposing retrieval error caused by the document itself and unfixable by a better retriever alone. Capability Pages are cluster-contrastive skill representations with a positive trigger, a negative boundary, and a discriminative body, built offline. **Why it matters:** Explains why skill descriptions, not embeddings, are the real bottleneck in large skill/tool libraries.

- **SpecBox: Speculative Sandbox Scheduling for Efficient LLM Agent Serving** — Zhang, Wo, Wang et al. (Beihang) · https://arxiv.org/abs/2607.23933
  Agents invoking isolated sandboxes over MCP face a dilemma: persistent long-lived reservations waste memory at scale, while lazy on-demand instantiation incurs cold-start penalties that wreck tail latency under multi-tenant, multi-turn loads. SpecBox speculatively preallocates sandboxes, using keyword matching plus streaming semantic embedding to detect pending tool-execution demand mid-token-generation and overlap warm-up with inference. **Why it matters:** Serving-side engineering for MCP tool execution — the cost center nobody budgets for until agents hit production traffic.

- **Architectural Implications of Agentic AI Workflows** — Yang, Liu, Zhang, Stojkovic · https://arxiv.org/abs/2608.04458
  First architectural characterization of agentic workloads, combining a production study at Microsoft Azure with a controlled study of open-source frameworks. Requests fan out into LLM inferences, tool invocations, and orchestration decisions that repeatedly cross the CPU–GPU boundary; because orchestration and tools run on the host, the CPU sits on the critical path. Load stays low with sudden spikes, and model composition determines how evenly GPUs are used, with task/tool diversity widening the range further. **Why it matters:** Hard production data that agent serving is a CPU-and-scheduling problem as much as a GPU problem.

- **Hierarchical Graph Memory for LLM Agents with Path-level Localization and Rewrite** — Yue, Wang, Zhang, Zheng, Zhang · https://arxiv.org/abs/2608.05095
  Graph memory gives structure for multi-hop retrieval, but flat graphs accumulate irrelevant history that inflates evidence-selection cost, and unit-wise updates force repeated rewrites to cover related changes. HiGram organizes memory coarse-to-fine and localizes both retrieval and rewriting at the path level, so a single update propagates across related memories instead of being redone unit by unit. **Why it matters:** Attacks the update cost of graph memory, which is where long-running agent memory systems usually degrade.

- **Behavioral Skill Reconstruction: Reconstructing Hidden Functionality from LLM Agent Skills** — Hua, Xu, Li · https://arxiv.org/abs/2608.04192
  Closed-source agent skills bundle proprietary instructions, scripts, constants, and data that providers expose as a service while hiding the package. Prior work and defenses target prompt injection that leaks those files — but preventing file disclosure does not prevent a user from recovering the functionality they implement. SkillClone is a black-box attack that builds a functional clone of a hidden skill from valid task requests and observed responses alone. **Why it matters:** If you monetize hidden skills, file-level secrecy is not a moat.

- **InsightEmb: Learning Action-Intent Embeddings for Agentic Insight Retrieval** — Chung, Li, Zhou, Yu · https://arxiv.org/abs/2608.04761
  Self-improving agents accumulate reusable insights from prior trajectories, so retrieval decides whether that experience becomes actionable guidance at each decision step. Existing retrievers model semantic similarity and ignore whether a retrieved insight resolves the agent's current decision bottleneck. InsightEmb is a contrastive embedding framework that learns transferable progress-oriented retrieval geometry from mathematical reasoning data alone, aligning concrete situations with abstract heuristic rules and clustering trajectories with similar progress structure. **Why it matters:** Retrieval for self-improving agents should be scored on unblocking the next decision, not on topical match.

- **Argus: A General-Purpose Agentic Runtime for Long-Horizon Reasoning** — Li, Wen, Fan et al. · https://arxiv.org/abs/2608.05144
  Argus is a persistent, self-evolving runtime in which Manager, Planner, Engineer, and Reviewer roles execute bounded missions over durable project state. It separates stable user intent from operational objectives, constraints, and verification criteria, and admits memories, skills, procedures, verifiers, routing decisions, and rejected routes into that state only after role-owned review plus task-native verification where available. Model weights stay fixed — self-evolution happens purely through runtime state and control policy, with autonomous execution between operator-owned escalation points. **Why it matters:** A concrete design for agent self-improvement that needs no training run and keeps a human escalation boundary.

- **ToolArtist: Tool-Using Unified Multimodal Models for Agentic Image Generation** — Zhao, Yu, Sun et al. · https://huggingface.co/papers/2608.04436
  Prior agentic image-generation work either prescribes a fixed workflow or places only part of the pipeline under agent control, so reasoning, tool invocation, and generation are never coordinated by a single policy. ToolArtist post-trains a Unified Multimodal Model into a fully agentic generator that dynamically orchestrates reasoning, external tool use, and native image generation under one policy, with SFT trajectories produced by a teacher agent equipped with search plus an image-generation tool. **Why it matters:** Moves multimodal generation from fixed pipelines to one policy that decides when to search versus when to draw.

- **K-EXAONE 2.0 Technical Report** — LG AI Research · https://huggingface.co/papers/2608.04505
  An open-weight multilingual foundation model built by upcycling K-EXAONE rather than training from scratch, expanded into a Mixture-of-Experts with 750B total parameters and ~37B activated per token — over 3× its predecessor's capacity. It supports context up to 256K tokens and grows multilingual coverage from six to ten languages. Training combines continual pre-training, difficulty-focused mid-training, and post-training aimed at reasoning, agentic coding, multilingual capability, and safety grounded in Korean sociocultural context. **Why it matters:** A serious open-weight MoE at frontier scale with agentic coding as an explicit training target.

- **AutoProteinEngine: An LLM-Driven Agent Framework for Multimodal AutoML in Protein Engineering** — Liu, Chen, Wang, Shen · https://arxiv.org/abs/2411.04440
  Deep learning shows promise in protein engineering but stays out of reach for biologists without computational backgrounds. AutoPE lets them drive DL models through natural language, integrating LLMs with AutoML to handle model selection across both protein sequence and graph modalities plus automatic hyperparameter optimization. **Why it matters:** A clean template for using an agent as the natural-language front end to a complex domain-specific ML stack.

- **MOON3.0: Reasoning-aware Multimodal Representation Learning for E-commerce Product Understanding** — Wu, Fu, Nie et al. · https://arxiv.org/abs/2604.00513
  Multimodal LLMs are typically used as feature extractors that implicitly squash product information into global embeddings, losing fine-grained attributes. MOON3.0 instead leverages the MLLM's reasoning ability to explicitly model those attributes, working around two obstacles: long-context reasoning diluting attention to salient input, and SFT encouraging rigid response patterns. **Why it matters:** Argues representation learning should route through explicit reasoning rather than implicit pooling.
