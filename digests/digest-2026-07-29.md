## 📄 Research Papers — Top Picks
- **HANDBOOK.md: A Benchmark for Long-Context Agentic Instruction Following** — Panavas, Minus, Monton et al. · https://arxiv.org/abs/2607.25398
  Existing agent benchmarks measure whether a task gets completed, not whether a long binding policy document actually constrains behavior over a long tool-use horizon. HANDBOOK.md gives 65 agentic tasks in self-contained company environments — file workspace plus mock email, chat, calendar, issue tracking, and commerce exposed over MCP — each governed by a company-handbook-style policy file. The setup directly mirrors how system prompts, policy files, and skills documents are deployed in practice. **Why it matters:** The first benchmark aimed squarely at the "does the agent actually obey its skills/policy file" question that every production agent deployment depends on.

- **VLD-RAG: Agentic Vision-Language Retrieval-Augmented Generation for Long, Visually-Rich Multi-Page Documents** — Seonok Kim · https://arxiv.org/abs/2607.24748
  VLD-RAG targets QA over reports, slides, and manuals where evidence is scattered across pages and mixes text with tables, charts, and layout cues. It builds a page-preserving multimodal index storing parsed text, page metadata, and dense visual representations, then uses hybrid sparse + dense retrieval with an agentic loop for cross-page reasoning. Retrieval must pick evidence pages carrying both textual and visual signal, not just text matches. **Why it matters:** Enterprise document QA is mostly visually-rich PDFs; text-only RAG silently drops the figures and tables that hold the answer.

- **SearchArt: Training Long-Horizon Search Agents with Scalable Synthetic and Verified Tasks** — Mei, Yu, Chen et al. · https://arxiv.org/abs/2607.24850
  Training search agents is bottlenecked by the scarcity of genuinely long-horizon tasks and by the difficulty of grading intermediate reasoning and tool-use steps. SearchArt synthesizes complex search, research, and user-oriented QA pairs together with search trajectories from web documents, verifying them automatically, then runs a multi-stage post-training pipeline over that data. The emphasis is on verification-driven synthesis so intermediate steps carry usable signal. **Why it matters:** Data, not architecture, is the current ceiling on deep-research agents — a scalable verified-trajectory recipe attacks the real bottleneck.

- **ProcAgent: An Agentic Framework for Procedural Task Guidance on Edge with Human-in-the-Loop** — Zahid, Biswas, Islam, Swaminathan · https://arxiv.org/abs/2607.24770
  ProcAgent runs a fully on-device vision-based procedural assistant (furniture assembly, home repair) on a single Jetson AGX Orin, avoiding the cloud inference and always-on perception of prior multimodal assistants. It uses a propose-and-verify architecture combining low-latency continuous perception, a symbolic task graph, and on-demand heavier reasoning, with a human in the loop for recovery. **Why it matters:** Shows a credible pattern for privacy-sensitive, latency-critical agents: cheap always-on perception gated by expensive on-demand reasoning.

- **HiSkill: Empowering LLM Agents with Hierarchical Skill Graphs** — Hao, Cai, Zhang et al. · https://arxiv.org/abs/2607.25853
  Trajectory-to-skill methods typically produce a flat pile of high-level textual skills stored and retrieved independently, leaving the relations between skills unused and the gap to executable actions unbridged. HiSkill organizes trajectories into a directed graph of skill nodes, AtomicOp nodes, and typed edges capturing decomposition, temporal transition, and composition. High-level reusable skills are wired to concrete executable action templates. **Why it matters:** Makes agent "skills" composable and grounded rather than a flat retrieval bag — closer to how skill libraries need to work at scale.

- **LazyMem: Retrieve Broadly, Construct Selectively for Efficient Long-Term Agent Memory** — Yu, Zhao, Zhang, Li · https://arxiv.org/abs/2607.22690
  Long-term agent memory faces a tension: broad recall floods reasoning with noise, while write-time compression irreversibly discards details future queries may need. LazyMem defers all memory construction to query time — a lightweight model processes a broadly retrieved candidate pool in overlapping parallel windows, keeping and compressing only what the current query needs. Nothing is thrown away at write time. **Why it matters:** Query-time-only memory construction sidesteps the irreversible-loss problem that plagues summarize-on-write memory systems.

- **From Naive RAG to Deep Agentic Retrieval: An Evolving Context Engineering Pipeline for Regulatory Compliance** — de Costa, Anwar, Mercier, Hammad · https://arxiv.org/abs/2607.24791
  A production retrospective from Ontario Power Generation's regulatory compliance and rate-case pipeline, tracing four successive stages: naive RAG, hybrid retrieval with re-ranking, agentic function-calling retrieval, and a deep multi-agent architecture with code-based tool synthesis and explicit planning. Each transition is motivated by concrete failure modes and tradeoffs observed at scale. **Why it matters:** Rare honest production war-story documenting *why* each RAG sophistication step was actually needed, instead of a benchmark table.

- **Hybrid Analysis for Secure MCP Tool Use in LLM Agents (MTGuard)** — He, Xie, Li, Ji · https://arxiv.org/abs/2607.25297
  MCP has become the de facto standard for connecting agents to external tools, and with it comes the risk of agents being induced into malicious or unauthorized actions. Prior defenses rely on static analysis of prompts and outputs, which the authors argue is too shallow and brittle. MTGuard proposes hybrid static + dynamic analysis of MCP tool use to catch what prompt inspection misses. **Why it matters:** MCP tool-call security is now a production concern, and prompt-level guardrails alone are demonstrably insufficient.

- **Addressable Recall Compaction for Long Context-Window Control in AI Agents (ARC)** — Dang, Ichikawa, Fatima, Shirahata · https://arxiv.org/abs/2607.25066
  Long-horizon agents accumulate traces, actions, and tool observations that overflow the context window; existing compaction discards, summarizes, or re-retrieves, all of which can lose task-critical detail. ARC separates archival storage from active-context presentation: tool observations go into an append-only ID-addressable log, and older observations are replaced by compact citations. The agent can later request stored content by ID without re-running the tool. **Why it matters:** Lossless, addressable compaction is a clean answer to context overflow that avoids the re-execution cost of tool replay.

- **UniMem: Complementary Episodic-to-Parametric Memory for Boundary-Agnostic Task Streams** — Xia, Zhang, Wu et al. · https://arxiv.org/abs/2607.26017
  Agents deployed on evolving task streams hit a stability–plasticity dilemma: retrieval memory absorbs new evidence fast but never internalizes recurring execution patterns and pays retrieval cost every call, while parametric memory is stable and cheap but needs explicit task boundaries. UniMem is a self-routing framework inspired by episodic storage plus gradual consolidation in the brain, moving knowledge from episodic to parametric over time. **Why it matters:** Points at the missing middle between RAG-style memory and fine-tuning for agents that run continuously.

- **A Control System, a Dataset, and a Recipe for Making Frozen LLM Agents Learn a Domain** — Debjyoti Paul · https://arxiv.org/abs/2607.25415
  Production agents are a frozen model wrapped in a harness — prompt template, tool set, memory layer, planning strategy, verification policy. Recent systems optimize or self-rewrite that harness via agentic proposers, at the cost of expensive code search or unauditable self-modifying code. This paper takes the narrow position: treat the harness as a small fixed human-legible action space and learn a policy over it online with classic sample-efficient RL. **Why it matters:** Auditable domain adaptation for black-box model APIs, with no fine-tuning and no self-modifying code.

- **RSMeM: Knowledge-Enhanced Memory Evolution for Remote Sensing Agents** — Wu, Zhang, Guo et al. · https://arxiv.org/abs/2607.24772
  Remote-sensing agents built on general-purpose LLMs are domain-agnostic and therefore brittle, and their failures are rarely consolidated into reusable experience. RSMeM bootstraps agents with pre-distilled domain knowledge via hierarchical taxonomy-aware retrieval, then iteratively folds online experience back into memory for robust multi-step tool execution. It ships with a systematic evaluation of the resulting agents. **Why it matters:** A concrete template for domain-specializing a general agent through memory rather than weights.

- **Distilling Temporal Search and Reasoning: Evolving LLMs for Future Prediction** — Cai, Chen, Zhu et al. · https://arxiv.org/abs/2607.25554
  Forecasting agents typically lose all predictive ability once their external harness is removed, and internalizing the skill is blocked by data: historical queries leak the answer, degrading forecasting into retrieval. The authors propose a time-truncation harness for efficient synthesis that avoids temporal leakage while retaining data that rejection sampling would discard. The goal is internalized temporal search and reasoning rather than harness-dependent performance. **Why it matters:** Temporal leakage is the core reason forecasting benchmarks overstate model ability — this attacks it at the data-synthesis layer.

- **Wonder: Video World Model Done Better** — Xu, Jiang, Shu et al. (HF Papers) · https://huggingface.co/papers/2607.26037
  Wonder is a general-purpose video world model supporting real-time camera-controllable exploration: from an image or conditional video it builds a playable world where users navigate, discover unseen regions, and revisit observed ones over a long horizon. Key pieces are a dense coordinate-field camera conditioning that renders spatially aligned motion cues as visual evidence, plus an efficient spatial memory for fast retrieval over a growing generation context. **Why it matters:** Long-horizon consistency plus real-time control is the bar interactive world models have to clear to be useful beyond demos.

- **Bekko Embedding: Parameter-Efficient Multilingual Retrieval with Ultra-Compact Encoders** — Yuichi Tateno · https://arxiv.org/abs/2607.25180
  bekko-embedding-v1-a8m has under 8M active (non-embedding) parameters yet scores 56.2 nDCG@10 on MMTEB Multilingual v2 Retrieval, above the multilingual-e5 family and BGE-M3 which carry ~40x the active parameters. The a25m variant reaches 57.5, on par with gte-multilingual-base, and is the strongest dense model in their long-input (NanoLongEmbed) comparison. Both handle 8192-token inputs via a deliberately simple pruning-based recipe. **Why it matters:** Retrieval quality at this active-parameter budget makes on-device and high-QPS multilingual RAG substantially cheaper.
