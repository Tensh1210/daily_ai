## 🚀 Product & Breakthroughs
- **The components of agent memory** — Anthropic Engineering · https://www.anthropic.com/research/components-of-agent-memory
  Anthropic explains that for Claude to learn from experience, it has to decide what is worth remembering before it knows what comes next. The post describes how "dreaming" helps it organize memory and correct mistakes. **Why it matters:** treats memory as a selection problem under uncertainty, not just a storage problem, which is a core design question for long-running agents.
- **Measuring how AI agents handle everyday wet-lab science** — OpenAI · https://openai.com/index/measuring-how-ai-agents-handle-wet-lab-science
  OpenAI introduced BioBasicsBench, a 100-task benchmark. It measures how well AI agents interpret raw experimental data and handle everyday wet-lab science. **Why it matters:** targets routine lab work and raw data, rather than headline scientific feats.
- **Partnering with Hacktron to find vulnerabilities in OpenAI's systems** — OpenAI · https://openai.com/index/partnering-with-hacktron
  OpenAI is partnering with Hacktron to find vulnerabilities and test connections with third-party services. The work uses frontier AI to strengthen defenses. **Why it matters:** a frontier lab pointing AI-assisted security testing at its own systems, including third-party integrations.
- **Teaching AI to build scientific models** — Anthropic Research · https://www.anthropic.com/research/teaching-ai-to-build-scientific-models
  In a guest post, Jakob Macke, Daniel Gedon and Stefan Wahl discuss how AI is starting to change the scientific modeling process. They cover the path from construction to interpretation. **Why it matters:** looks at AI across the whole modeling workflow, including interpretation, not only model building.
