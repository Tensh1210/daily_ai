## 📄 Research Papers — Top Picks
- **TurnSight: Turn-Level Hindsight Self-Distillation for Tool-Integrated Reasoning** — Qu, Dai, Cai, Zhou, Chen, Xu · https://huggingface.co/papers/2608.04007
  Tool-integrated reasoning RL usually supervises whole trajectories, so credit assignment is coarse over long tool-calling horizons. TurnSight derives supervision from execution-conditioned hindsight — replaying what actually happened rather than from ground-truth answers or retrieved skills — and builds multiple hindsight views with different lookahead horizons, selecting reliable ones. Crucially it supervises at the turn level, matching the real structure of tool interactions instead of flat token-level signals. **Why it matters:** Turn-level credit is probably the missing granularity for training agents that call tools many times per task.

- **When Agents Learn to Be You: Benchmarking Privacy Leakage, Impersonation Risk, and Defenses in Persona Skills** — Xiang, Zhang, Yang, Hong, Feng, Xu, Liu · https://huggingface.co/papers/2608.03700
  Persona skills compress a user's interaction history into portable, executable artifacts an agent can reuse — which also concentrates scattered personal signals into one reusable object. AntiSkillBench supplies 7,500 persona-grounded dialogue traces from 50 rich profiles, measures skill-level privacy leakage plus agent-level attribute disclosure and behavioral impersonation across three distillation strategies, and evaluates four defense families. Existing per-record or retrieval-time defenses do not transfer to this pipeline. **Why it matters:** If you ship user-personalized skills, this is the first concrete way to measure what those artifacts leak.

- **SkillJack: Persistent Skill Backdoors in Self-Evolving Agents** — Ying, Wu, Wu, Zheng, Cheng, Shi, Guo · https://huggingface.co/papers/2608.03509
  Prior poisoning attacks only fire when the poisoned record is retrieved into context. SkillJack instead hijacks the experience-to-skill distillation step so malicious behavior is baked into the agent's durable, reusable skill library. The paper names three mechanics: sanitization whitewashing (intent hidden during extraction), cross-layer promotion (transient experience becomes persistent capability), and persistence beyond the original task. **Why it matters:** Self-improving agents that write their own skills need supply-chain review of those skills, not just prompt filtering.

- **Video-DeepResearch: Towards the Next-Generation Multimodal Deepresearch Agent** — Fang, Zeng, Huang, Zhao, Huang, Ren et al. · https://huggingface.co/papers/2608.03979
  Extends deep-research agents from static images to continuous video plus open-web exploration. It identifies two failure modes in current models — modality bias (agents skip visual tools and just text-search) and parametric knowledge leakage (answering from memory instead of tools) — and counters both with a decoupled perception-exploration pipeline that stage-gates tool unlocking so cross-frame grounding must happen before web retrieval. Training is SFT followed by GRPO. **Why it matters:** Names and fixes the "agent pretends to use tools" problem that quietly inflates multimodal agent benchmarks.

- **PATH-Bench: Path-Dependent Evaluation of Lifelong Agents** — Yang, Zhang, Li, Liu, Sheng, Hua et al. · https://arxiv.org/abs/2608.01149
  Lifelong agents accumulate memories and skills, but benchmarks rarely control for the order and content of that accumulated experience. PATH-Bench estimates directed task relationships via multi-model in-context learning, builds probe-centered sequences with deliberately helpful vs interfering histories, and measures average performance, forward and backward transfer, and forgetting. Eight agents are evaluated on single-turn code generation and multi-turn tool use. **Why it matters:** Shows agent scores depend heavily on which experiences arrived first — a confound most memory papers ignore.

- **SkillTrace: Traversing a Query-Skill Graph for Composable LLM Agents** — Yao, Wang, Chen, Zhang, He, Luo, Gedeon · https://arxiv.org/abs/2608.02356
  Retrieving individually relevant skills is not enough; agents need a complete, executable *composition*. SkillTrace models three levels in one graph — compositional relations among sub-queries, query-to-candidate similarity in the skill library, and dependencies among selected candidates — then decomposes the user query into a semantic hierarchy and propagates over dependencies. Reports 53.17% on SkillsBench and 91.43% on ALFWorld. **Why it matters:** A practical retrieval design for skill libraries once they grow past what a single prompt can list.

- **Cross-Benchmark Generalization in Long-Horizon Agents** — Mehta, Ritchie, Panavas, Chen · https://arxiv.org/abs/2608.00181
  Argues in-distribution holdouts can't distinguish real skill from exploiting environment regularities (tool schemas, grader parsing, task templates), so cross-benchmark transfer is the honest test. The authors post-train an open-weight MoE model on 363 long-horizon MCP tasks across 27 categories with a two-stage SFT-then-RL pipeline, deliberately keeping external benchmark tasks, graders, and scores out of training and reward. Evaluation then asks how the agent behaves elsewhere. **Why it matters:** A clean methodology for claiming an agent actually learned tool use rather than memorizing one harness.

- **Personalizing Large Language Model Agents with Small Policy Models** — Jin, Zhang, Li, Pan, Huang, Zhou · https://arxiv.org/abs/2608.00215
  Frames personalization of a frozen (possibly black-box) agent as online learning of a per-user execution policy from scalar feedback on the executed action only. FABLE is a lightweight bandit layer sitting outside the host agent that factorizes memory, information-acquisition, and response decisions so one piece of feedback updates all related choices, with actions filtered through an external constraint spec. No fine-tuning of the underlying LLM is required. **Why it matters:** Personalization for proprietary agents where you can't touch weights and prompts alone don't adapt behavior.

- **Hear, Invoke, and Understand: A Skill-Calling Multimodal Agent for Large Audio Language Models** — Wang, Zhang, Cai, Ren, Jiang, Wang et al. · https://arxiv.org/abs/2608.01881
  Treats hard acoustic questions as tool-interactive audio reasoning: the model must run audio operations and reason over processed-audio or textual observations instead of answering directly from a fixed clip. SpeechAgent-R is trained on HIU-Corpus (65,492 trajectories, 507.6 hours of audio, 24 tasks, 8 skills, 9 tools) via trajectory SFT then multi-turn RL, with HIU-Bench scoring both task success and interaction quality. **Why it matters:** Brings the tool-calling agent pattern to audio, where single-pass models hit a hard ceiling.

- **AiFlow: Token-Native Reactive Orchestration with Bounded Backpressure for Streaming LLM Applications** — Zhang · https://arxiv.org/abs/2608.00558
  Most frameworks expose provider token deltas but still treat generation as a coarse request-response step, leaving queueing, worker allocation, ordering, and backpressure to ad hoc callbacks. AiFlow normalizes provider deltas into typed Context events flowing through a directed streaming graph, where each node has a Guardian declaring queue bounds, concurrency, ordering, overflow policy, cancellation propagation, and retry discipline. It formalizes a bounded-memory property and compiles from a compact DSL/JSON graph. **Why it matters:** Real infrastructure semantics for streaming multi-agent apps that currently fall over under load.

- **Agentic Reinforcement Learning with Self-Distilled Reward Shaping** — Zhang, Chen, Lin, Xu, Zhang, Wang · https://arxiv.org/abs/2608.03223
  Sparse trajectory-level rewards tell you a run succeeded but not which turn deserved credit. ADRS uses a frozen policy snapshot conditioned on task-matched procedural skills to rescore tokens from skill-free trajectories, then centers and normalizes those privileged teacher scores across interaction steps and folds them into native reward-to-advantage construction. The point is calibrating teacher confidence against realized returns rather than trusting raw scores. **Why it matters:** Denser training signal for multi-turn agents without hand-labeled step rewards.

- **Training Documents Reranker with Search Rubrics for Deep Research Agent** — Liu, Lu, Xia, Xu, Zhao, Xi et al. · https://arxiv.org/abs/2608.03527
  Standard rerankers optimize per-document relevance, but a research agent needs the retrieved *set* to be diverse, concise, and authoritative together. The authors synthesize hierarchical search rubrics with a strong LLM that state explicitly what a good document set must satisfy for a given agent query, then train RubricRanker in two stages to select that subset. **Why it matters:** Set-level retrieval quality is the actual bottleneck for deep-research agents, not top-1 relevance.

- **Before Reasoning Can Fail: Pre-Evidence Procedural Failures in Agentic RAG** — Roh, Han · https://arxiv.org/abs/2608.02011
  Agentic RAG can fail before reasoning is even tested: the agent retrieves snippets, then finalizes without reading them. Using 12,000 paired trajectories on HotpotQA, 2WikiMultiHopQA, and MuSiQue, the authors separate pre-evidence discipline failures from post-gold-read failures and find them largely non-redundant (both-trigger rate 11.2–13.1%). Read-Gate, a minimal runtime invariant forcing a read between search and finalization, lifts LLM-Acc by 14.9–19.9 points on affected trajectories. **Why it matters:** A one-line runtime invariant recovers a large chunk of RAG-agent errors — cheapest fix on this list.

- **FRAMES: Guarded and Dual-Objective Skill Evolution for Agents in Policy-Governed Enterprise Workflows** — Wang, Shu, Dan, Xu, Luo, Mai, Wan · https://arxiv.org/abs/2608.01772
  Enterprise agents doing document auditing must apply rules consistently, ground every value, and stay auditable, yet operational feedback is sparse and unlabeled and fixing one rule regresses others. FRAMES cold-starts deployable skills from existing assets then evolves them via consensus-based mutation and Pareto selection over accuracy *and* cost, with an anti-regression guarantee. Reported deployed in an internal production system, with gains reproduced on tau-bench. **Why it matters:** One of the few skill-evolution papers with production constraints — cost, auditability, no regressions — baked into the objective.

- **Learning to Coordinate Symbolic Tools: LLM Agents for Verified Sum-of-Squares Certificates** — Chen, Patel, Hoffmann, Looi, Yu · https://arxiv.org/abs/2608.00326
  Weighted sum-of-squares decomposition is a nice agent testbed: candidates are exactly machine-checkable, but finding one means coordinating multiple symbolic transformations with non-unique regroupings. The agent is trained on 1.35M synthetic examples across eight supporting polynomial tasks plus weighted-SOS decomposition, combining algebraic task training, symbolic tools, and verifier-grounded optimization instead of training on the composite task alone. **Why it matters:** Verifier-grounded rewards plus decomposed sub-skills is a repeatable recipe wherever outputs can be checked exactly.
