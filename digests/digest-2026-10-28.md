## 📄 Research Papers — Top Picks
- **Log-To-Leak: Prompt Injection Attacks on Tool-Using LLM Agents via the Model Context Protocol** — Hu, Fan, Samyoun, Du · https://arxiv.org/abs/2610.36108
  The authors study a tool-poisoning attack in which malicious MCP tool metadata makes an agent issue an extra "logging" call after its legitimate work, leaking the user query, server name, server response and agent response. Across 18 model-server pairs the attack succeeds 62.6–100% of the time while barely changing task completion. Three tested defenses leave residual attack success above 55% on GitHub MCP with GPT-4o. **Why it matters:** A completed task does not mean the run was safe, so MCP hosts need their own authorization for secondary tool calls.
- **SWE-Skills-Bench: Do Agent Skills Actually Help in Real-World Software Engineering?** — Han et al. · https://arxiv.org/abs/2603.15401
  The benchmark pairs 98 public SWE agent skills with pinned real repositories and runs 3,920 with/without-skill evaluations across four agent-model setups. 92 of the 98 skills have no significant effect, and the average pass ratio moves only from 76.6% to 76.9%. Helpful skills supply procedures the agent would otherwise skip (up to +17.7 points), while harmful ones anchor the agent on their own templates. **Why it matters:** Skill libraries should be tested per skill before installing; most add context cost without helping.
- **OmniBrain-0: A Unified Agentic Model for Embodied Intelligence** — Xiaomi Embodied Intelligence Team et al. · https://arxiv.org/abs/2610.36013
  OmniBrain-0 is a lightweight embodied agent that handles manipulation and navigation through one shared decision model, covering planning, progress tracking and failure recovery. It is trained with embodied pretraining, domain-specialist distillation and multi-teacher on-policy distillation, plus a rubric-guided recursive self-improvement data flywheel. It performs strongly on LIBERO, RoboCasa, RoboTwin and R2R-CE at much lower inference cost than its closed teacher. **Why it matters:** It shows a way to fit frontier-agent behavior into a compact robot brain.
- **DocSkill: Skill-Integrated Agentic Reasoning for Multilingual Multi-Hop Document Question Answering** — Huang et al. · https://arxiv.org/abs/2610.36759
  DocSkill learns a skill-orchestration policy that decides when to select, revisit or skip document skills as evidence builds up. Training data comes from bounded MCTS over skill trajectories and is used for SFT and DPO. The paper also releases MMHop-DocBench (60K QA pairs, 10 languages), where DocSkill with Qwen3-VL-8B beats the best baseline by +5.5 accuracy and +6.3 F1. **Why it matters:** It gives a concrete recipe for learning skill orchestration instead of hand-scripting it.
- **Skill Dreaming: Evolving Repository Skills through Pull Request Streams** — Song et al. · https://arxiv.org/abs/2610.36188
  Skill Dreaming builds a repository-specific skill library from validated PRs and keeps refining it as new PRs land. The skills guide coding agents not only on features but also on tests, docs, compatibility and repository conventions, and the framework integrates CI and code execution. **Why it matters:** Agent skills that update themselves from PR history could stop skill libraries from going stale.
- **InfraDev: Can Coding Agents Develop AI Infrastructure, and How Can We Tell?** — Deng et al. · https://arxiv.org/abs/2610.36589
  InfraDev has 36 multi-file, multi-GPU tasks taken from real PRs to Megatron-LM, vLLM and verl, graded with synthesized hidden probes. The best of six frontier models resolves only 38.9% of tasks, the probes reject 32% of patches that pass all official tests, and turning the failure analysis into a skill adds +10.5% on Megatron-LM. **Why it matters:** Official tests overstate how well agents handle infrastructure code, so stricter grading is needed.
- **EMMA: Structured Episodic Memory for Multi-Agent Workflow Synthesis** — Niu, Liu, Yu, Klinkner · https://arxiv.org/abs/2610.35966
  EMMA treats a multi-agent system's configuration (routing, specialist prompts, per-step skills) as episodic memory. A reflector assigns each failure to the scope that owns its fix and proposes one bounded edit there. It is best on KramaBench, AppWorld and BBEH across five backbones, up to +32.5% over ACE, GEPA, EvoMAS and ADAS, with 17–38% fewer training tokens. **Why it matters:** Scoped, guarded self-edits make agent-system evolution more predictable than letting the backbone decide what to change.
- **Pretraining Knows What, Simulation Teaches How: Compositional Generalization in a Sim-Trained Robot Agent** — Pikus et al. · https://arxiv.org/abs/2610.35817
  ZAP teaches a 27B off-the-shelf VLM to control a robot through a simple tool harness, using SFT and GRPO on simulated tasks only. With zero real-world training data it reaches 96.7% real-world success, matching GPT-6 Astra in the same harness at 3x the speed and 1/17 the cost, and generalizes to an unseen embodiment. **Why it matters:** Robot control framed as tool-calling plus sim RL is a cheap path to real-world robot agents.
- **RouteDRAG: Learning to Route and Control Agentic Execution for Multimodal Document RAG** — Chen et al. · https://arxiv.org/abs/2610.36444
  The authors show that agentic RAG helps on some queries and hurts on others. RouteDRAG learns when to invoke the agent and how to control its tool use and stopping. It gains +3.47 points over shorter paths while sending only 79.3% of queries to the agent, and it also beats always-agent execution with fewer calls. **Why it matters:** Choosing per query whether to run an agent saves cost and can improve accuracy.
- **OA-RAG: Ontology-based Agentic RAG for Faithful LLM Reasoning** — Yang, Chen, Gao · https://arxiv.org/abs/2610.36335
  OA-RAG is an agent that combines formal ontology reasoning with LLM reasoning. For each answer it reports the ontology evidence used and a grounding level (entailed, supported, related or unrelated). It targets biomedical and healthcare QA, where answers must follow established knowledge. **Why it matters:** Explicit grounding labels make RAG answers auditable in high-stakes domains.
- **Nemotron-Labs-Diffusion-Uni: Elastic Self-Refining Unified Diffusion LLM with Cross-Paradigm On-Policy Distillation** — NVIDIA (Li, Ye, Heinrich et al.) · https://huggingface.co/papers/2610.36466
  NLD-Uni is a unified discrete diffusion LLM for both visual understanding and generation. It distills understanding from autoregressive VLMs and generation from flow models through cross-paradigm on-policy distillation. A progressive self-refining corruption process, replacing masking, lets it commit to tokens early and refine them later. **Why it matters:** It strengthens the case for diffusion LLMs as one backbone for multimodal understanding and generation.
- **PerceptRL: Making Visual Perception Rewardable in MLLMs from Answers to Interactions** — Guan et al. · https://arxiv.org/abs/2610.37471
  PerceptRL uses a multi-agent pipeline to mine verified perception errors from dense image captions and turn them into QA pairs with rule-based, verifiable rewards. This keeps perception improving during RL post-training. **Why it matters:** Perception errors cap the gains from reasoning RL, and this approach makes perception trainable with checkable rewards.
- **SpectRAG: Weighted Chunk Graphs for Token-Budgeted Context Selection in Multi-Hop Retrieval-Augmented Generation** — Sahinoglu et al. · https://arxiv.org/abs/2610.36991
  SpectRAG builds a weighted chunk graph whose edges encode semantic similarity, document adjacency, section hierarchy, shared entities and citations. It applies spectral relevance propagation over the graph and then selects context under a token budget for multi-hop RAG. **Why it matters:** It targets redundant and incomplete evidence, a common reason dense-retrieval RAG fails on multi-hop questions.
- **LM-DSB: A Lightweight Multi-agent System for Automated Daily Safety Bulletin Generation in Construction** — Zhao et al. · https://arxiv.org/abs/2610.36433
  LM-DSB uses planner, researcher and writer agents with RAG and a domain-fine-tuned local LLM to generate construction daily safety bulletins on consumer PCs. Writing these bulletins by hand takes 2–3 hours a day. **Why it matters:** It is a practical template for small, local multi-agent systems in regulated field work.
- **Benchmark Radar: A Living Database and Search Engine for AI Benchmarks and Evaluation** — Wu et al. · https://arxiv.org/abs/2609.11115
  Benchmark Radar is a continuously updated catalog and search engine for AI benchmarks covering LLM, agentic and tool-use, coding, reasoning and safety evaluations. It pulls from 37 sources daily and tracks score histories and model-card mentions with source citations. **Why it matters:** It makes it easier to find suitable agent and tool-use evals and check the settings behind reported scores.
