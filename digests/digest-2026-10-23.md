- **Donating Agent Skills to the Agentic AI Foundation** — Anthropic · https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation

## 📄 Research Papers — Top Picks
- **Is Complex Agentic Memory Always Needed? Naive RAG Is Stronger Than We Thought** — Zhengye Bao et al. · https://huggingface.co/papers/2610.30755
  The authors test Raw-RAG, plain dense retrieval plus reranking over raw conversation history, against complex agentic memory systems. It ranks first in six of seven benchmark-model settings across LoCoMo, LongMemEval, MEME and MemoryAgentBench, beating the strongest agentic memory system by 0.13–5.53 points. Analysis shows raw history's higher evidence coverage offsets lower utilization, and even full access to transformed memory stores trails raw evidence. **Why it matters:** Before building elaborate memory pipelines, benchmark against naive RAG over raw history; preserving raw information may matter more than restructuring it.
- **Can LLMs Improve Their Own Harness? A Controlled Study on ARC-AGI-3** — Jens Lehmann et al. · https://arxiv.org/abs/2610.30499
  Frontier models each build a complete ARC-AGI-3 task harness from a fixed coding bootstrap, play five development games, and revise their whole codebase twice; every version is scored on twenty held-out games. Across 27 lineages, performance spans zero to near-ceiling, but two revisions raise mean held-out RHAE by only 2.80 points (95% CI [-1.44, 7.35]). Development gains overstate held-out improvement, and cost reductions can hurt task performance. **Why it matters:** Self-improving harnesses are not yet reliable: models can write good scaffolds but their revisions don't generalize, so human steering still adds real headroom.
- **The Cost of Saying Hello: An Empirical Study of Handshake Overhead in AI Agent Communication Protocols** — Pranav Varshney · https://arxiv.org/abs/2610.30151
  The first phase-decomposed benchmark of handshake cost in MCP (2025 and 2026 eras), A2A and ACP, using official SDKs. Round trips dominate: a legacy MCP handshake takes three round trips and 230 ms at 50 ms RTT versus one round trip and 61 ms for A2A. When an LLM reads the counterpart's metadata, cost grows at 24–107 tokens per capability, so a 200-capability server consumes 11% of a 200k context before the task starts. **Why it matters:** Gives hard numbers for the latency and context tax of large MCP servers, and confirms why MCP's 2026 revision cut round trips.
- **MCP vs CLI for AI Agents: A Comparative Analysis of Tool Integration Strategies for Autonomous Systems** — Arun Malik et al. · https://arxiv.org/abs/2610.30157
  Compares CLI (agents running shell commands) and MCP (typed JSON-RPC tool access) across 14 dimensions, with security assessment against compliance frameworks and economic modeling. CLI wins on efficiency for single-user local workflows, while MCP covers needs CLI cannot: fine-grained access control, credential isolation, structured audit and multi-tenant governance. Progressive disclosure closes MCP's context-overhead gap, and the paper recommends a hybrid architecture. **Why it matters:** A practical framework for the CLI-vs-MCP choice: CLI for local dev speed, MCP where governance and credential isolation matter.
- **Automating Feature Flag Cleanup at Scale with Multi-Agent LLM Systems: An Industrial Experience at DoorDash** — Atharv Chandratre et al. · https://arxiv.org/abs/2610.31351
  DoorDash has over 56,000 feature flags across 623 repos, 1,659 of them stale, and manual cleanup takes 1–2 hours each. Their multi-agent LLM system queries live rollout data via MCP, processes Jira tickets and opens pull requests end to end. It produced engineer-approved removal PRs for 45 of 50 stale flags (90%), averaging $4.79 and 13.8 minutes per cleanup. **Why it matters:** A production case study with real cost and success numbers for agent-driven tech-debt cleanup.
- **SCOPE: Compiling Natural-Language Policies into Neurosymbolic Predicate Programs** — Arnon Mazza et al. · https://huggingface.co/papers/2610.31062
  SCOPE compiles a natural-language agent policy into an executable program of neural predicates run by small models, deterministic extractors and composing code. The program is optimized jointly with its training data by adversarially generating counterexamples where it deviates from the policy. It achieves the highest average accuracy against prompt-optimization, decomposition and workflow-generation baselines, transfers across models, and reaches frontier-level accuracy on cheap models with more stable, interpretable verdicts. **Why it matters:** A cheaper and more auditable alternative to LLM-as-judge guardrails for compound policies over tool-call trajectories.
- **Adaptive Skill Granularity for Coding Agents: Runtime Routing and Macro-to-Micro Recovery** — Dingxuan Zhang et al. · https://arxiv.org/abs/2610.31461
  Treats skill granularity in coding agents as a runtime policy: a task can be solved with primitive tool calls, macro skills, or a macro that falls back to micro-level recovery. A feature-based granularity controller plus a finite-state recovery executor are evaluated under a deterministic, verifier-scored protocol. Fixed macro execution is efficient when it fits but brittle under mismatch, while runtime routing and macro-to-micro recovery fix failures fixed-granularity execution leaves unresolved. **Why it matters:** Skill libraries should be controllable and recoverable execution units, not just retrievable documents.
- **Separate Field Scoring Protects Unused Tools When Agents Pool Tool-Use Experience** — Abhijit Chakraborty · https://arxiv.org/abs/2610.30867
  When agents pool tool-usage examples into a shared retrieval index, adding them as extra entries boosts used tools but sharply lowers Hit@5 for held-out tools with no usage. SYNAPSE scores usage as a separate field, which keeps held-out tools visible (0.785 vs 0.683 Hit@5 against a slot-reserving router on StableToolBench) across three catalogs and two embedders. Pooling across ten agents helps exactly as much as giving one agent the same records. **Why it matters:** Naively mixing usage logs into a tool index buries new tools; score usage separately.
- **AgentPhishing: A Benchmark of LLM Email Agents Under Adaptive Attack** — Justin Tan et al. · https://arxiv.org/abs/2610.31404
  AgentPhishing benchmarks whether persuasive phishing can evade detection and get LLM email agents to comply with malicious requests. PhishOpt optimizes reusable email-generation skills against each agent under realism constraints, and Cialdini-based analysis yields a universal attack skill. Agents handle existing phishing datasets safely, but four of nine agents show detection below 10% and compliance above 45% against adapted attacks. **Why it matters:** Passing conventional phishing tests says little about how an email agent behaves under adaptive, agent-targeted persuasion.
- **Beyond Watching and Searching: Benchmarking Agents for Video-centered Deep Research Reports** — Jiahao Meng et al. · https://huggingface.co/papers/2610.31158
  Introduces video-centered deep research: given a video and a request, an agent forms research questions, retrieves external multimodal evidence and writes an interactive report linked to video moments. OmniDR-Bench has 50 Chinese and English tasks with 6,414 atomic rubric criteria built via audited rubric construction. Across 18 agent configurations the best scores 63.3/100, with gaps in coverage, cross-modal causal analysis and citation accuracy. **Why it matters:** Extends deep-research agents to video as the anchor source, with a rubric-based benchmark and released code.
- **AgentVQA: A Unified Benchmark for Agentic Visual Understanding** — Advait Gupta et al. · https://huggingface.co/papers/2610.31494
  AgentVQA is an offline VQA benchmark of 1,000 hand-picked agent scenarios from 23 datasets across web agents, robotics, egocentric video, games and spatial planning. Its model rankings track online evaluations. The best of 22 VLMs reaches only 58.5%, with errors driven mainly by failures to ground and track visual state (UI localization, motion, state changes, 3D relations) rather than reasoning. **Why it matters:** A cheap offline proxy for agentic VLM evaluation that points to visual-state grounding as the main bottleneck.
- **Agentic Knowledge-Model Co-Evolution via Consistency Regularization** — Sirui Chen et al. · https://arxiv.org/abs/2610.30790
  SPLICE co-evolves external knowledge (skills, memories) and model weights. It analyzes the same experience in several perturbed ways and keeps knowledge updates with consistent utility gains across views, then internalizes it via self-distillation alongside RL, using consistently harmful knowledge as a contrastive reference. It beats knowledge-evolution and training baselines by up to 7.1 and 4.6 points and cuts output tokens per correct solution by up to 44%. **Why it matters:** Consistency across views is a cheap filter for which self-generated skills are actually useful.
- **Why Bother Me Again? Benchmarking Personal Agent Memory for Interaction Preferences** — Jialin Li et al. · https://arxiv.org/abs/2610.30485
  MemPABench tests whether personal agents remember how users want to be assisted: when to clarify, confirm or act. Four simulated users hold 14 preferences across 99 sessions over four months with event-driven changes. Retrieval-based memory (Mem0, MemOS, simple RAG) does not beat no memory; file-based memory helps but over-applies preferences, and agents struggle to override default habits even with the right preference in context. **Why it matters:** Interaction-preference memory is largely unsolved, even with file-based memory.
- **Certified Execution Harness for Agentic AI: Safe and Least-Intrusive Petri-Net Supervisory Control Between Reasoning and Action** — Chao Gu et al. · https://arxiv.org/abs/2610.31376
  Formalizes the execution harness between an LLM and its tools as Petri-net supervisory control, where tokens represent capabilities, approvals and budgets. An injected request whose preconditions are unmet or spent is refused regardless of wording. The paper characterizes a least-intrusive safe supervisor for a replanning loop where retries cost inference, and applies it to an autonomous release agent. **Why it matters:** A formal, wording-independent defense against prompt injection at the tool-execution layer.
- **ReflectPO: Reflection-Guided Policy Optimization for Long-Horizon LLM Agents** — Rumei Li et al. · https://arxiv.org/abs/2610.30933
  ReflectPO is an RL framework for error recovery in long-horizon tool-use tasks. Reflection-guided sampling builds recovery hints from branch differences and repeated visits, and tree-structured credit assignment scores actions by parent-child reward differences and recovery gains. It beats baselines in most domains of two long-horizon benchmarks and improves agents' ability to notice and recover from their own deviations. **Why it matters:** Targets compounding early errors, a main failure mode of long-horizon agents.
