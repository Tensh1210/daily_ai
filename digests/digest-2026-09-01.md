## 📄 Research Papers — Top Picks
- **SHERLOC: Structured Diagnostic Localization for Code Repair Agents** — Tamoyan, Narenthiran, Arakelyan, Mezini, Ginsburg · https://arxiv.org/abs/2606.24820
  Repo-level coding agents burn roughly half their budget just locating the fault before editing. SHERLOC is a training-free framework pairing a reasoning LLM with compact repository tools and a self-recovery loop, producing diagnostic context rather than bare file paths. It reports 84.33% accuracy@1 on SWE-Bench Lite and 81.27% recall@1 on SWE-Bench Verified, without fine-tuning or multi-agent orchestration. **Why it matters:** Cheap localization wins translate directly into lower token cost and higher patch rates for any SWE-agent stack.
- **MM-BrowseComp: A Comprehensive Benchmark for Multimodal Browsing Agents** — Li, Bu, Wang, Liu et al. · https://arxiv.org/abs/2508.13186
  Existing browsing benchmarks are text-only, ignoring that much of the web's evidence lives in images and video. MM-BrowseComp adds 400 hand-crafted questions requiring extraction of key evidence from web images and videos, making text-only pipelines insufficient. Each question ships with a verified checklist for fine-grained scoring. **Why it matters:** If your deep-research agent strips images before reasoning, this benchmark quantifies exactly how much you are losing.
- **PA3: Policy-Aware Agent Alignment through Chain-of-Thought** — Roy Dipta, Bis, Zhou, Wang et al. · https://arxiv.org/abs/2603.14602
  Stuffing every business rule into context is slow, expensive, and triggers needle-in-a-haystack degradation. PA3 is a multi-stage alignment method that trains models to recall and apply the relevant policies during chain-of-thought at inference, instead of carrying the full policy text in-context. It introduces a Policy Recall reward based on Jaccard overlap of the recalled rules. **Why it matters:** A practical path to policy-compliant assistants that does not scale prompt length with your rulebook.
- **S3C-LLM: Skill-Code Guided Agentic Language Models for Spectrum-to-Structure Elucidation** — Zhao, Cai, Cheng, Xu · https://arxiv.org/abs/2608.30910
  Rather than mapping spectra directly to SMILES, S3C-LLM retrieves modality-specific spectroscopy skills, executes analysis code to instantiate them on the input spectra, and integrates the results. This mirrors how spectroscopists actually work: diagnostic peak interpretation, fragment reasoning, formula constraints, consistency checks. The skill-plus-code grounding replaces opaque end-to-end generation. **Why it matters:** A clean template for turning domain expertise into retrievable, executable agent skills instead of prompt prose.
- **Beyond NL2Code: A Structured Survey of Multimodal Code Intelligence** — Zhao, Sun, Xiao, Liu et al. · https://arxiv.org/abs/2606.15932
  Many real programming tasks specify intent visually — screenshots, charts, videos — not in text. This survey organizes multimodal code intelligence by the role code plays: rendered artifact, editable structure, intermediate reasoning trace, or executable program. It covers generation, editing, refinement, and reasoning under visually grounded inputs and outputs. **Why it matters:** The map to consult before building any screenshot-to-UI or chart-to-code feature.
- **SciOrch: Learning to Orchestrate Expert LLMs for Frontier Multimodal Scientific Reasoning** — Guo, Xue, Zhang, Xu et al. · https://arxiv.org/abs/2606.15872
  Frontier models are strongly complementary — different models win on different question types — which single-model evaluation hides. SciOrch trains a lightweight 8B orchestrator that decomposes a question, delegates sub-problems to selected commercial models via API, and synthesizes the answer. Training it is harder than standard agentic RL because every action is an expensive external call. **Why it matters:** Small-model routing over expensive frontier APIs is the cost-control pattern most production stacks will need.
- **Are Online Skill and Memory Modules Always Worth Their Tokens?** — Hajimiri, Aminbeidokhti, Dolz, Ben Ayed et al. · https://arxiv.org/abs/2606.15017
  Memory, workflow, and skill modules for web agents consume test-time tokens that are rarely reported next to actor inference cost. Under a fixed total budget across four WebArena domains and three models, a token-matched vanilla baseline matched or beat AWM, ASI, and ReasoningBank on aggregate success rate, often using fewer tokens. The gains attributed to augmentation largely disappear once you pay for them honestly. **Why it matters:** Strong evidence to budget-test your memory layer before assuming it earns its keep.
- **Breaking MCP with Function Hijacking Attacks** — Belkhiter, Zizzo, Maffeis, Tirupathi, Kelleher · https://arxiv.org/abs/2604.20994
  The paper introduces a function hijacking attack class targeting the tool-calling interface of agentic models and MCP servers. Beyond prompt injection, the function-calling surface enables data tampering and theft, disruptive endless loops, and jailbreak-style harmful output. It positions the tool schema itself as the attack vector. **Why it matters:** Anyone exposing MCP tools to untrusted content needs a threat model at the function boundary, not just the prompt.
- **Skill-as-Pseudocode: Refactoring Skill Libraries to Pseudocode for LLM Agents** — Li, Zang, Cao, Sun · https://arxiv.org/abs/2605.27955
  Markdown skill libraries ship as free-form prose, so agents re-derive input schema and invocation syntax on every retrieval, causing a confused → re-retrieve → still-confused loop. SaP automatically converts skill markdown into typed pseudocode contracts, filtered by a four-check deterministic verifier (coverage, binding, replacement, risk). Promoted contracts are inlined into a rewritten skill skeleton. **Why it matters:** Directly applicable to Claude-style skill libraries — typed contracts beat prose for reliable invocation.
- **WebXSkill: Skill Learning for Autonomous Web Agents** — Wang, Wu, Zhang, Zhang et al. · https://arxiv.org/abs/2604.13318
  Textual workflow skills give guidance but cannot execute; code skills execute but give no step-level guidance for recovery. WebXSkill pairs a parameterized action program with step-level natural-language guidance in a single executable skill. It mines reusable action subsequences from synthetic agent trajectories, then organizes and abstracts them into parameterized skills. **Why it matters:** A concrete answer to the grounding gap that makes long-horizon browser agents brittle.
- **EvoSkill Injection: Red-Teaming Autonomous Skill Generation in Self-Evolving Agents** — Kim, Kim, Eo, Yoon, Park · https://arxiv.org/abs/2608.30429
  Self-evolving agents that generate, refine, and reuse their own skills open a new attack surface: malicious capabilities can be written into the skill store and later reused as legitimate skills. The paper defines EvoSkill Injection as a threat model over that pipeline and proposes SARGE, a red-teaming framework targeting it. Persistence across sessions is what makes the attack severe. **Why it matters:** Skill memory is now a supply chain — treat writes to it as privileged operations.
- **SPADE: Self-Play in Adaptive Synthetic Executable Environments** — Liu, Yu, Jiang, Qu et al. · https://arxiv.org/abs/2608.19197
  Existing agent training environment pools are hand-curated or frozen, so the goal distribution stops scaling as the learner improves. In SPADE one LLM plays two roles: an Environment Designer that writes complete long-horizon environments as executable Gym-style reset()/step() code, and a Reasoning Agent that learns to act in them. Each environment is stateful and multi-turn with its own reward and verification code. **Why it matters:** Self-generated executable environments are a credible route past the scarcity of agentic RL training data.
- **AlgoWorlds: Benchmarking Tool Use for Global Optimization in Algorithmic Worlds** — Xu, Wang, Meng · https://arxiv.org/abs/2608.29397
  Tool-use benchmarks usually check only whether a workflow completed with valid arguments, but feasible is not the same as optimal in settings like route planning and fleet dispatch. AlgoWorlds converts formally specified combinatorial optimization problems into partially observed environments with verifiable global optima. Agents must turn tool-gathered information into globally optimal decisions. **Why it matters:** Shifts agent evaluation from "did it call the tool correctly" to "was the decision actually good".
- **Learning Simple Test-Time Environments for LLM Web Agents** — Li, Liu, Huang, Li et al. · https://arxiv.org/abs/2608.29305
  Web agents that look strong in curated environments often collapse in real-world settings. The authors add trial steps letting the agent decompose a complex environment observation into sub-modules, and propose TTED (Test-Time Environment Decomposition), a label-free method that adapts agent behavior from experience during inference. Adaptation happens at test time with no additional supervision. **Why it matters:** Test-time adaptation is a cheap lever for closing the sim-to-real gap in browser agents.
- **CAST: Critique-Aware Supervision for Training Reliable Long-Horizon Tool-Calling Agents** — Saeidi, Zhang, Singh, Ahuja et al. · https://huggingface.co/papers/2608.30147
  In stateful long-horizon settings a single wrong action — refunding the wrong purchase — can cause irreversible task failure and must be intercepted before execution. CAST replaces prompt-based critique agents with training on rich verification rationales, targeting reliability measured across repeated trials rather than single runs. It addresses why even frontier models struggle to explain what makes an action wrong. **Why it matters:** Pre-execution critique is the guardrail production tool-calling agents are still missing.
