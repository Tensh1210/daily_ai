## 📄 Research Papers — Top Picks
- **Tool-Calling LLM Agents Under Realistic MCP Faults: Scale Does Not Purchase Fault Tolerance** — Antonio Ken Iannillo et al. · https://arxiv.org/abs/2610.32555
  Introduces MCP-Injector, a protocol-aware fault-injection middleware for MCP tool calls whose fault model is calibrated on 57,240 issue/PR threads from 1,774 open-source MCP repos. Across 1,350 runs (gpt-oss 20B/120B, three agent stacks incl. OpenAI Agents SDK and LangChain), realistic faults cut task-completion scores by 60%, and the 120B model was no more fault-tolerant than the 20B. Agent stacks differed noticeably in how well they absorbed faults. **Why it matters:** Framework-level error handling, not model scale, is what makes tool-calling agents robust — test with fault injection, not just capability benchmarks.
- **When Agents Fail: Model or Harness--Who's to Blame?** — Shao Zhang et al. · https://arxiv.org/abs/2610.32483
  Proposes evaluating agent harnesses jointly with models via five measures (valid completion rate, model-harness fit, cross-model fit, interaction residuals, token load). Evaluates OpenCode, Codex CLI, Pi CLI and DeepAgents with four models over six benchmarks (52,168 trajectories). Harness rankings shift across models and benchmarks; OpenCode ranks first cross-model. **Why it matters:** Agent benchmark scores are model×harness properties — choose a harness per model, not from a single leaderboard.
- **SkillRep: Characterizing and Understanding the Representation Design Space of Agent Skill Retrieval** — Tianyi Sun et al. · https://arxiv.org/abs/2610.32336
  Maps the representation design space for retrieving agent skills from large libraries: encoder fine-tuning, query/document expansion, background projection and a lexical channel, combined in one retriever (SkillRep). With a 0.6B encoder plus LLM expansion it beats the best same-size retriever by 7–9 MRR@10 points on SRA-Bench and leads SkillsBench. It also shows which modules complement vs. compete for the same part of the request-skill gap. **Why it matters:** Practical guide for building skill/tool retrieval at scale — tells you which retrieval tricks stack and which are redundant.
- **LeafSkill: Efficient Leaf-Level Action Grounding for Recursive LLM Agents** — Shen Liu et al. · https://arxiv.org/abs/2610.32412
  Recursive LLM agents waste big-model calls translating familiar atomic subtasks into actions. LeafSkill adds an external skill layer that retrieves past grounding experience, binds action templates to current objects, and uses a frozen 1.7B selector to pick an action or defer to the main agent. On Robotouille it lifts completion from 60.5% to 68.5% vs. ReCAP while cutting host-model tokens ~14%. **Why it matters:** Cheap leaf-level skill reuse improves both success and cost without touching high-level planning.
- **Agentic AI Defense: Decode-Time Provenance Binding for MCP** — Eric Yocam et al. · https://arxiv.org/abs/2610.31974
  Demonstrates 'cross-modal trust laundering': prompt-injection instructions hidden in email-signature images (LSB/DCT/metadata steganography) bypass text scanners and enter MCP multi-agent workflows once a tool decodes them. Proposes decode-time provenance binding — HMAC-authenticated trust labels, an MCP provenance ledger and context-taint tracking that blocks critical tool calls influenced by untrusted content. Attack success drops from 100% (62.5% with keyword/regex filters) to 0%. **Why it matters:** Shows text-only injection filters are insufficient for MCP agents and offers a concrete provenance/taint design that works.
- **MCPHunt: An Evaluation Framework for Cross-Boundary Data Propagation in Multi-Server MCP Agents** — Haonan Li et al. · https://arxiv.org/abs/2604.27819
  MCPHunt is a controlled benchmark for non-adversarial credential propagation across multi-server MCP trust boundaries, using canary-based taint tracking and benign/hard-negative controls. Across 3,615 traces from 5 models and 147 tasks, policy-violating propagation (credentials leaked despite the option to redact) ranges 11.5–41.3% for every model. Leakage concentrates in browser-mediated data flows. **Why it matters:** Faithful tool composition alone leaks secrets across MCP servers — information-flow control is needed, not just a well-behaved model.
- **Contextual Memory Virtualisation: DAG-Based State Management and Structurally Lossless Trimming for LLM Agents** — Cosmo Santoni · https://arxiv.org/abs/2602.22402
  Contextual Memory Virtualisation treats accumulated session understanding as version-controlled state, modelling history as a DAG with snapshot, branch and trim primitives reusable across parallel sessions. A three-pass 'structurally lossless' trim keeps every user/assistant message verbatim while stripping raw tool outputs, base64 images and metadata, cutting tokens 20% on average (up to 86%). On 76 real coding sessions it stays economical under prompt caching. **Why it matters:** A concrete alternative to lossy compaction for long coding-agent sessions, with a reference implementation.
- **Don't Forget What You Just Learned: Self-Directed Repair Turns Agent Mistakes Into Lasting Lessons** — Yuval Kansal et al. · https://arxiv.org/abs/2610.31846
  Self-Direction lets an agent that fails a task reflect on its trajectory, extract a lesson and immediately distill it into a tiny LoRA adapter (~0.02% of parameters), stored in a persistent lesson library and routed to related future tasks. On Qwen-based agents across GAIA, Claw-Eval and Terminal-Bench 2.1 it raises success by 8.9–17.0 points. Adapters transfer to dozens of unseen tasks. **Why it matters:** Turns in-context reflections that get forgotten into durable, cheap weight updates — a practical path to agents that actually learn from mistakes.
- **Beyond Gain: Measuring Skill Internalization for Agent Skill Retirement** — Yanze Wang et al. · https://arxiv.org/abs/2610.32322
  Skill hubs with ~100k entries need to retire skills a model has internalized, but gain-based rules confuse 'internalized' with 'uncovered' (neither model nor skill delivers). The authors instead withhold the skill and score the model on a synthesized task, trusting high scores only when another model benefits from the skill. On SkillsBench, 28 of 31 gain-rule retirements rested on probes no run fully passed; the authors release 1,251 skills with tasks and scores. **Why it matters:** Relevant to anyone curating skill libraries as models improve — naive with/without-gain tests retire the wrong skills.
- **RSIHub: A Composable Framework for Agent-Evolution Methods** — Zimu Wang et al. · https://arxiv.org/abs/2610.32253
  RSIHub is an open-source framework for agent-evolution methods that improve prompts, skills, tools and orchestration from execution feedback. Recipes compose reusable operators while the framework handles execution, evaluation, recovery and lineage; AHE, Hyperagents, A-Evolve and GEPA are reimplemented without core changes. On Terminal Bench 2 and τ³ Banking the best gain is 13.5 pass@1 points, but rankings vary and gains don't always transfer to held-out tasks. **Why it matters:** Common infrastructure for fair comparison of self-improving agent methods, and a caution that gains often don't generalize.
- **Lifelong Context Adaptation through Bidirectional Memory-Skill Learning** — Tianyi Xu et al. · https://arxiv.org/abs/2610.32295
  MemCryst couples memory and skills for lifelong agents with a frozen LLM: recurring episodes in memory drive skill creation and revision, and skill-guided interactions feed new memory. Task outcomes re-weight the retrieval influence of served records without rewriting them. It leads 7 of 10 reported comparisons; on ALFWorld joint serving hits 63.2% vs. 59.8% memory-only and 50.5% skill-only. **Why it matters:** Evidence that memory and skills are complementary context sources and should be learned together.
- **Model-Adaptive Tool Necessity Reveals the Knowing-Doing Gap in LLM Tool Use** — Yize Cheng et al. · https://arxiv.org/abs/2605.14038
  Defines tool necessity per model from its own empirical performance rather than a model-agnostic label. Across four models on arithmetic and factual QA, 26.5–54.0% of decisions mismatch actual necessity. Hidden-state probes show models often 'know' a tool is needed, but the knowing and acting directions become nearly orthogonal in late layers — most errors occur in the cognition-to-action transition. **Why it matters:** Explains why tool-calling under- or over-fires and points at the action stage, not knowledge, as the thing to fix.
- **A-MapReduce: Executing Wide Search via Agentic MapReduce** — Mingju Chen et al. · https://arxiv.org/abs/2602.01331
  A-MapReduce recasts wide-search tasks (large-scale, breadth-oriented retrieval) as a horizontally parallel MapReduce-style multi-agent problem with task-adaptive decomposition and structured aggregation, plus experiential memory to evolve task allocation. It reaches state of the art on WideSearch and DeepWideSearch with 5.1–17.5% Item F1 gains over strong o3/Gemini 2.5 Pro baselines. Running time drops 45.8% vs. multi-agent baselines. **Why it matters:** Deep-research agents are built for vertical search; this is a parallel pattern for breadth-heavy collection jobs.
- **4DMemory: Benchmarking Long-Horizon Spatiotemporal Memory with Harness-Augmented Agents** — Yanhao Jia et al. · https://arxiv.org/abs/2610.32332
  Introduces LongVideo (~900 hours of video, 5,000+ reviewed questions) and 4DMemoryBench for long-horizon spatiotemporal memory. The 4DMemory Harness combines four skills, 22+ specialized tool models and model-specific RAG. Across 13 leading models, standalone foundation models struggle, while the harness improves all of them by over 50%. **Why it matters:** Another data point that harness design (skills + tools + retrieval) dominates raw model capability on long-horizon tasks.
- **Architecture-Aware Reinforcement Learning Makes Sliding-Window Attention Competitive in Math Reasoning** — Kai Liu et al. · https://arxiv.org/abs/2606.11634
  SWARR converts a pretrained full-attention model to sliding-window attention via SFT, then adapts it with on-policy RL. SFT alone leaves SWA behind full attention, likely due to long-range dependencies in SFT data; RL on self-generated trajectories largely closes the gap on math reasoning benchmarks while keeping linear-complexity efficiency. **Why it matters:** Suggests cheap long-context inference via SWA is viable for reasoning models if conversion is followed by RL.
