- **How Claude's text watermark works** — Anthropic · https://www.anthropic.com/news/claude-text-watermark
  Anthropic published an explainer of the text watermarking scheme embedded in Claude's outputs, describing how the signal is carried in generated text and how it can later be detected. The post is aimed at making the provenance mechanism legible to developers and researchers rather than keeping it opaque. ## 📄 Research Papers — Top Picks
- **Spatial Memory Agent: Experience-Grounded Procedure Memory for Spatial Intelligence** — Zhang, Ding, Zhou et al. · https://arxiv.org/abs/2608.12743
  Instead of post-training a VLM or calling external depth/3D tools at inference, the authors let a frozen VLM agent self-evolve a procedure memory grounded in its own past spatial experience. Retrieved procedures guide reasoning on new spatial tasks with no parameter updates and no expert tool dependency. **Why it matters:** Shows memory engineering can substitute for both fine-tuning and tool stacks on spatial reasoning — a much cheaper path for embodied agents.

- **ERSkill: Evolving for Skill-Guided Adaptive Memory Retrieval** — Chen, Zhang, Li et al. · https://arxiv.org/abs/2608.12720
  ERSkill treats memory retrieval itself as an evolvable component: interaction histories are compiled into a structured store, and retrieval behaviors are represented as executable skills built from primitives. A trained router matches each query to the best skill to assemble tailored evidence. **Why it matters:** Most agent memory work fixes retrieval and evolves the store; flipping that targets the actual bottleneck on heterogeneous queries.

- **Learning Latency-Aware Orchestration for Multi-Agent Systems** — Shi, Zheng, Lou · https://arxiv.org/abs/2601.10560
  Existing MAS orchestration optimizes accuracy and token cost but ignores wall-clock latency, which is governed by the critical execution path rather than total cost. The authors optimize latency along that path while guarding accuracy against naive operator-level credit misassignment. **Why it matters:** Production multi-agent systems fail on responsiveness, not token bills — this makes latency a first-class orchestration objective.

- **Practice Makes Unsafe: Skill Misevolution in Self-Improving LLM Agents** — Mao, Zhao, Zheng, Wang · https://arxiv.org/abs/2608.12851
  Self-improving agents distill successful trajectories into persistent, reusable skills — so a single unsafe success can become durable policy long after its triggering input is gone. The paper introduces SkillMisevo-Gym (versions skill state across frameworks) and SkillMisevo-Bench to attribute risk across authoring, retrieval, and later execution. **Why it matters:** Names and measures a failure mode that self-improving agent stacks create by design, and that snapshot benchmarks structurally cannot catch.

- **Teach the Magnitude, Not the Direction: Verifier-Bounded Credit Assignment for Multi-Turn Multi-step LLM Agents** — Wang, Lu, Zhang et al. · https://arxiv.org/abs/2608.13179
  CrEST keeps RLVR's verifier-bounded ceiling while adding dense token-level supervision from a privileged self-teacher. Credit is resolved at two levels: turn-segmented verified advantages fix inter-turn dilution, and entropy-gated teacher modulation refines within turns without gradient collapse. **Why it matters:** Directly addresses why multi-turn tool-use agents train poorly — a single trajectory reward cannot say which turn was actually wrong.

- **@skills: Attention is all you have** — Yin, Li, Shi et al. (Atlas) · https://arxiv.org/abs/2608.12610
  With ~56,800 public agent skills, the install-then-reside model forces every skill description to compete for fewer than 100 reliable trigger slots in the system prompt. The authors separate content, persistence, and automatic triggering, proposing @skills: a path addresses any skill, subtree, or collection, and simply reading a skill is enough to use it — nothing installs or stays resident. **Why it matters:** A concrete protocol fix for the skill-catalog scaling wall every agent harness (including Claude Skills and MCP servers) is now hitting.

- **SteerBench-Work: A Benchmark for Agent Steering at Action Boundaries** — Serdar, Mertayak · https://arxiv.org/abs/2608.12654
  Benchmarks the pre-commit decision — proceed or hold for human/policy review — at the moment an agent is about to send an email, merge a PR, or move money. Release v2026-05 has 106 incident-anchored scenarios across devops, support, finance, legal, medical, HR, and security, with evidence-reversed mirrors and a near-even proceed/hold split. **Why it matters:** Turns "when should the agent stop and ask" from a vibe into a measurable, incident-grounded capability with balanced error accounting.

- **SkillEvo: Self-Renewing Evolution Gradients from Multi-Turn Interaction Feedback** — Yan, Chen, Zhao et al. · https://arxiv.org/abs/2608.13120
  Skills authored in one LLM pass never learn from the failures they cause; systems that do close the loop use single-turn QA feedback, so the evolution gradient decays once the obvious gaps are patched. SkillEvo sources feedback from multi-turn interaction, exposing defects only visible across turns, and replaces scalar pass/fail gating with localization of structural causes. **Why it matters:** Explains why skill self-improvement plateaus fast and offers a feedback source that keeps the gradient alive.

- **SkillShapley: Boundary-Adaptive Shapley Valuation for Skill Step Attribution in LLM Agents** — Liu, Zhang, Zhong et al. · https://arxiv.org/abs/2608.13173
  Models the contribution of each step inside an agent skill as a Shapley value estimation problem, then computes step-level attribution in two phases with adaptive step boundaries. Reveals which procedure steps actually drive task success versus which are dead weight. **Why it matters:** Gives skill authors a principled way to prune and debug long procedures instead of rewriting them by intuition.

- **EgoCITE: Context-Augmented Indexing and Time-Aware Retrieval for Long-Horizon Egocentric Memory** — Zhang, Sun · https://arxiv.org/abs/2608.12627
  Identifies two bottlenecks in egocentric memory: indices built from context-poor captions are unreliable for agentic search, and retrieval ignores a question's temporal intent. EgoCITE turns fragmentary captions and speech into self-contained atomic memory indices, organizes action/activity/utterance/conversation views, and adds time-aware evidence retrieval. **Why it matters:** Long-horizon multimodal memory is the substrate for always-on assistants, and index quality — not model size — is the limiting factor.

- **MARC v1: An Open-Source Multi-Agent Framework for Clinical AI Reasoning and Coordination** — Shetty, Tripathi, Lin et al. · https://arxiv.org/abs/2608.13476
  MARC replaces monolithic clinical prompting with deterministic orchestration over role-specialized agents (extraction, reasoning, answer generation, evaluation), with explicit context passing and traceable intermediates for stage-wise failure attribution. A Decomposer generates task-specific agent prompts from plain-language descriptions; everything is YAML-configurable and runs API-based or local CPU. **Why it matters:** Traceability and stage-level failure attribution are the actual gate for clinical deployment, not raw benchmark scores.

- **LLMs Are Not Good Strategists, Yet Memory-Enhanced Agency Boosts Reasoning** — Wu, Hu · https://arxiv.org/abs/2608.12626
  Long-horizon strategic reasoning degrades through "strategic drift": finite attention prevents coherent subgoals across thousands of steps. EpicStar maintains a bank of successful past episodes as heuristics plus a working memory for short-term change, with dynamic gating deciding when to execute a retrieved plan. **Why it matters:** Quantifies where LLM strategy breaks down and shows episodic memory-as-policy recovers coherence without retraining.

- **Discovering Efficient and Explainable Communication Topologies for LLM-based Multi-Agent Systems via Causal Inference** — Li, He, Ji et al. · https://arxiv.org/abs/2608.12921
  Topology generators for multi-agent systems are optimized as black boxes against task reward, leaving no explanation for why particular communication edges exist. E2-Explainer is a model-agnostic framework that explains any generator's topology and isolates the critical communication subgraphs responsible for successful collaboration. **Why it matters:** Identifying the subgraph that actually carries the work lets teams cut agent-to-agent chatter — the dominant cost in MAS.

- **Alipay-PIBench: A Realistic Payment Integration Benchmark for Coding Agents** — Ying, Cao, Ma et al. · https://arxiv.org/abs/2607.14573
  A repository-level benchmark where coding agents must pick the right payment product, implement coordinated client-server flows, verify outcomes, and keep transaction and business state consistent. Nine product-specific projects, 18 task instances split into Basic completion and Advanced risk-aware hardening, scored by deterministic static/unit/integration/e2e rubrics plus LLM-assisted semantic checks. **Why it matters:** Moves coding-agent evaluation from isolated functions to money-handling, multi-file integration where consistency bugs are expensive.

- **FlashDrive: Flash Vision-Language-Action Inference for Autonomous Driving** — Li, Liang, Zhang et al. · https://arxiv.org/abs/2608.12932
  VLA inference for driving stalls on four cascaded bottlenecks: redundant visual encoding across overlapping frames, repeated LM prefill, serial low-entropy reasoning tokens, and uniform-compute flow-matching denoising. FlashDrive is an algorithm-system co-design attacking all four at once rather than one in isolation. **Why it matters:** Real-time control is a hard latency wall — partial optimizations of VLA stacks simply do not close it.
