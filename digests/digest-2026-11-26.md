## 📄 Research Papers — Top Picks
- **GDS Agent for Graph Algorithmic Reasoning** — Shi et al. · https://arxiv.org/abs/2508.20637
  The GDS agent exposes a broad set of graph algorithms as tools in an MCP server, with retrieval-based preprocessing, result postprocessing and an accompanying skill that guides graph analysis. It works with any modern LLM, and new benchmarks score intermediate tool calls as well as final answers, with demonstrations on money-laundering tracing and biological pattern mining. This is a v3 revision. **Why it matters:** A clear MCP-plus-skill pattern for giving agents reasoning over large graph data.
- **Sports Agent: A Self-Evolving System for Conversational Data Analytics** — Chen et al. · https://arxiv.org/abs/2611.33700
  Sports Agent is a self-evolving conversational analytics system combining an agentic SQL model, a planning and tool-orchestration harness, and a feedback engine linking online runs to offline model and harness updates. In a live product it improves factual correctness by 10.5 points and cuts average latency by 41.3% versus baseline. Across 30 harness-evolution rounds, the aggregate score improves by 10.8 points. **Why it matters:** Reported production evidence that regression-tested prompt and skill evolution can improve a deployed agent.
- **RoboEvo^2: Recursive Robot Self-Improvement via Harness-Policy Co-Evolution** — Liu et al. · https://huggingface.co/papers/2611.34675
  RoboEvo^2 co-evolves a coding-agent harness and a robot policy: policy failures drive the agent to build reusable skills and memory, and verified trajectories train the policy. Without extra human demonstrations, standalone success on LIBERO-PRO rises from 11.0% to 84.1% and hybrid success from 30.4% to 90.5%. **Why it matters:** A concrete self-improvement loop that also reports lower agentic cost on RoboTwin C2R.
- **The Detour Is the Danger: Preserving Security During LLM Agent Recovery** — Ma et al. · https://arxiv.org/abs/2611.33605
  The paper studies workflow security downgrade: after a failed operation, an agent replans and preserves task function while silently dropping required protections. It evaluates this with fault injection in an MCP/Skill environment and proposes ARGUS, which isolates recovery-plan validation and enforces obligations at execution time, preventing all observed protection losses in an 864-run evaluation. **Why it matters:** Agent error recovery is a security risk even without any prompt injection.
- **AliceAI-Foundation-80B-A3B-Base** — Skachkov et al. (Yandex) · https://arxiv.org/abs/2611.34529
  An Apache 2.0 mixture-of-experts base model with 80B total and about 3B active parameters, combining Kimi Delta Attention, Attention Residuals and the Muon optimizer, trained from scratch with a dedicated reasoning and agentic stage. It reports zero-shot 88.7% pass@8 on IMO-AnswerBench and 82.9% pass@8 on LiveCodeBench v5-v6, and releases two Russian factual benchmarks. **Why it matters:** A detailed training report for a sparse open model, including the effect of agent trajectories in pretraining.
- **MINE: A Training-Free Defense against Indirect Prompt Injection via Mutual Information and Embedding Variance** — Phan et al. · https://arxiv.org/abs/2611.34188
  MINE is a training-free defense against indirect prompt injection that maximizes relevance instead of detecting attacks, and doubles as a query-conditioned reranker. Across short- and long-context QA and agent tool-call injection (InjecAgent), the authors report the best accuracy-security trade-off among training-free defenses and the lowest latency on long contexts. **Why it matters:** A lightweight, attack-agnostic layer for RAG and tool-using agents.
- **EATS: Scaling Tool-Use Experience for Medical Reasoning Agents** — Li et al. · https://arxiv.org/abs/2611.33897
  EATS improves tool selection in medical reasoning agents by storing past queries, tool choices, arguments and self-evaluated feedback, then retrieving relevant experience for new queries. It needs no ground-truth supervision and shows consistent gains across four datasets and three multimodal LLMs. **Why it matters:** Simple tool descriptions are weak signals for uncertain neural tools; accumulated experience helps.
- **FORK: Co-Evolving Safe Disclosure and Decision Skills Against Attackers Who Read Every Refusal** — Man et al. · https://arxiv.org/abs/2611.33879
  FORK co-evolves a guardrail's decision and disclosure skills with an adaptive attacker that reads every public message, aiming to explain refusals without helping attacks. Averaged over three agents on FORK-World, it cuts adaptive attack success from 78.4% to 14.1% while keeping utility above 85%. **Why it matters:** Treats guardrail rejection messages as a security-relevant design choice.
- **IntentMiner: Intent Inversion Attack via Tool Call Analysis in the Model Context Protocol** — Yao et al. · https://arxiv.org/abs/2512.14166
  The authors define an Intent Inversion Attack in which a semi-honest third-party MCP server reconstructs user intent from function signatures, arguments and receipts, without seeing the raw query. IntentMiner reaches over 85% semantic alignment with original queries on ToolACE. This is a v3 revision. **Why it matters:** Connecting a third-party MCP server can leak what the user is trying to do.
- **What Does Skill Lift Actually Measure? A Source-Code-Level Audit and Noise-Aware Reanalysis of SkillsBench** — Zhang, Long · https://arxiv.org/abs/2611.33943
  A source-code audit and reanalysis of SkillsBench over 7,554 public trials finds grader-dependence cases, placeholder skill directories and a harness that added 48 built-in skills in most runs. No task-level performance drop from skills was statistically significant after multiple-testing correction, and a gating strategy still showed gains with shuffled condition labels. **Why it matters:** Cautions against pruning agent skills based on a few noisy runs.
- **Failure Broadens, Success Sharpens: Continual Adaptation of Tool-Use Agents Across Diverse Tasks with Dual-Polarity Memory** — Zhang et al. · https://arxiv.org/abs/2611.33612
  DualPM is a retrieval-free procedural memory workflow that learns from both successes and failures and periodically consolidates under a capacity limit. On streams of multi-domain tool-use tasks, failure memory mainly broadens coverage, success memory streamlines execution, and combining them gets both benefits. **Why it matters:** Practical guidance on what a self-improving agent should remember.
- **EGSE: Evidence-Grounded Skill Evolution for Medical Reasoning Agents** — Li et al. · https://arxiv.org/abs/2611.33909
  EGSE distills dialogues from similar medical cases into conditional workflows in a skill library, with additions gated by source-grounded review and execution validation. On four chest X-ray benchmarks it outperforms medical-agent and skill-evolution baselines in reasoning accuracy while reducing tool calls. **Why it matters:** Shows how to make skill evolution traceable and validated in a high-stakes domain.
- **JOVE ICE: Intent Guided Cloud Edge Device Collaboration for AI Glasses** — Jin et al. · https://arxiv.org/abs/2611.33735
  JOVE ICE routes AI-glasses requests across glasses, phone and cloud using hierarchical intent classification and dynamic subagent orchestration. Simple device control, over 30% of real-world requests, is handled on device, and the system cuts time to first token by about 13% and token usage by over 11% on public benchmarks. **Why it matters:** Intent-based routing is a direct lever on latency and cost for wearable assistants.
- **Read Before You Use: Improving Visual Memory Utilization in Vision-Language Models** — Kim et al. · https://arxiv.org/abs/2611.33687
  The authors find vision-language models often fail even when sufficient multimodal memory is supplied. Their two-stage MemRU training (supervised evidence reading, then GRPO for evidence use) lets an 8B model outperform Qwen3-VL-32B and approach GPT-5-mini across three unseen memory systems. **Why it matters:** Agent memory needs to be read well, not just stored and retrieved.
- **Engram: Multi-Stage Memory for Agentic Tuning of Heterogeneous Models** — Li et al. · https://arxiv.org/abs/2611.28356
  Engram is a cross-session memory for LLM agents that tune models, linking trial outcomes to hypotheses and rationale and assessing whether the evidence applies to the current model. On two ads models it matches the 32-trial result of a no-memory control with 47% fewer trials. This is a v2 revision. **Why it matters:** Reusable experience can cut the cost of agent-driven model tuning.
