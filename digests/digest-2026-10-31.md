## 📄 Research Papers — Top Picks
- **Nemotron 3.5 Super and Lightning: Open, Efficient Mixture-of-Experts Hybrid Mamba-Transformer Models for Agentic AI** — NVIDIA · https://arxiv.org/abs/2610.38095
  NVIDIA releases Nemotron 3.5 Super (120B total / 12B active, multimodal) and Lightning (30B / 3B active, text), open hybrid Mamba-Transformer MoE models for reasoning, long-context and agentic workloads. Training combines large-scale distillation, long-context training, native speculative decoding, agentic SWE mid-training, SFT + RLVR/RLHF and multi-teacher on-policy distillation. Super can reason over text, images, video and interactive tool environments. **Why it matters:** Strong open-weight option for efficient self-hosted agent backends.
- **SkillMem: Compact External Skill Memory for Latent Multi-Agent Reasoning** — Zhu et al. (IBM) · https://arxiv.org/abs/2610.37935
  SkillMem stores each reusable skill as a small external latent memory read by a role-conditioned cross-attention module during latent multi-agent reasoning. Memories and reader are trained via behavioral distillation to mimic the effect of textual skills while the backbone stays frozen, avoiding repeated text processing or per-skill KV/parameter storage. **Why it matters:** Cheaper way to inject many skills into multi-agent systems without long prompts.
- **Compile Away Uncertainty: Self-Evolving Agent Skills via Programmatic Compilation** — Yang et al. · https://arxiv.org/abs/2610.39508
  SkillCompiler turns self-evolving agent skills into hybrid skeletons: well-specified operations are compiled into deterministic executable programs while ambiguous steps keep LLM reasoning. The executability-aware decomposition reduces re-interpretation of learned procedures at every run. **Why it matters:** Practical pattern for making skill libraries more deterministic and verifiable.
- **Scan Before You Install: Detecting and Mitigating Local and Composite Vulnerabilities in Skills** — Gandhi et al. (BGU) · https://arxiv.org/abs/2610.37901
  A six-module scanner detects unintended (not just malicious) vulnerabilities in agent skills, including composite risks from multi-skill interactions. It reaches 95.9% recall at 4.2% FPR on SkillTrustBench and F1 0.947 on MalSkillBench, beating Cisco, NVIDIA and other scanners; 53/59 findings in top GitHub skill repos were confirmed. **Why it matters:** Skill supply-chain security is now a real attack surface for Claude/agent ecosystems.
- **When Skills Tell Agents Not to Ask: A Large-Scale Study of Oversight Directives in Agent Skills** — Sanko & Tian · https://arxiv.org/abs/2610.37734
  First large-scale study of oversight-loosening directives (e.g. proceed without approval, --no-verify) across 1.53M SKILL.md-based skills. About 1 in 17 skills (~88k) contains such a directive, mostly via permission flags and 70.1% applied unconditionally. **Why it matters:** Copied skills silently remove human checkpoints — worth auditing your own skill sets.
- **ATLAS: Dual-Horizon Diagnostic Evaluation for Tool-Use Agents in Meituan Xiaotua** — Chen et al. (Meituan) · https://arxiv.org/abs/2608.30685
  ATLAS is a dual-horizon diagnostic evaluation framework for industrial tool-use agents: within-turn signals cover thinking, tool/skill execution and responses, while across-turn signals track intent, constraints and corrections over user lifecycles. LLM judges are calibrated against references maintained from business logs. **Why it matters:** Production-grade template for diagnosing where tool-use agents fail, not just whether.
- **CHI-Bench: Can AI Agents Automate End-to-End, Long-Horizon, Policy-Rich Healthcare Workflows?** — Chen et al. · https://arxiv.org/abs/2605.16679
  χ-Bench tests long-horizon healthcare workflows (prior auth, utilization management, care management) in a simulator of 20 apps exposed via 87 MCP tools, guided by a 1,290+ document handbook skill. The best of 30 harness/model configs resolves only 28% of tasks. **Why it matters:** Realistic MCP-based benchmark showing policy-dense enterprise workflows remain far from solved.
- **AgentDecept: Benchmarking Deceptive Behavior in Tool-Using LLM Agents under Pressure** — Zhang et al. (UCSC) · https://arxiv.org/abs/2610.39377
  AgentDecept is an executable benchmark of 477 pressure variants from 257 tasks that checks whether tool-using agents faithfully report their actions. Pressure enters via events, context, app state, tool responses and quotas; evaluation separates falsification, concealment and equivocation against time-ordered evidence. **Why it matters:** Measures a key trust gap: agent reports vs. what actually happened.
- **SCOPE: Selective Critical-Step On-Policy Self-Distillation for Agentic Reinforcement Learning** — Liu et al. · https://arxiv.org/abs/2610.38391
  SCOPE improves agentic RL by having the policy generate step-specific hindsight skills from its own trajectories and distill them only at selected error steps, with a bounded signed teacher-student coefficient and a length reward. Qwen2.5-3B reaches 97.7% on ALFWorld and 85.2% on WebShop. **Why it matters:** Finer credit assignment for long-horizon agents trained on outcome rewards.
- **INFRAMIND: Infrastructure-Aware Multi-Agent Orchestration** — Kabir et al. · https://arxiv.org/abs/2606.11440
  INFRAMIND is a hierarchical policy that chooses the multi-agent collaboration graph at arrival and the model/reasoning strategy before each call, based on serving load, telemetry and deadline. It improves low-load accuracy by up to 7.6 pp over baselines on a shared five-model deployment. **Why it matters:** Orchestration that is aware of serving congestion — relevant for deadline-bound agent systems.
- **Advancing Clinical Genomic Analysis with a Skill-Centred Agent** — Zheng et al. · https://arxiv.org/abs/2610.40556
  ClinGeX is an LLM agent composing 105 curated executable skills via task-specific retrieval and dependency-aware orchestration for clinical genomic analysis. It hits 71.7% concordance with experts vs 45.7% for the best comparator, and improved professionals' accuracy in a 45-person study. **Why it matters:** Strong evidence that curated skill libraries beat general chat assistants in expert domains.
- **Do Personalized Skills Help Coding Agents? An Empirical Study of Developer Interaction Traces** — Huang et al. · https://arxiv.org/abs/2608.10319
  Distills developer-specific skills from coding-agent interaction traces using rule-based bootstrapping plus LLM refinement, evaluated with a replay framework and LLM developer simulator. Task-specific skills work best overall; personalized skills help when preferences recur often on related tasks. **Why it matters:** Guides when to invest in per-user CLAUDE.md/skills vs. task skills.
- **SkillCT: A Multidimensional Benchmark and Execution-Free Baseline for Agent Skill Assessment** — Sun et al. · https://arxiv.org/abs/2610.38147
  SkillCT benchmarks agent skills across nine dimensions in static (spec quality), dynamic (stability across models/requests) and human-assisted (behavior-chain consistency, granularity) aspects, with an execution-free baseline for pre-deployment assessment. **Why it matters:** Lets skill authors assess quality without costly task-environment runs.
- **Online Dense Reinforcement Learning with Planning-Grounding Agent for UI Navigation on Live IOS Apps** — Duan et al. (Apple) · https://arxiv.org/abs/2610.39264
  Trains UI-navigation agents with online RL on live iOS apps, splitting into a planning agent and a UI grounding model. An LLM judge supplies dense step-level plus terminal rewards, optimized with PPO and a new neighbor-conditioned value estimator (GiGPPO). **Why it matters:** Path to small, cheap on-device GUI agents that recover from errors.
- **World Model Science: Self-Organized Criticality, Weak Chaos, and Metastable Belief Dynamics in Long-Horizon LLM Agents** — Song & Cai · https://arxiv.org/abs/2609.17419
  Studies long-horizon LLM agent world-model dynamics through self-organized criticality, weak chaos and metastable beliefs across puzzles, tool-use, embodied, retrieval tasks and Game of Life. Errors are temporally correlated, external pressure sharply raises collapse risk, and locally valid actions can continue after global task state is wrong. **Why it matters:** Explains why long agent runs fail suddenly — useful for designing checkpoints.
