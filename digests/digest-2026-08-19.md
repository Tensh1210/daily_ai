## 📄 Research Papers — Top Picks
- **Agentic ESOpt: Fine-Tuning Long-Horizon LLM Agents with Minimal GPU Requirements** — Zheng, Chen, Ba, Wang, Teh, Lee · https://huggingface.co/papers/2608.17310
  Argues evolution strategies (ES) beat RL for fine-tuning long-horizon agents: ES needs only inference-level GPU memory yet performs full-parameter optimization, avoiding the heavyweight backprop training stack. Its lightweight black-box feedback interface also composes cleanly with prompt-space evolution and skill optimization, and it sidesteps RL's brutal credit-assignment problem on long, branching trajectories. **Why it matters:** Makes agent post-training feasible for teams without large training clusters.

- **GxP-Agent: Process-DAG Topology for Reliable Clinical Trial Programming with LLM Agents** — Jaime Yan · https://arxiv.org/abs/2608.16890
  Five frontier models failed all 11 single-shot attempts at producing a valid CDISC subject-level analysis dataset. GxP-Agent encodes regulatory process ordering as a DAG of 15 domain-specific nodes run by worker agents with pharmaverse skill context, validation gates, and conditional retry, reaching 100% structural match (49/49 ADSL variables) on a new execution-based benchmark built from an FDA pilot submission. **Why it matters:** Shows explicit process topology, not a bigger model, is what turns a catastrophic-failure task into a solved one.

- **Security Assessment of DeepSeek Harness with A.I.G: Evaluating Resistance to Indirect Prompt Injection** — Ying, Wu, Wu, Zheng, Cheng, Shi, Guo · https://huggingface.co/papers/2608.16393
  14,560 controlled executions across 16 indirect-content channels, 35 payload objectives, and 12 attack methods run against the DeepSeek Harness agent loop, judged by both a deterministic rule judge and an LLM judge. Strongest attack success rates: 17.0% (fake-completion, text mode), 25.5% (hidden Unicode, file mode), 16.0% (skills channel, file mode). **Why it matters:** Quantifies that file-carried and skill-channel injection remain wide open in production-shaped agent harnesses.

- **Towards Safer RAG: Only Agents Capable of System 2 Thinking may Access Untrusted Documents** — Mehrdad Ghassabi · https://arxiv.org/abs/2608.17153
  RAG systems stay vulnerable to knowledge-poisoning: an LLM can correctly detect that a document contains false information and still be influenced by it. Rather than the strict Cordon Principle (full isolation of the answer synthesizer from raw evidence, which is computationally expensive), this proposes a refined rule — only agents capable of deliberative System-2 reasoning may touch untrusted documents. **Why it matters:** Offers a cheaper trust boundary for RAG than full evidence isolation.

- **Teach and Grow: An Agent-Centered Architecture for General Robot Learning** — Nie, Liu, Wang · https://arxiv.org/abs/2608.17209
  End-to-end VLA and world-action models are bounded by validated physical coverage; anything outside it triggers the "retraining tax" of new robot data, a policy update, and regression testing. TGL instead has a multimodal agent turn a few successful demonstrations into reusable closed-loop Skill Blocks, then ground and compose those blocks in new scenes. **Why it matters:** Reframes robot generalization as runtime skill composition rather than continual retraining.

- **Co-RL: Unsupervised Reasoning Emerges from Diverse Cohort in Multi-agent RL** — Yang, Bian, Tian, Fu, Huang, Shi, Xiao, Vasconcelos, Li · https://arxiv.org/abs/2608.17253
  Self-rewarding RL removes the need for verifiable ground truth but tends to reinforce existing bias, shrink response diversity, and collapse into homogenized output. Co-RL trains multiple decoupled agents as a cohort so the reward signal comes from diversity across the group instead of a model grading only itself. **Why it matters:** A practical route to keep scaling reasoning RL past the point where humans can reliably label answers.

- **When Agents Act on Web3: An Attack-Surface Survey of MCP, Skills, and Tool Calling** — Karanjai, Lu, Diallo, Xiong, Xu, Shi · https://arxiv.org/abs/2608.17275
  Reports that state-modifying tools rose from 27% to 65% of MCP tool use, then argues four properties of the blockchain execution layer — irreversibility, signing authority, continuous autonomy, sequence-level composition — qualitatively change the agent threat model. Contributes an attack-surface taxonomy over the fragmented MCP-security literature plus a Web3 risk-mapping matrix. **Why it matters:** Where generic agent security tolerates recoverable failures, on-chain execution converts the same bugs into permanent loss.

- **LEGO-RL: Harness-Native Reinforcement Learning for Coding Agents** — Du, Jiang, Yuan, Dai, Wang, Chen, Tao, Yu, Shang, Wong, Li, Bai · https://arxiv.org/abs/2608.17393
  Coding-agent harnesses are misaligned with policy-gradient training: environment crashes and reward hacking corrupt outcome signals, while train-inference discrepancies decouple rollout behavior from policy updates. LEGO-RL bridges native harnesses to scalable policy-gradient optimization without modifying their control flow, using in-process LLM proxying for token-level alignment and robust trainer-side log-probability recomputation. **Why it matters:** Lets teams train on the exact harness they ship instead of a simplified training-only environment.

- **aDSL: Agentic 3D Creation via Joint Agent-Program Design** — Wang, Wei, He, Wei, Chen, Wang · https://huggingface.co/papers/2608.17975
  LLM-authored 3D programs are brittle because conventional programmatic interfaces demand fragile absolute numeric choices, while LLMs reason better over semantic structure and spatial relations. aDSL co-designs an agent-centric DSL built on relational operators together with a role-specialized multi-agent system. **Why it matters:** Generalizable lesson — design the tool API around how the model reasons, not around the old human-facing API.

- **Write, Execute, Refine: From Skill Followers to Skill Optimizers via RL from Execution Feedback** — Peng, Zhang, Zhang, Wang, Du, Tu, Wang, Liang, Xu, Wong · https://arxiv.org/abs/2608.17587
  Agent-authored skills score 8–11 points worse than using no skill at all, implying that following procedural guidance and improving it from execution evidence are distinct capabilities. WER trains a Skill Optimizer outside a frozen executor: the optimizer proposes skills, the frozen agent runs each repeatedly, and a programmatic verifier scores outcomes to supply relative credit over matched successful and failed trajectories. **Why it matters:** Directly targets why self-written agent skills currently hurt more than they help.

- **CABLE: Extending the Reach of Memory Retrieval via Complementary Antecedent-Based Linking and Expansion** — Tan, Gao, Wang · https://arxiv.org/abs/2608.17911
  Long-term agent memory retrieval leans on semantic similarity, which recalls topically-close items but misses earlier experiences, plans, or motivations that are semantically distant from the events they explain. Existing memory graphs often duplicate what the host retriever already recovers; CABLE instead builds a sparse set of retriever-complementary antecedent links. **Why it matters:** Fixes the specific failure where an agent has the history but cannot reach the part that matters.

- **Search-G1: Grounded Search Agents via Representation-Based Intrinsic Rewards** — Cheng, Ma, Zhang, Zhang, Duan, Xia, Wang, Lu, Shi, Ma · https://arxiv.org/abs/2608.07531
  Outcome rewards scale but cannot distinguish grounded retrieval from redundant search, while internal rewards like entropy or likelihood mainly reflect model confidence. Search-G1 uses two intervention-calibrated representation readouts to measure whether an answer is operationally grounded in retrieved evidence. **Why it matters:** A cheap training signal for "search only when needed, then actually use what you found."

- **The Blind Curator: How a Biased Judge Silently Disables Skill Retirement in Self-Evolving Agents** — Zhang, Cui, Wang, Li, Qiu, Zhu, He · https://arxiv.org/abs/2607.07436
  Self-evolving agents rely on retiring bad skills to keep a growing library above the no-skill baseline — a guarantee that assumes unbiased reward, which the LLM judges used for reference-free tasks violate. A corrupted-reward analysis plus a behavioral study on report-writing and code-generation testbeds shows symmetric noise is harmless, but false-pass bias disables contribution-based retirement entirely. **Why it matters:** Explains why skill libraries degrade quietly instead of failing loudly.

- **Auditing Self-Evolution in Financial Agents: Capability Gains, Security Drift, and Execution-Interface Mismatch** — Li, Zhu · https://arxiv.org/abs/2608.17684
  Audits SkillOpt, Agent Workflow Memory, and ReasoningBank in simulated e-banking using matched benign trajectories, sealed evaluation endpoints, execution-grounded checks, and independent state replay. SkillOpt lifts benign utility 0.741→0.837, but exposure to injected content rises 0.820→0.943, overall attack success rate rises 0.496→0.530, and unauthorized financial state changes reach 0.685. **Why it matters:** Self-evolution buys capability and pays for it in security drift — measured on the same trajectories.

- **Agent Lightning v1.0: Towards Harnessed Agentic RL** — He, Zhang, Zhou, Yang, Kang, Zhang, Qiu, Tsui, Xu, Luo · https://huggingface.co/papers/2608.17528
  Formalizes "harnessed agentic RL," where the deploy-time harness owns the environment interaction loop and the trainer observes only LLM request-response pairs — a paradigm since adopted by verl Uni-Agent, AReaL 2.0, slime, and Polar. The paper addresses the resulting retokenization, sample merging, advantage calculation, loss normalization, and backend scheduling problems. **Why it matters:** Infrastructure standard for training agents inside the harness they actually run in.
