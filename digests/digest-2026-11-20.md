## 📄 Research Papers — Top Picks
- **Harness-Zero: Harness Distillation via Agent-as-Harness** — Haoran Ye et al. · https://arxiv.org/abs/2609.24974
  Introduces harness distillation: using a domain- or instance-optimized agent harness as training-time guidance and transferring its behavior into model weights so gains persist under a single fixed deployment harness. Harness-Zero does this via agent-as-harness, where a harnessing agent corrects student responses in the deployment harness's action space before execution. **Why it matters:** Lets agents keep specialized-harness gains without routing among many harnesses at deployment.
- **FinVeriQA: Financial Research Agents for Question Answering: Routing, Retrieval, MCP Tool Use, and Provenance-Aware Evidence Verification** — Meenakshi Rajpurohit et al. · https://arxiv.org/abs/2611.25071
  FinVeriQA is an open-source multi-agent financial QA prototype over SEC filings and live market data: a small typed router (Laya) picks tools, Python computes all numbers, Mistral-7B writes a cited answer, a validator checks citations, and an MCP server exposes the pipeline. Laya routed better than Mistral-7B (0.85 vs 0.52), and Mistral-7B got only 29% of 100 calculations right versus 100% for Python. **Why it matters:** Evidence for letting code compute numbers and small routers decide tools, with MCP as the serving layer.
- **Beyond Weight Updates: Evolving Agent Harnesses for Domain Specialization** — BoHao Chen · https://arxiv.org/abs/2611.25380
  Studies evolving the agent harness (system prompt, tool schemas, skill library, planning scaffolding) with the GEPA reflective optimizer while keeping the policy frozen. On SWE-bench Verified, OfficeBench and Terminal-Bench with a Claude Code-style agent, harness evolution recovers most of the gains of weight updates at a small fraction of the compute, and combining both is best. **Why it matters:** A cheap, GPU-free path to domain-specialize coding agents that composes with RL.
- **EvoSkill Injection: Red-Teaming Autonomous Skill Generation and Evolution in Self-Evolving Agents** — Doyun Kim et al. · https://arxiv.org/abs/2608.30429
  Defines EvoSkill Injection, a threat model where the autonomous skill generation and evolution pipeline of self-evolving agents is used to create and reuse malicious skills. Proposes SARGE, a red-teaming framework, and EvoSkillBench, a dataset of malicious interaction trajectories for inducing malicious skill formation. **Why it matters:** Self-evolving skill libraries are a new attack surface that needs red-teaming before adoption.
- **AutoMaster: Autonomous Post-Training by Making the Same Model a Better Teacher** — Guoxin Chen et al. · https://huggingface.co/papers/2611.26510
  Proposes Skill-FT, which uses natural-language skills to suppress bad habits and elicit effective behaviors during teacher rollouts, then fine-tunes a student model on those trajectories. AutoMaster is an LLM agent that autonomously designs these interventions, improving over vanilla SFT by 1.42-8.99 points on Terminal, Search and SWE tasks with 4B and 9B models. **Why it matters:** Agents can automate post-training by shaping teacher behavior with skills.
- **Beam Model Technical Report** — Reflection Team · https://arxiv.org/abs/2611.26358
  Technical report for Beam, a sparse MoE with 501.3B total / 23.4B active parameters built for coding, reasoning and agentic workloads, with a 1M-token context and a large asynchronous RL campaign (over 100M rollouts on 10.5K GB300 GPUs). Serving uses FP8/NVFP4 quantization and a speculative decoding drafter, claiming 3-4x less inference compute than comparable models. **Why it matters:** A large open-lab agentic model with RL that reportedly kept improving with more compute.
- **MINTEval: Evaluating Memory under Multi-Target Interference in Long-Horizon Agent Systems** — Hyunji Lee et al. · https://arxiv.org/abs/2605.18565
  MINTEval is a benchmark for memory-augmented agents under multi-target interference, with long interconnected contexts and frequently updated information across state tracking, multi-turn dialogue, Wikipedia revisions and GitHub commits. It tests single-target recall as well as aggregated reasoning over multiple evolving memories. **Why it matters:** Exposes how agent memory degrades when facts are repeatedly updated.
- **ResearchFlow-Eval: Tracing the Execution Gap in End-to-End Multi-Claim Autoresearch** — Peng Jiang et al. · https://arxiv.org/abs/2610.18088
  ResearchFlow-Eval scores end-to-end autoresearch systems at the stage and claim level, with rubrics derived from published anchor papers. It evaluates general-purpose harnesses, skill-augmented harnesses and others on multi-claim completion and revision across attempts. **Why it matters:** Measures the execution gap in agents running whole research projects.
- **Agent^2 RL-Bench: Can LLM Agents Engineer Agentic RL Post-Training?** — Wanyi Chen et al. · https://arxiv.org/abs/2604.10547
  Agent^2 RL-Bench tests whether LLM agents can autonomously design, implement, debug and run RL post-training pipelines within a fixed budget. It spans six tasks from static rule-based training to closed-loop online RL, with diagnostic skills for runtime recording and post-hoc summarization. **Why it matters:** A benchmark for agents that engineer their own model post-training.
- **SheetAlign: Grounded Interaction and Stage-Isolated Learning for Spreadsheet Agents** — Yuxiang Wang et al. · https://arxiv.org/abs/2611.26069
  SheetAlign is a spreadsheet agent framework with stage-isolated policy learning (where to operate, what to change, how to implement), plus API grounding and execution-consistency program selection. It lifts Qwen3-4B accuracy on SpreadsheetBench from 13.5% to 29.2% without training via its grounded interface. **Why it matters:** Makes small local open-weight models viable for sensitive spreadsheet automation.
- **Designer-RSI: Evolving Procedural Memory for Graphic Design Agent** — Hongyang Du et al. · https://arxiv.org/abs/2609.22086
  Designer-RSI evolves a modular SKILL.md skill bank from unlabeled design trajectories for an agent covering 230+ raster, vector and layout tools. It combines acquiring new skills with revising failing ones, gating updates with a Pareto-style matched replay check that requires gains without local regressions. **Why it matters:** Practical recipe for self-improving tool agents via external skill files.
- **Keel: A Frontier Model Teaches a Vision-Language Model by Rewriting Its Weights** — Jiajun Fan et al. · https://arxiv.org/abs/2611.25257
  Keel uses a frontier multimodal LLM as an agentic editor that locates the cause of thinking-mode looping in small VLMs like Qwen3.5, edits the weights and tests them. The harness keeps only edits that reduce failures without hurting held-out accuracy, requiring no training and leaving model size unchanged. **Why it matters:** Agentic weight editing as a training-free repair for model failure modes.
- **Generalist Meets Specialists: An Evolving Multimodal Agent with Persistent Tool Orchestration for Traffic Scenario Understanding** — Linjia Kang et al. · https://arxiv.org/abs/2611.25868
  StarTV-Agent is a tool-augmented VLM for traffic scenario understanding that combines process-level policy learning (RSPO, WDL) with experience evolution. At inference, Lightweight Adaptive Workflow Reuse picks a fast path of reusable workflows to cut repeated planning cost. **Why it matters:** Workflow reuse reduces planning overhead for tool-orchestrating agents.
- **A$^2$-VLA: Adapting Vision-Language-Action Policies to New Tools through Agentic Affordance Discovery** — Chenyuan Zhou et al. · https://arxiv.org/abs/2611.25656
  A^2-VLA pairs an embodied agent with a VLA policy to adapt to new tools: the agent treats tool affordances as hypotheses, tests them in reconstructed simulation scenes, and stores validated extraction skills in a reusable library for unseen tools. **Why it matters:** Skill libraries help robot policies transfer across tools.
- **Harnessing Medical Visual-Language Models with Agentic Evidence Management** — Qiming Huang et al. · https://arxiv.org/abs/2611.25840
  Introduces Mask-Evidence MedVQA (2.5K examples, four image types) to separate evidence use from segmentation quality, showing that how the same mask is rendered changes model behavior and that masks create an evidence trade-off. Proposes agentic evidence management to use tool outputs more effectively. **Why it matters:** Tool output presentation, not just accuracy, determines agent performance.
