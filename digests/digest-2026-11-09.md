## 📄 Research Papers — Top Picks
- **Explore Separately, Adopt Selectively: Execution-Guided Tool Use over Large Tool Libraries** — Anna Mazhar, Seiji Maekawa, Nikita Bhutani · https://arxiv.org/abs/2610.22688
  BRIA (Branch-Inspect-Adopt) is a plug-and-play method for agents facing large, evolving tool catalogs. Instead of probing plausible tools one after another, it runs each candidate in an isolated branch that retrieves and executes independently; the task agent then inspects the execution evidence and adopts only useful results into its context. It also retrieves newly added tools as capabilities change. **Why it matters:** Directly addresses context pollution and wrong-tool commitment in MCP-scale tool libraries.
- **ENGRAM: From Agent Experience to Weights through Verified Consolidation** — Ruiyi Yang, Zechen Li, Lihuan Li et al. · https://arxiv.org/abs/2611.09472
  ENGRAM decides which stored agent experience to train into weights and when external memory records can be safely released. A demonstration-aware gate admits skills based on student mastery or enough successful teacher demonstrations, decoupling training admission from memory release. **Why it matters:** A principled path from retrieval-based agent memory to parametric skills without dropping still-needed guidance.
- **ClawTrace: Cost-Aware Tracing for LLM Agent Skill Distillation** — Boqin Yuan, Yue Su, Renchu Song et al. · https://arxiv.org/abs/2604.23853
  ClawTrace records cost-attributed agent traces and compiles each session into a TraceCard; CostCraft reads them and writes preserve/prune/repair skill patches. Per-step cost lets the pipeline distinguish adding a missing step from removing an expensive step that never affected the outcome, exposing transfer patterns aggregate metrics hide. **Why it matters:** Brings cost accounting into skill distillation, key for cheaper production agents.
- **From Procedures to Permissions: Learning Precise Subagent Authorization from Agent Skills** — Wenkai Yu, Ning Ding, Wentao Zhang, Yehui Tang · https://arxiv.org/abs/2611.08905
  Multi-agent systems must decide which tools and workspace resources each delegated subagent may access, but outcomes and trajectories give weak supervision for this. The authors observe that Agent Skills already encode procedural knowledge about what a task requires and use them to learn precise subagent permissions. **Why it matters:** Least-privilege delegation is a core safety gap in orchestrator/subagent setups.
- **From LoRA to Language: Recovering Skill Documents from Adapters** — Saranya Dintakurthy Swadha, Pavan C Shekar, Arpit Jain et al. · https://arxiv.org/abs/2611.09454
  Agent skill documents are increasingly compiled into LoRA adapters to save context, losing readability and auditability. The paper asks whether the skill text can be recovered from the adapter plus frozen base model, scoring recovered docs on key-instruction coverage and task success; reading the weights alone recovered little. **Why it matters:** Quantifies the auditability cost of compiling skills into weights.
- **On Agentic Manipulation Policies** — Chen Chen, Omid Bagherieh, Naveen Nikamanth Appiah Balaji et al. · https://arxiv.org/abs/2611.09892
  The authors show that generalist AI models commanding robot manipulators directly can be more reliable than specialist VLA and world-action models. Their reference harness AMP1 runs unchanged across single-arm, bimanual, and mobile manipulation and reaches state of the art on RoboLab-120 and CaP-Gym without demonstrations. **Why it matters:** Agent harnesses around generalist models may outpace demo-trained robot policies.
- **Decision Context: Persistent Behavioral Learning for AI Agents** — Nima Vahdat, Pashootan Vaezipoor · https://arxiv.org/abs/2611.08644
  forge_dc captures behavioral signals from human corrections and self-assessed tool-call failures, compiles them into imperative RULE directives, and injects them at the decision points where they apply. It is evaluated against four predecessor approaches on DC-Bench, 71 scenarios across nine behavioral categories. **Why it matters:** Targets the "user fixes the same mistake every session" problem with procedural rather than factual memory.
- **MemSkill: Learning and Evolving Memory Skills for Self-Evolving Agents** — Haozhen Zhang, Quanyu Long, Jianzhu Bao et al. · https://arxiv.org/abs/2602.02474
  MemSkill replaces static, hand-designed memory operations with learnable, evolvable memory skills: reusable routines for extracting, consolidating, and pruning information from interaction traces. A controller learns which skills to apply, following the agent-skills design philosophy. **Why it matters:** Makes agent memory management adaptive instead of hard-coded.
- **SafeOrchestrate: Runtime Checked Intent-Driven Orchestration for Cyber-Physical Systems** — Muhammad Ashfaq, Ahmed R. Sadik, Ewan Warburton et al. · https://arxiv.org/abs/2611.09364
  A reference architecture that turns natural-language intents into atomic goals with runtime-checkable specifications, grounds them to device affordances, and verifies actions before execution. It constrains LLM tool use by device capabilities, runtime state, and safety rules. **Why it matters:** A concrete pattern for safe LLM tool use when actions touch physical systems.
- **LUCA: A Synthetic World for Experimental Reasoning** — Anna Gogleva, Thomas Charman, Martin Balla, Karl Gemayel · https://arxiv.org/abs/2611.03100
  LUCA is a configurable synthetic world where agents learn unknown regulatory systems through budgeted experiments, then predict interventions, diagnose hidden faults, and attempt rescues under fully known ground truth. Across seven frontier LLMs these capabilities dissociate sharply, and agents often succeed for the wrong reasons. **Why it matters:** Evaluates an agent's experimental process, not just its final answer.
- **SkinMind: Equipping Agentic RAG with Human-Inspired Graph Probing for Reliable Dermatology AI** — Jing Hao, Weinan Zhou, Zhihong Lu et al. · https://arxiv.org/abs/2611.08935
  SkinMind is a multimodal agentic RAG framework in which an orchestrator iteratively probes a graph environment of textual and visual clinical evidence, using hierarchical graph actions to adapt retrieval granularity and follow multi-hop relations. **Why it matters:** Shows agentic, graph-structured retrieval as an alternative to one-shot RAG in a high-stakes domain.
- **More with Less: Efficient Parallel Scientific Code Translation via an Agent-Skill Workflow** — Jianuo Shen, Pengyi Xu, Bo Zhang · https://arxiv.org/abs/2611.08947
  Translation, compilation diagnosis, and execution validation are split across three agents coordinated by a verdict-driven orchestrator that routes each failure to a targeted repair skill instead of retrying blindly; an automated output check drives self-correction. **Why it matters:** A practical template for skill-routed repair loops in code agents.
- **Safety and accuracy diverge across deployment conditions in clinical large language models** — Sebastian Wind, Tri-Thien Nguyen, Jeta Sopa et al. · https://arxiv.org/abs/2605.04039
  SaFE-Scale tests whether scaling model size, context length, retrieval, or inference compute makes clinical LLMs safer, using RadSaFE-200, a radiology benchmark with clinician-defined clean/conflict evidence and high-risk error labels. It examines whether higher accuracy actually implies safer behavior. **Why it matters:** Accuracy is not a sufficient proxy for safety in medical deployment.
- **AdaAlloc: Adaptive Visual Token Allocation for Long-Video Question Answering** — Joungbin An, Kristen Grauman · https://arxiv.org/abs/2611.09092
  AdaAlloc recasts long-video QA as allocating a fixed visual-token budget between global context and high-resolution local evidence, and deciding where in the video to draw that evidence from. It avoids lossy caption or frame-similarity proxies that miss motion and state changes. **Why it matters:** Better accuracy per token for multimodal LLMs on long video.
- **Phantom Consensus: Measuring Social Reasoning in Multi-Agent LLM Decision-Making** — Disha Sheshanarayana, Rajat Subhra Pal, Manjira Sinha, Tirthankar Dasgupta · https://arxiv.org/abs/2611.08971
  LLMs in collectives shift public decisions after ambiguous social signals while misreporting what other agents privately judged, even when private judgments do not support the apparent consensus. PHANTOM-Bench separates private judgments, public decisions, and beliefs about others to measure this. **Why it matters:** A failure mode to watch in multi-agent voting and aggregation designs.
