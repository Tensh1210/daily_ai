## 📄 Research Papers — Top Picks
- **Continual Tool-Space Extension Learning for Multimodal Agents** — Seo et al. · https://arxiv.org/abs/2611.23810
  COTEX adds new specialist vision tools to an already-trained multimodal agent at adapter-level cost. It finds parameter directions that trigger tool calls vs. select tools, and constrains the new adapter orthogonally so earlier tool choices are unaffected. A protocol converts specialist annotations into verified tool-use trajectories; gains on ten VLM benchmarks with at most a 0.3-point drop elsewhere. **Why it matters:** Continual tool-space growth without forgetting is key for evolving agent toolkits.
- **KnowledgeClaw: Towards Agentic Knowledge Engineering via Omnimodal Hypergraphs** — Luo et al. · https://arxiv.org/abs/2611.24294
  KnowledgeClaw is an agentic knowledge-engineering system that builds an omnimodal typed hypergraph, keeps it current via a closed-loop lifecycle agent, and routes queries to the right granularity. The paper also releases OmniKE-Bench (6 tasks, 1,829 items, 3,960 real files, 5 modalities); it ranks first against 30 baselines (+14.6 OKE). **Why it matters:** Moves RAG toward maintained, multimodal knowledge bases with a benchmark to measure them.
- **GUARD: Stabilizing Recursive Self-Improvement with Regret Guidance** — Zhang et al. · https://arxiv.org/abs/2611.23476
  GUARD evolves an agent harness (prompts, skills, tool rules, memory) without weight updates or external graders. It decomposes tasks into pre-execution self-checks, pins mastered rules, prioritizes newly broken behavior, and promotes an edit only when gains outweigh regressions via a Soft-HURT gate. **Why it matters:** Stabilizes self-editing agents against skill forgetting and memory bloat.
- **SCAFFOLD: Toward Warrant-Preserving Evidence Transport for Reusable LLM-Agent Skills** — Cho, Gupta · https://arxiv.org/abs/2611.23990
  SCAFFOLD argues the unit of trust for reusable agent skills is a Warranted Reuse Claim tied to a versioned skill, context, evidence and defeaters. It proposes Warrant-Preserving Evidence Transport to decide which historical evidence stays admissible after context change. **Why it matters:** Gives a principled framing for when a previously validated skill is safe to reuse.
- **Thinking Fast, Anywhere: One System-1 for the Decision Points of Any Agent Workflow** — Li et al. · https://arxiv.org/abs/2611.23751
  AnyS1 mines enumerable decision points from 1,000+ public procedural skills and trains one calibrated 4B pointer model (System-1) to resolve routine choices in a single forward pass, falling back to the large model when confidence is low. Works across three unseen benchmarks and several System-2 families. **Why it matters:** Cuts cost and latency of agent loops with a reusable lightweight decision model.
- **Semantic Context Handoff with On-Demand Evidence for Long-Horizon Agents** — Zheng et al. · https://arxiv.org/abs/2611.24357
  Semantic Context Handoff separates a compact semantic state from addressable action-observation evidence that can re-enter context on demand, with no extra summarization or retrieval calls. On a 150-task SWE-bench study it lifts Pass@1 from 80.0% to 86.9% at essentially unchanged token use. **Why it matters:** Better long-horizon context management for coding agents without losing evidence.
- **QDA: Closed-Loop LLM Quantization Design with Agents** — Li et al. · https://arxiv.org/abs/2611.23388
  QDA lets an LLM agent design a post-training quantization recipe per model and precision. Candidates are scored in minutes by output KL divergence on hidden reasoning traces, then checked with long generations to catch repetition loops, using a library of compatible public PTQ methods. **Why it matters:** Automates quantization design, a costly expert task, with fast evaluation.
- **A Capability Framework for Evaluating Agentic AI Platforms in Regulated Enterprises** — Ali et al. · https://arxiv.org/abs/2611.24039
  A bank innovation lab evaluated ten agentic platforms (open-source, proprietary, hyperscaler) on nine capability dimensions across credit risk, RAG and process automation. Scores split the field into three stable tiers, though very high inter-dimension correlation (Cronbach alpha 0.98) suggests the dimensions are hard to separate. **Why it matters:** Rare industrial evidence for comparing agent platforms beyond vendor demos.
- **LProp: Propagating Latent Uncertainty through Evidence-Conditioned Belief Revision in LLM Agents** — Shi et al. · https://arxiv.org/abs/2611.23564
  LProp preserves uncertainty in a latent-space estimator and revises inherited answer distributions as new evidence arrives, without extra trajectory sampling. It beats baselines on most metrics across QA and math reasoning and uses the fewest inference tokens in all eight propagation settings. **Why it matters:** Stops agents from treating tentative intermediate judgments as facts.
- **Openhagen Worlds: Calibrated Environments for Measuring and Training Scientific Discovery Agents** — Lorup · https://arxiv.org/abs/2611.24711
  Openhagen Worlds is a suite of 27 procedurally generated environments (178 calibrated difficulty levels) where agents run budgeted experiments and commit an answer checked by a deterministic verifier. Levels are admitted only if an oracle solves them and shortcut policies fail. **Why it matters:** Cleaner benchmark and training signal for scientific-discovery agents.
- **Space-X: Self-Evolving Spatial Agents Weaving Clues into Evidence Chains** — Zhang et al. · https://arxiv.org/abs/2611.24004
  Space-X pairs an Execution Agent (acquires and judges evidence) with a Control Agent that diagnoses evidence-chain breaks and revises tools, interfaces, skills, memory and decision rules. It improves spatial-reasoning accuracy across four base models and several benchmarks. **Why it matters:** Shows self-evolving tool/skill revision applied to spatial reasoning.
- **Replay, Don't Resample: Off-Policy Consolidation of Long-Horizon RL Experts** — Yue et al. · https://arxiv.org/abs/2611.24059
  MRPD consolidates per-domain RL experts into one model by replaying the experts' own scored training rollouts in their original order, rather than re-sampling on-policy as in multi-teacher distillation. It is off-policy in origin but quasi-on-policy in practice, and cheaper. **Why it matters:** Cheaper way to merge RL-trained experts in frontier post-training.
- **LoongSage: A Production-Grade, High-Efficiency Agentic RL Framework for Frontier LLMs with Validated Recipes** — LoongSage Team · https://arxiv.org/abs/2610.16352
  LoongSage is a ~14K-line, fully asynchronous agent-native RL framework built on Megatron and SGLang with a single controller and Ray actors. AgentFlow unifies white-box and black-box agents, and sliding windows bound trajectory staleness. **Why it matters:** Lightweight open infra for agentic RL on tool-using LLMs.
- **Agentic On-Policy Distillation Implicitly Reshapes LLMs' ReAct Patterns** — Kong et al. · https://arxiv.org/abs/2611.19244
  Studies how on-policy distillation reshapes ReAct behavior across math, ALFWorld and tau2-bench. Some supervision cuts redundant tool calls while raising accuracy, but ALFWorld supervision collapses tau2 accuracy from 41.5% to 6.6%; selective OPD guided by teacher preference shifts mitigates it. **Why it matters:** Warns of negative cross-domain transfer when distilling agent behavior.
- **Arbor: How Search Policy Shapes Agent Behavior in System Optimization** — Prakriya et al. · https://arxiv.org/abs/2606.12563
  Arbor gives autonomous agents an explicit optimization tree with pluggable search policies, parallel swarms and a sandboxed harness. It yields +40% to +193% on six production inference models and +42.8% on LLM training; ablations show search structure shapes agent behavior. **Why it matters:** Evidence that search policy matters for agent-driven system optimization.
