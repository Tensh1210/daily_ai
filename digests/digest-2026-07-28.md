## 📄 Research Papers — Top Picks
- **The Hitchhiker's Guide to Agentic AI: From Foundations to Systems** — Haggai Roitman · https://arxiv.org/abs/2606.24937
  A full-stack practitioner reference for agentic systems, from the LLM substrate (transformers, GPU systems, SFT/LoRA/MoE, compression, inference optimization) up through alignment and reasoning (RLHF, PPO, DPO, GRPO, reward modeling, test-time scaling). The second half is devoted to agentic AI proper: architectures, tooling, and production deployment. Positioned as a book-length reference rather than a single result. **Why it matters:** One of the few places the whole agent stack is written down coherently, useful as a shared vocabulary for teams building agents.

- **A corrective agentic hybrid RAG and an operations-grounded evaluation for a scientific facility** — Sainju, Jarosz, Cherukara et al. · https://arxiv.org/abs/2607.24663
  APS-RAG is a deployed retrieval platform over decades of Advanced Photon Source institutional knowledge: logbooks, technical docs, wikis, ops chat, maintenance records, and live control-system data. It fuses dense, sparse, and knowledge-graph retrieval with query-type-adaptive reciprocal-rank fusion, then adds a corrective agentic loop and a native-tool ReAct executor. Evaluation is grounded in real operations rather than synthetic QA. **Why it matters:** A rare end-to-end account of hybrid RAG surviving contact with messy real institutional data plus live systems.

- **CRAFT: Learn the Schema, Execute the Plan** — Kolekar, Genc, Shariat et al. · https://arxiv.org/abs/2607.22642
  Enterprise coding agents normally get exhaustive schema and tool docs injected into every prompt, which inflates inference cost and breaks when schemas evolve. CRAFT is a two-stage post-training recipe that moves stable schema knowledge and tool-use behavior into the weights: schema-stripped PLAN supervised fine-tuning first, then execution training. The goal is production-grade consistency in multi-turn analytics. **Why it matters:** Direct attack on the biggest hidden cost of enterprise agents — stuffing schema and tool docs into context on every single call.

- **ConsistencyGate: Preventing Memory Contamination in LLM Agents via Self-Consistency Admission Control** — Yan Zhang, Shibo Li · https://arxiv.org/abs/2607.22962
  Long-running agents write facts into external memory, so one hallucinated fact becomes a false premise for every later step — memory contamination. Existing memory work handles retrieval and capacity but not write-time correctness. ConsistencyGate queries the LLM K times for a soft support score before admitting a candidate fact, and only writes above a threshold; it is model-agnostic and needs no fine-tuning. **Why it matters:** Cheap, drop-in guard for the failure mode that quietly destroys long-horizon agent runs.

- **From Proprietary to Open-Source: Multi-Agent Protocol Distillation in Agentic Search** — Liu, Chen, Song et al. · https://huggingface.co/papers/2607.24280
  Outcome-based RL gives agentic search only sparse supervision, while distilling from proprietary teachers is blocked by hidden logits and mismatched tokenizers. MAPD introduces a style-normalized JSON protocol (task type, reasoning plan, extractive grounding facts) produced offline by a multi-agent system as the intermediate representation. During training the protocol feeds only a privileged branch of the student, supplying a dense distillation signal alongside sparse RL. **Why it matters:** A practical route to transfer closed-model reasoning into open models without logit access.

- **The Physics of Multi-Turn Long-Horizon Planning** — Men, Jin, Liu, Zhao · https://arxiv.org/abs/2607.24720
  A controlled multi-turn environment lets the authors trace where long-horizon planning ability actually comes from across pre-training, post-training, and distillation. Explicit world-model construction via CoT state-transition modeling generalizes better than atomic skills alone, and suboptimal trajectories hurt badly because errors amplify over long horizons. On-policy distillation has a broader effective region than GRPO under low-quality, long-horizon settings. **Why it matters:** Turns "make the agent plan better" into concrete data and post-training choices with measured trade-offs.

- **Co-Harness: Co-Evolving Harnesses and Model Weights for LLM Agents** — Chen, Xiao, Zhu et al. · https://arxiv.org/abs/2607.22688
  Standard agent post-training optimizes weights under a frozen harness — prompts, tools, skills, middleware, memory — leaving trajectory quality outside the objective. Co-Harness alternates harness optimization (an LLM HarnessCritic diagnoses failed runs and proposes validated local edits) with model fine-tuning on trajectories from the improved harness. A 200+ hour autonomous case study shows recovery from crashes and discovery of ensemble strategies without humans. **Why it matters:** Says out loud what agent teams learn the hard way: the scaffolding is a trainable parameter, not a constant.

- **ProvenanceGuard: Source-Aware Factuality Verification for MCP-Based LLM Agents** — Alvarez, Rajan, Mugel, Orús · https://arxiv.org/abs/2606.18037
  MCP agents pull evidence from many heterogeneous tools, so a claim can be supported somewhere yet attributed to the wrong source — cross-source conflation that pooled-evidence factuality metrics miss. ProvenanceGuard consumes MCP traces with stable tool/source IDs, decomposes answers into atomic claims, routes each claim to source-specific evidence, and returns per-claim verdicts plus allow/block. On held-out medical traces it hits block F1 0.802 and source accuracy 0.858, beating source-blind baselines. **Why it matters:** First serious verification layer built on MCP traces themselves, for domains where citing the wrong source is the failure.

- **A New Role for Relevance: Guiding Corpus Interaction in Agentic Search** — Li, Li, Yu, Zhang, Zhou · https://arxiv.org/abs/2607.24223
  Direct corpus interaction (grep-style exploration) gives agents fine-grained evidence operations but wastes turns because the search is relevance-agnostic. RARG turns relevance into an execution prior: it orders documents for ripgrep traversal, seeds entry points with query-relevant paragraphs, and reranks grep matches so informative excerpts surface first. It improves the accuracy–efficiency frontier on browse-QA and reasoning-intensive retrieval. **Why it matters:** Directly relevant to coding and research agents that already navigate corpora with grep.

- **Zing: Social Mind for LLMs** — Zing Team (ICT/CAS et al.) · https://arxiv.org/abs/2607.23740
  An integrated framework for measuring, internalizing, and grounding social intelligence in LLMs. SoMBench spans 17 secondary dimensions and 71 task paradigms over 3,481 expert-verified instances; the best of 20 evaluated models reaches only 72.08% overall, with no dimension near ceiling. Zing then combines SFT, on-policy distillation, and rubric-based RL, and Actio adds a harness-controlled inference architecture for deployment-time grounding. **Why it matters:** Quantifies a capability gap that matters as soon as agents operate over long relationships with real users, not one-off tasks.

- **Data Pyramid for Embodied Manipulation** — Ye, Fu, Lv et al. · https://huggingface.co/papers/2607.24744
  Organizes the embodied data ecosystem as a five-layer pyramid — real-robot, UMI-style, ego/exocentric, simulation, and general vision-language data — structured around the tension between scalability and robot alignment. Recent embodied foundation models are then re-read through their data recipes, relating mixture choices to perception, planning, and action capabilities. Closes with six open challenges including tactile datasets and failure/recovery data. **Why it matters:** Gives robotics teams a shared frame for the data-mixture decision that dominates embodied model quality.

- **VecTree-RAG: Combining Vector and Tree Retrieval for Efficiency and Accuracy** — Zhong, Shi, Wei et al. · https://arxiv.org/abs/2607.23006
  Scientific QA needs two different things — finding relevant papers and locating supporting evidence inside them — which flat passage similarity search conflates. VecTree-RAG splits the tasks: vector search ranks compact document and section representations corpus-wide, then reasoning-guided traversal of source-verified section trees localizes evidence within the shortlist. Document structure is preserved instead of flattened. **Why it matters:** Clean decomposition that fixes the standard RAG failure of ripping claims out of their methodological context.

- **MARS: Multi-hop Adaptive Retrieval and SPARQL Generation for KGQA** — Srivastava, Vollmers, Speck et al. · https://arxiv.org/abs/2607.14561
  MARS answers knowledge-graph questions without fine-tuning by linking question entities to the KG and iteratively retrieving next-hop information. At each step it decides whether to keep traversing or emit the final SPARQL query, adapting retrieval depth per question while staying more predictable than open-ended agentic exploration. It stays competitive with SOTA across three benchmarks including multilingual settings. **Why it matters:** Shows structured, bounded retrieval can match agentic exploration while remaining debuggable and cheap.

- **Melo: A Production LLM-Powered Music Recommendation Agent** — Wang, Guo, Xiao et al. · https://arxiv.org/abs/2607.23718
  Melo runs on NetEase Cloud Music as a deterministic five-node state graph over heterogeneous tools, orchestrated by prompts and a state machine rather than a fine-tuned controller. Two production failure modes drove the design: entity hallucination and long-tail collapse to popular fallbacks; fixes are inference-time entity grounding against the live search index and reflective retry that verbalizes tool-chain failures into the next plan. A one-month A/B test showed >2pp playlist retention lift and 7.8pp fewer entity mistakes offline. **Why it matters:** Rare production agent report with real A/B numbers, and it argues error recovery beats raw model intelligence at scale.

- **RecoWorld: Building Simulated Environments for Agentic Recommender Systems** — Liu, Lin, Yu et al. · https://arxiv.org/abs/2509.10397
  A blueprint for simulators where an agentic recommender and a simulated user interact over multiple turns to maximize retention, letting agents learn from errors without touching real users. The user simulator updates its mindset and emits reflective instructions when sensing disengagement, and the recommender adapts using those instructions and reasoning traces. Supports text, multimodal, and semantic-ID content representations plus multi-agent population simulation. **Why it matters:** Training environments, not model size, are the bottleneck for RL-trained recommender agents.
