## 📄 Research Papers — Top Picks
- **Firefly: Illuminating Large-Scale Verified Tool-Call Data Generation from Real APIs** — Yuxuan Lu et al. · https://arxiv.org/abs/2605.17558
  FireFly inverts tool-data synthesis: a strong LLM first explores real MCP servers along graph-guided DAGs, then tasks are written backward from observed outcomes so labels are correct by construction. A retrieval-augmented simulator caches API results for offline, reproducible RL. The resulting 5,144 verified tasks span 240 servers and 993 tools, and a 4B model trained with GRPO matches Claude Sonnet 4.6 on the held-out set. **Why it matters:** Verified, real-API MCP training data lets small models reach frontier tool-calling quality.
- **$\Delta\tau$-Bench: Pushing Agents Toward a Moving Capability** — Shuofei Qiao et al. · https://arxiv.org/abs/2610.34238
  Δτ-Bench is an executable agent benchmark where tool ecosystems evolve: tools vanish, get replaced, or are superseded by more efficient ones amid noisy docs. It has 1,588 multi-turn tasks across 42 domains and six ecosystem states; the best model/harness reaches only 42.3%, and existing skill-learning gains do not carry over as the ecosystem changes. The authors propose Steward, which jointly maintains tools and procedural skills during execution. **Why it matters:** Real tool ecosystems drift; static benchmarks overstate how well agents and their skills keep up.
- **CoSA: The Conflict of Skills Attack in Real-World LLM Agent Ecosystems** — Yujia Zheng et al. · https://arxiv.org/abs/2610.35082
  Composing individually safe Agent Skills can still violate policy ("Conflict of Skills"); the authors identify four mechanisms from public Skills. CoSA adds locally admitted Skills to a pool without changing existing Skills or permissions. On CoSA-Bench (288 tasks; five LLMs, three harnesses), adding at most 5% new Skills raises the policy-violation rate from 35.0% to 58.5%. **Why it matters:** Per-skill vetting is not enough; skill marketplaces need composition-level security checks.
- **Skill$^{\infty}$: Recursive Self-Improvement for Agent Skill Optimization** — Wangcheng Tao et al. · https://arxiv.org/abs/2610.35434
  Skill^∞ makes skill optimization recursive: a meta agent follows a meta-skill to optimize task skills, then optimizes the meta-skill itself with the same procedure (diagnosing traces, proposing candidates, requesting reviews, allocating budget). Both levels are standard skill packages loaded via native discovery. On 83 SkillsBench tasks it reaches a 60.7% pass rate, ahead of the baselines reported. **Why it matters:** A practical, harness-native path to self-improving agent skills without weight updates.
- **Evolving to Match Capabilities: Improving Harness Self-Evolution via Skill Adaptation** — Zhihao Yang et al. · https://arxiv.org/abs/2610.33024
  Skills that help strong models can hurt weak ones: across 103 task-skill pairs, skills give GPT-5.6-luna +31.1 points but cost Gemma-4-E4B 8.8 points, and in 86% of weak-model failures the violated requirement was already in the skill. The authors distill failure diagnoses into a meta-skill that rewrites skills to fit the executor, gaining 5.1–14.1 points on three weak models. **Why it matters:** Skills should be tailored to the model that runs them; one skill library does not fit all.
- **What Effort Level Should I Choose? On the Economics of Reasoning Effort in LLM Agents** — Kaiser Sun et al. · https://arxiv.org/abs/2610.34491
  Treats reasoning effort as a "credence good" and measures counterfactual effects of effort levels on proprietary and open models across four benchmarks, including long-horizon agent tasks. Higher effort often fails tasks lower effort solved, costs up to 42× more on easy tasks, and changes agent behavior (more self-verification and searching). **Why it matters:** Default to lower effort and escalate selectively; max effort is not a free accuracy win.
- **TellOnce: Correcting Coding Agents Once, Improving Their Future Actions** — Yujun Zhou et al. · https://arxiv.org/abs/2606.13174
  TellOnce turns conversational corrections into persistent, scoped, revisable behavioral rules, plus reusable checks where verification is possible, without updating the model. Agents using Mem0 still violate 57.5% of preference checks; TellOnce cuts violations by 19.3–42.3 points vs. PGMem on ClawArena and also improves new coding tasks on SWE-Together. **Why it matters:** Remembering feedback is not enough; coding agents need it compiled into enforceable rules.
- **Unified Context Evolution for LLM Agents** — Zixuan Zhu et al. · https://arxiv.org/abs/2606.02304
  UCE externalizes agent experience into a typed library of Evolvable Context Units (Memory, Strategy, Workflow, Skill) that are retrieved, scored by usage outcomes and pruned. A scheduler spends generation budget on the weakest type. Without retraining, ALFWorld success rises from 75.4% to 96.3% and WebShop score from 45.1% to 61.3%. **Why it matters:** A gradient-free recipe for agents that keep learning across episodes via context.
- **Trajectory2Gym: Decision-Grounded Compositional Interaction Synthesis for Tool-Use Agents** — Yihao Hu et al. · https://arxiv.org/abs/2610.33568
  Argues successful trajectories are not necessarily good supervision; training data needs compositional coverage and decision grounding (each action justified by visible history). Trajectory2Gym builds executable interactions around under-supported structures and trains only on grounded decisions. Across five Qwen3 sizes it lifts the Tau1/Tau2/BFCL mean by 16.9–29.8 points. **Why it matters:** Data quality for tool-use SFT is about grounded decisions, not just successful runs.
- **Recursive Semantic Divergence for LLM Agent Consistency** — Harshavardhan Abichandani et al. · https://arxiv.org/abs/2610.33012
  Recursive Semantic Divergence (RSD) is an unsupervised, trajectory-level consistency metric adapted from bisimulation: it measures expected cumulative semantic disagreement (via NLI) between two rollouts from the same state. A learned approximator gives a per-turn consistency score without extra rollouts. **Why it matters:** Gives teams a way to measure agent run-to-run reliability, not just task success.
- **ACARE: Agent-Context-Aware Reranker for Iterative Search** — Sahel Sharifymoghaddam et al. · https://arxiv.org/abs/2610.35840
  ACARe is a 4B LLM reranker that scores documents against the agent's broader task and reasoning, not just the generated sub-query. Across benchmarks and agent families it improves retrieval and answer accuracy while reducing search calls, and narrows the gap between small and large agents. **Why it matters:** Context-aware reranking is a cheap way to make agentic search both better and faster.
- **LatentRAG: Latent Reasoning and Retrieval for Efficient Agentic RAG** — Yijia Zheng et al. · https://arxiv.org/abs/2605.06285
  LatentRAG moves agentic RAG reasoning and sub-queries into latent space: thoughts and sub-queries are produced as latent tokens in a single forward pass and aligned with a dense retriever for end-to-end training. A parallel latent decoder translates latent tokens back to text for transparency. **Why it matters:** Attacks the main cost of agentic RAG: latency from long autoregressive thoughts and queries.
- **SkillQR: Agentic Skill Discovery for Reason-Intensive Query Rewriting** — Kenan Jiang et al. · https://arxiv.org/abs/2610.33768
  SkillQR finds that the best query-rewriting strategy depends on the retrieval corpus, not just the model. It automatically discovers sets of reasoning strategies from that corpus and routes each query to one at inference time. Without training data it is competitive with fine-tuned rewriters on BRIGHT and R2MED, with lower latency than iterative rewriting. **Why it matters:** Training-free, corpus-adaptive query rewriting for reasoning-heavy retrieval.
- **Learning to Remember: Advances in Memory Mechanisms for Large Language Models** — Chenye Han et al. · https://arxiv.org/abs/2610.35089
  A survey organizing LLM memory by life cycle, storage substrate and system role, covering nonparametric (text/graph/DB), parametric (KV cache, adapters, weights) and memory for agent evolution (RL, continual learning, context engineering, harness design). Evaluation is treated as a separate cross-cutting axis. **Why it matters:** A useful map of the fast-growing agent-memory design space.
- **Hypergraph-Enhanced Evidence Selection for Long-Context Multimodal Document QA** — Wenxin Zhao et al. · https://arxiv.org/abs/2610.35542
  HyperDoc frames long multimodal document QA as budget-aware evidence selection: it builds a document hypergraph capturing structural, logical and cross-modal relations and selects hyperedges adaptively by query intent and input budget. It beats state-of-the-art baselines on three benchmarks. **Why it matters:** Better evidence selection for VLMs over long PDFs and reports under tight context budgets.
