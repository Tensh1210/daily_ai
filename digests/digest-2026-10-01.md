## 📄 Research Papers — Top Picks
- **SkillSeek: Revisiting Agent Skill Retrieval at Marketplace Scale** — Yang et al. · https://arxiv.org/abs/2609.38822
  With open skill aggregations past 230k SKILL.md packages, selection is the bottleneck. SkillSeek is a plain two-stage IR retriever (BGE bi-encoder plus small cross-encoder, exposed over MCP). On SkillsBench it matches an LLM-mediated retrieval loop, BM25 alone ties or beats it in three of four settings, and per-trial cost drops from $51.30 to $27.54, near the no-skill baseline. **Why it matters:** Standard IR is a strong, cheap default for skill routing; LLM-in-the-loop retrieval is mostly unnecessary.
- **MILO: Automated Harness Discovery via Orchestrated Multi-Agent Evolution** — Jana et al. · https://arxiv.org/abs/2609.38349
  MILO co-evolves full agent harnesses and the search strategy, using island-based lineage memory with rejected mutations as negative evidence, per-island mutator agents, and an orchestrator that grafts, speciates, and revises curriculum. With Opus 4.8 it improves its starting harness by +12.0% on Terminal-Bench 2.1, +28.3% on PaperBench, and +10.3% on DeepSWE, reaching 86.1% on Terminal-Bench 2.1. **Why it matters:** Harness design can be searched automatically and beats hand-built harnesses on hard agent benchmarks.
- **Pretext: Defeating Malicious Skill Detection Frameworks for AI Agents** — Kaisar, Dhar · https://arxiv.org/abs/2609.39607
  Skill scanners pair static checks with an LLM judge, as in NVIDIA's SkillSpector. A white-box attacker moves the payload from code into natural language, frames it as the skill's legitimate purpose, and splits instructions across files. It evades a frozen detector up to 97% and a co-adaptive one up to 77% while still completing the benign task. **Why it matters:** Pre-install skill scanning alone is not a sufficient defense for skill marketplaces used by Claude Code and OpenClaw.
- **Can Agents Trust Their Skills? Uncovering Unsafe Chains of Trust in Skill-Based LLM Agents** — Wang et al. · https://arxiv.org/abs/2609.39065
  TrustProbe traces source-to-sink paths from skill-controlled inputs to security-sensitive operations in agent code, then fuzzes realistic SKILL.md seeds with canaries and validates harm with an oracle. Across 11 open-source agents, eight with over 10k GitHub stars, it found 104 taint-style vulnerabilities. **Why it matters:** Popular agent frameworks admit skill content into privileged paths with too little validation.
- **ActionGuard: Tool Call Authorization under Poisoned Skills** — Han et al. · https://arxiv.org/abs/2609.39450
  ActionGuard intercepts each tool call before execution and has a separate Reviewer decide ALLOW/DENY fail-closed, judging against the trusted user request, a balanced skill profile, recent calls, and local scripts, never the raw possibly-poisoned skill text. Against SKILL-INJECT-style attacks it cuts ASR by 35.5-46.1% relative to existing safeguards. **Why it matters:** Separating authorization context from the poisoned planning context is a practical runtime defense.
- **Do Self-Evolving Skills Generalize to Held-Out Tasks?** — Piao et al. · https://arxiv.org/abs/2609.39148
  Testing five self-evolving skill methods on six benchmarks with fixed splits, only 5 of 21 skills that improved on training tasks kept all gains on test tasks, and 3 kept none. Poor transfer comes from hard-coding task details or generalizing one-off fixes. An LLM judge ranks finished skills well (86% pairwise) but cannot predict single-edit effects; the proposed GSO writes a fresh skill per task from a guide. **Why it matters:** Self-evolving skill gains are often overfit; evaluate on held-out tasks before trusting them.
- **Agent Error Dataset: Scaling 50,000 Error-Diagnosis Pairs for Failure Analysis and Error-Aware Post-Training** — Zhu et al. · https://arxiv.org/abs/2609.40111
  AED contains 50,228 error-diagnosis pairs from 9,961 tasks across 33 environments, 19 harness families, and 23 policy models, with source traces kept. In matched replays, first-proposal corrections raise verifier pass rates from 18.4% to 51.1%. Fine-tuning Qwen3-8B on diagnoses lifts exact-step agreement from 47.2% to 63.6%. **Why it matters:** Failed rollouts become reusable training signal for diagnosis and recovery.
- **EvoSteer: Online Self-Evolving Graph Orchestration via Reference-Anchored Credit Assignment** — Zhang et al. · https://arxiv.org/abs/2609.38661
  EvoSteer lets the orchestrator repair a running multi-agent team mid-trajectory instead of after it ends. Anchored Trajectory Balance assigns per-action credit against a frozen reference, and Validated Skill Admission promotes a skill only if paired evidence passes a sequential test. It outperforms baselines on twelve datasets across QA, math, code, and interactive tasks. **Why it matters:** Online repair plus statistically gated skill admission addresses two weak points of self-evolving orchestration.
- **Harness Continual Learning: Continual Adaptation Beyond Model Parameters** — Kang et al. · https://arxiv.org/abs/2608.19013
  HCL frames continual learning for agents whose harness (prompts, memory, tools, skills, routing) evolves around a frozen model, and defines harness-level forgetting. A Continual Optimizer proposes harness updates and a Continual Evaluator commits them only after checking improvement, historical retention, and validity. Gains exceed 10% over baselines in several settings. **Why it matters:** Harness updates can regress earlier behavior just like weight updates; gate them with retention checks.
- **Hiding in Plain Sight: Decoupling Pretext from Actuation for Skill Poisoning in LLM Agents** — Wu et al. · https://arxiv.org/abs/2609.39352
  The attack keeps a malicious operation intact in a downstream Steering Skill while an upstream Grounding Skill quietly alters environment artifacts to supply the pretext. The actuation then looks legitimate and task-driven when judged in context. An automated framework discovers execution dependencies and synthesizes coordinated skill pairs. **Why it matters:** Per-skill inspection misses attacks that only emerge from cross-skill coordination.
- **EngramBench: A Capability-Grounded Benchmark for Skill-Evolution Harnesses** — Tan et al. · https://arxiv.org/abs/2609.39284
  EngramBench enforces capability overlap without solution overlap, with 30 learning tasks and 13 unseen transfer tasks in multi-hour development cycles driven by simulated users. Skill banks do not solve the last mile of exact implementation, but they steer agents away from trial-and-error, cutting coding time by over 55%. **Why it matters:** Separates genuine skill abstraction from solution leakage when evaluating skill-evolution harnesses.
- **ATTUNER: Recomputation-Free KV Cache Reuse via Query-Side Adaptation** — Chen et al. · https://arxiv.org/abs/2609.36722
  Agents repeatedly load the same skills, documents, and memories; position-independent KV caching avoids re-encoding but loses quality. The authors localize the loss to attention when selecting among multiple artifacts, not positional mismatch. ATTUNER adds low-rank adapters to query projections (<0.05% of parameters), distilled from full prefill, so frozen caches can be reused without recomputation. **Why it matters:** Cheap reuse of cached skill/document KV is directly relevant to agent serving cost.
- **Janus: Evidence-Before-Effect Sagas and Offline-Verifiable Provenance for Agentic LLMs** — Arslan · https://arxiv.org/abs/2609.38266
  Janus writes each step's proposal, verdict, and approvals into a signed, hash-chained log before the effect may run, holding effects at the MCP edge until then. Auditors re-derive every verdict offline from the log and a public key. In a lending workflow, the plain agent paid six over-mandate loans while Janus blocked all six via a deterministic validator. **Why it matters:** Puts auditability on the effect path for agents that move money through tools.
- **PatchHolmes: Agentic Patch Retrieval via Listwise Selection** — Yang et al. · https://arxiv.org/abs/2609.38807
  60-63% of CVEs lack a patch link. PatchHolmes pairs a hybrid retriever with an agent that reads the top-100 candidates listwise and inspects 3-10 commits with budgeted tools. It beats Favia by 25.34% Recall@1 and IRCoT by 31.40%, on a frozen open-weight model over a local repo. **Why it matters:** A listwise agent loop adds large gains over retrieval alone, without fine-tuning.
- **SkillFM: Generating Skills for LLM Agents via Latent Flow Matching** — Zhang et al. · https://arxiv.org/abs/2609.39382
  SkillFM encodes textual skills into a continuous latent space and trains a conditional flow model (improved MeanFlow) to generate task-conditioned skills in one step, decoded to text for a frozen agent. It leads vector-based skill approaches on ALFWorld and Search-QA. **Why it matters:** Generating skills on demand is a viable alternative to retrieving them from a bank.
