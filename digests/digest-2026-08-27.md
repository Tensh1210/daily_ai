## 📄 Research Papers — Top Picks
- **PHMForge: Evaluating LLM Agents on Industrial Prognostics through MCP-Native, Algorithm-Grounded Tools** — Li, Feng, Chen, et al. · https://arxiv.org/abs/2604.01532
  PHMForge is an evaluation environment for LLM agents doing safety-critical Prognostics and Health Management over the Model Context Protocol. It ships 99 SME-authored scenarios across eight industrial asset classes (rotating equipment, aero-engines, lithium-ion cells) on public datasets including NASA PCoE, served through 39 MCP-native tools that wrap published PHM algorithms (C-MAPSS, ISO 10816, Arrhenius capacity-fade models, time-series foundation models). The design explicitly separates protocol fluency from reasoning, instrumentation failures from agent failures, and tool use from tool retrieval — the three conflations prior benchmarks suffer. Inter-rater agreement is Krippendorff's α ∈ [0.74, 0.82] on a stratified 30-scenario sample. **Why it matters:** First MCP benchmark that isolates whether the protocol or the model is what breaks in high-stakes tool use.

- **Corpus2Skill: Distilling Enterprise Knowledge into Navigable Agent Skills for QA and RAG** — Sun, Wei, Hsieh · https://arxiv.org/abs/2604.14572
  Corpus2Skill replaces passive retrieval with corpus navigation: an offline compiler distills a bounded corpus into a hierarchical skill directory, and at serve time the agent drills from a bird's-eye view down through progressively finer summaries to documents, backtracking on unproductive branches. On an enterprise customer-support benchmark it beats single-shot dense, hybrid, hierarchical-retrieval, and agentic RAG baselines on both answer quality and grounding at moderate extra cost, holding under encoder-matched controls. An eleven-dataset study is honest about limits — five wins, three ties, three losses. **Why it matters:** Turns "agent skills" into a retrieval architecture, and reports where the approach loses rather than only where it wins.

- **JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution** — Zhang, Lu, Xie, et al. · https://huggingface.co/papers/2608.25593
  JIT-Agent argues the agent *harness* — memory management, planning strategy, action protocol, tool/skill orchestration — often dominates the base model's contribution, yet is still hand-built per task. It formalizes the harness as a composable, machine-generatable artifact under a fixed four-module protocol and trains a model to synthesize, repair, and self-evolve harnesses for arbitrary off-the-shelf agentic LLMs. With JIT-Agent attached, DeepSeek-V4-Flash surpasses GPT-5.6 on DeepSearchQA (+9.1) and OdysseyBench (+4.3), while GLM-5.2 gains up to +20.2. **Why it matters:** If harness synthesis generalizes, scaffolding becomes a trainable component instead of bespoke engineering per deployment.

- **Retrieve, Match, Escalate: Accurate and Scalable Product Linking with VLM-Distilled Cross-Encoders and Agentic VLMs** — Wang, Xu, Thete, et al. · https://arxiv.org/abs/2608.25037
  A production retrieve-then-match cascade for marketplace-scale entity resolution that spends compute in proportion to difficulty: retrieval surfaces plausible matches, a lightweight text cross-encoder auto-resolves the high-confidence majority, and an agentic multimodal VLM settles the ambiguous remainder by inspecting product images and issuing web searches for evidence present in neither record. The cross-encoder is distilled from millions of dual-VLM-consensus labels, retiring human annotation from the training set. **Why it matters:** A worked template for using expensive agentic models only on the tail, which is how agent economics actually close in production.

- **CaSKG: Counterfactual-Causal Skill Graphs for Scalable Agent Skill Retrieval** — Li, Gao, Ding, et al. · https://arxiv.org/abs/2608.25500
  Skill libraries let agents reuse procedural knowledge but turn memory access into a hard retrieval problem — full-library prompting is expensive, vector retrieval treats skills as independent text, and graph retrieval only helps if the edges are reliable. CaSKG calibrates those edges before retrieval: it builds a high-recall directed candidate graph from semantic, lexical, input/output, and structural evidence, then applies direction-conditioned textual counterfactual probes that remove, substitute, and reorder skill pairs, aggregating with Bayesian smoothing into a state-filtered weighted graph. The graph is built offline and used without changing the downstream agent. **Why it matters:** Makes large skill libraries usable as a drop-in retrieval layer instead of a context-budget problem.

- **AsymSpec: Context-Asymmetric Speculative Decoding for Agentic LLMs** — Liang, Zhang, Brian, et al. · https://arxiv.org/abs/2608.26004
  Agentic pipelines accumulate context across retrieval, tool use, and multi-turn interaction, so deployments compress inputs and lose accuracy. AsymSpec breaks speculative decoding's usual assumption that drafter and verifier share an identical context: a lightweight drafter reads the full input while the large verifier operates on the compressed view, steered by a contrastive δ-fusion of logits under a divergence-aware acceptance gate. Across four agentic capabilities and two end-to-end agent benchmarks it reaches ~90% of full-context accuracy with 1.3–1.7× throughput at 0.2–0.3× the compute cost. **Why it matters:** Recovers most of the accuracy lost to context compression without paying for full-context inference.

- **AgentWorld: Personality-Aware Reliability Evaluation for Agentic Information Retrieval** — Agarwal, Das, Menon, et al. · https://arxiv.org/abs/2608.24076
  AgentWorld simulates agentic IR against Big Five (OCEAN) personality-driven user populations in stateful tool-use environments, scoring with a pass^k consistency metric plus structured fault classification, partial-credit scoring, and dual-control handoff verification. An adversarial Risk Analyser snapshots required-intermediate-state spines and branches Monte-Carlo rollouts under four task-aware perturbation types, quantifying risk via ΔP/ΔT scoring, Dempster–Shafer evidence fusion, and Shapley attack-category attribution. It is demonstrated on a conversational analytics agent across 10 personas, a support agent across 5 tasks × 4 persona variants, and adversarial stress tests. **Why it matters:** Most agent evals assume a uniform, cooperative user; this one measures what happens when real users vary.

- **Eluna: An Agentic LLM System for Automating Warehouse Operations with Reasoning and Task Execution** — Liu, Sreekar, Kujanpää, et al. · https://arxiv.org/abs/2607.08960
  Eluna is a production-deployed system for executing warehouse Standard Operating Procedures, which encode multi-system decision logic under strict time constraints and overload agents when supplied in full. It encodes SOPs as directed acyclic graphs with progressive disclosure and delegates independent tasks to parallel sub-agents, each with persistent code execution and live data access. To meet production latency and accuracy needs it uses asymmetric episodic distillation: a strong teacher improved through episodic error memories, then a smaller student fine-tuned on the corrected trajectories with memory stripped. **Why it matters:** Rare detail on how a deployed agent system meets hard latency and procedural-compliance constraints, not just benchmark scores.

- **StreamPI: Streaming Multimodal Temporal Modeling for Vision-Language-Action Models** — Liu, Hou, Lu, et al. · https://huggingface.co/papers/2608.26067
  State-of-the-art VLA models such as pi0.5 operate single-frame, so they cannot retain past observations or develop precise spatial perception. StreamPI adds temporal reasoning with zero additional parameters via instruction-anchored temporal modeling: each (visual observation, language instruction) pair is an atomic temporal unit with bidirectional attention inside and causal attention across pairs, keeping the instruction a persistent semantic anchor while preserving autoregressive streaming inference. A random-interval streaming training strategy bridges synchronous training and asynchronous real-robot deployment. **Why it matters:** Retrofits memory onto existing VLA checkpoints without growing the model or breaking streaming inference.

- **V-Rubrics: Visual Faithfulness via Rubric-Based Reinforcement Learning** — Tian, Li, Dong, et al. · https://huggingface.co/papers/2608.25580
  Vision-language models produce fluent answers insufficiently grounded in visual evidence, which the authors frame as a credit-assignment failure: scalar outcome rewards say whether an answer is acceptable but not which visual facts are grounded, which reasoning steps are valid, or which instruction constraints were missed. V-Rubrics decomposes reference responses into atomic propositions and scores answers along Visual Faithfulness, Reasoning Consistency, and Instruction Following, giving structured partial credit localized to supporting evidence spans. They build V-Rubrics 50K (50,248 examples) on top of a Qwen3-VL-8B-Instruct SFT checkpoint trained on OpenMMReasoner-SFT-874K. **Why it matters:** Moves multimodal RL reward from "was the answer okay" to "which specific claim was ungrounded."

- **EngiAI: Capability-Based Evaluation of Tool-Connected LLM Agents for Engineering Design** — Molinari, Felten, Massoudi, Fuge · https://arxiv.org/abs/2605.19743
  EngiAI separately evaluates workflow execution, retrieval-assisted parameter selection, HPC orchestration, and training-code authoring using execution traces and resulting engineering artifacts, so failures stay diagnosable instead of lumped into one score. Four LLM backends were run on EngiBench Beams2D and Photonics2D through a LangGraph reference implementation. Proprietary models complete 96–97% of Beams2D workflow tasks versus 55–78% for open-source; tool-decision-heavy Photonics2D workflows drop to 20–53%. For HPC orchestration Gemini-3-Flash completes every tested pipeline while GPT-5-mini reaches 50–70%. **Why it matters:** Quantifies the open/closed gap on real engineering tool use, and shows tool-based decision-making is where everything degrades.

- **ClueWeaver: Reward-Guided Dual-Agent Evidence Reasoning for Compact LLMs on Literary Long Narratives** — Zhu, Yang, Zhang, et al. · https://arxiv.org/abs/2608.25531
  Humanities and social-science research needs close reading of novels, scripts, archives, and case reports, but long-context proprietary models are costly and stuffing a whole narrative into a compact local model misses sparse evidence. ClueWeaver splits the job: a Finder locates answer-critical passages via retrieval-guided segmentation, and an Interpreter derives the answer from that evidence, produces rationales with paragraph-ID citations, and runs a self-calibration pass for high-risk questions. Both agents are optimized with reward-guided RL — Finder rewards emphasize evidence retention and faithful paragraph-ID references. **Why it matters:** A locally deployable path to auditable long-document QA with citation-level traceability.

- **LatentSkill: From In-Context Textual Skills to In-Weight Latent Skills for LLM Agents** — Yu, Zhou, Xu, et al. · https://arxiv.org/abs/2606.06087
  Textual skills injected into the prompt at every step burn context and expose skill content as plaintext. LatentSkill converts them into plug-and-play LoRA adapters via a pretrained hypernetwork, storing skill knowledge in weight space while preserving modular loading, scaling, and composition. It improves ALFWorld success by 21.4 and 13.4 points on seen and unseen splits with 63.9% fewer prefill tokens on average, and Search-QA exact match by 3.0 points with 71.8% fewer tokens per step. Generated skill LoRAs form a structured semantic geometry and can be continuously modulated via the LoRA scaling coefficient. **Why it matters:** Directly attacks the context tax and plaintext exposure that make large skill libraries impractical.

- **Recurrence Meets Transformers for Universal Multimodal Retrieval (ReT-2)** — Caffagni, Sarto, Cornia, et al. · https://arxiv.org/abs/2509.08897
  ReT-2 is a unified retrieval model supporting queries composed of both images and text, searching across document collections where text and images coexist — unlike prior work limited to task-specific VLM fine-tuning on single-modality queries or documents. It uses multi-layer representations and a recurrent Transformer with LSTM-inspired gating to dynamically integrate information across layers and modalities. It reports state-of-the-art on the M2KR and M-BEIR benchmarks across retrieval configurations, with faster inference and lower memory than prior approaches. **Why it matters:** One retriever for mixed-modality queries is the missing piece for multimodal RAG stacks.

- **AgentRoom: Concurrent Multi-Agent Coding in a CRDT-Backed Shared Workspace** — Cho, Lee · https://arxiv.org/abs/2608.23740
  Existing multi-agent coding systems either sequence agents through phase handoffs or pool independent samples without coordination, inheriting the serial limit of token-by-token generation; a single agent abandons up to half of hard tasks with a one-file stub-and-exit. AgentRoom borrows Conflict-free Replicated Data Types from realtime collaborative editing, exposing file-level claim, status, and broadcast as MCP tools over a CRDT-merged shared filesystem. Five frontier coding-CLI models ran four backend tasks with cross-language checks in Python DevBench and Rust+axum. For CLI-stable models, 2-agent AgentRoom abandons fewer tasks than solo with less run-to-run variation. **Why it matters:** Real concurrent editing for coding agents, with MCP as the coordination surface rather than a bolt-on orchestrator.
