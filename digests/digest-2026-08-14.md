## 📄 Research Papers — Top Picks
- **MindMemOS: A Portable and Self-Evolving Memory Operating Layer for AI Agents** — Kaichao Liang et al. · https://arxiv.org/abs/2608.12428
  MindMemOS is a portable memory layer that organizes open-world information with a unified entity-property-time structure and evolves its own schemas. MindMemEvolve runs validation-driven evolutionary search over memory schemas, while a "dreaming" pass merges redundant records and resolves conflicts; implicit corrective feedback acts as a human-in-the-loop signal. A companion MindSkillEvolve turns execution trajectories into reusable skills. It reports 94.03% on LOCOMO, 70.63% on PersonaMem, and +9.2 pts on SpreadsheetBench over the initial-skill baseline. **Why it matters:** Treats agent memory as an evolving OS layer instead of a fixed store, which is the missing piece for long-lived assistants.

- **LycheeMemory V2: Efficient Long-Term Memory for LLM Agents via Semantic Segment-Level Consolidation** — Dongfang Li et al. · https://huggingface.co/papers/2608.12990
  Instead of consolidating memory after every turn, LycheeMemory V2 batches exchanges into semantically bounded segments and encodes each finalized segment into context-independent typed records. Semantic boundary detection preserves event-level and temporal evidence better than fixed-window batching, and lightweight structured indexes support query-planned retrieval. With GPT-4.1-Mini it hits 89.22% on LoCoMo and 92.20% on LongMemEval-S while cutting construction tokens 86.0% / 75.9% versus A-Mem, without raising query-time tokens. **Why it matters:** Shows consolidation *granularity*, not just retention policy, drives the accuracy-cost curve of agent memory.

- **Spatial Memory Agent: Experience-Grounded Procedure Memory for Spatial Intelligence** — Haokai Zhang et al. · https://huggingface.co/papers/2608.12743
  SMA improves a frozen VLM's spatial reasoning with no parameter updates and no external depth/3D tools at inference. In a verifiable environment it collects predictions plus rewards, then uses verifier-guided reflection to distill compact transferable lessons, each scored by a Transfer Reliability Score calibrated from later retrieval outcomes. At deployment it retrieves lessons by semantic filter and similarity-TRS ranking to steer inference. It leads macro average across five spatial benchmarks and four base VLMs. **Why it matters:** A practical parameter-free self-evolution path for agents that cannot be fine-tuned.

- **AutoDesign: Meta-Harness Optimization for Long-Horizon Agentic Design** — Yaxin Luo et al. · https://huggingface.co/papers/2608.13560
  AutoDesign makes the *harness* — not the model — the object of optimization: a meta-harness optimizer guides a code agent to recursively improve the harness from rollout feedback. Evaluated on paper-to-poster generation via the new PosterBench (100 papers, five disciplines), it scores 78.32, beating the closed-source Claude Design by 7.45 points. Plugging the learned DesignHarness into seven code-agent configs lifts the average from 54.99 to 67.39. A full autonomous run took 253 tool calls and 11 editing turns in 40 minutes for under $3. **Why it matters:** Harness/scaffold optimization is a cheap, model-agnostic lever that transfers across agent backends.

- **OmniScientist: An Omni-Modal Omni-Discipline AI Scientist** — Bobo Li et al. · https://huggingface.co/papers/2608.13558
  OmniScientist runs the full research lifecycle — ideation, experiment, writeup — directly over raw heterogeneous evidence rather than precomputed summaries, using a perception layer plus three autonomous agents in a deterministic pipeline. Code-enforced idea, rigour, and claim checks handle novelty screening, statistical validity, execution provenance, and numerical traceability. Across 36 real-data cases spanning five discipline families it produced a compiled manuscript every time (mean score 6.3), and direct perception beat a scalar-features-only variant on all seven dimensions, winning 85% of head-to-heads. **Why it matters:** Quantifies how much of an AI scientist's quality comes from seeing raw evidence rather than summaries.

- **Intern-S2-Preview: Scientific Agentic Foundation Model** — Lei Bai et al. (Shanghai AI Lab) · https://huggingface.co/papers/2608.13505
  A series of scientific agentic foundation models trained via multimodal scientific pre-training then a unified post-training stack: SFT, scalable multi-task RL, black- and white-box agentic RL, and on-policy distillation. Stability techniques include partial rollout with off-policy correction, adaptive length regularization, online speculative decoding, and trace-aware experience assembly. The 397B model extends time-series modelling to numerical forecasting, while a separate Memory Decoder path (Intern-MemDec-4B) lifts Biology-Instructions from 56.92 to 60.32 without touching the frozen backbone. **Why it matters:** One of the most detailed public recipes for agentic RL at frontier scale.

- **GEM: A Generative Embedding Model Bridging Reasoning and Retrieval** — Zhili Shen, Craig Macdonald · https://arxiv.org/abs/2608.13200
  GEM unifies generation and embedding in one model: it first reasons over the query about user intent and relevance criteria, then appends an embedding token that encodes the enriched context for retrieval. This closes the gap between how users phrase complex needs and how surface-matching retrievers interpret them. On reasoning-intensive and instruction-following retrieval it beats its non-reasoning variant and matches baselines built on substantially larger models, and prompting enables test-time compute scaling. **Why it matters:** Reasoning-augmented embeddings let small retrievers punch above their weight on instruction-heavy queries.

- **RAGSieve: Self-Referenced Local Contrast for Knowledge-Poison Detection in RAG** — Xinlong Xu, Yoshua Y. Li · https://arxiv.org/abs/2608.13010
  RAGSieve detects poisoned documents without trusted references or global thresholds by building its reference from the inspected system itself. RSQ scores the top-5 candidates against ranks 6–20 of the same retrieval to spot answer-anchor concentration; RSG compares each document against semantically similar but lexically distinct neighbors to catch coordinated density before queries arrive. RSQ reaches 95.2% AUROC (vs 81.1% for GMTP) and joint deployment drops attack success from 67.4% to 14.0%. **Why it matters:** Practical RAG supply-chain defense that needs no poison labels or clean reference corpus.

- **EviReform: Evidence-Guided Query Reformulation for Multi-Hop Graph Retrieval** — Xinlong Xu, Yoshua Y. Li · https://arxiv.org/abs/2608.13006
  Multi-hop retrieval often can only describe the missing evidence *after* the first passage resolves an implicit entity, yet graph retrieval usually keeps deriving its signal from the original question. EviReform separates revising the retrieval request from aggregating evidence: retrieved passages generate residual queries for the unresolved need, and the original plus residual signals are normalized separately, combined, and propagated across propositions sharing entities. Gains reach +5.59 Recall@5 and +4.50 F1 over the strongest baseline on 2WikiMultiHopQA, HotpotQA, and MuSiQue. **Why it matters:** A concrete fix for the classic "you don't know what to search for until you've searched" failure in multi-hop RAG.

- **When Should Multi-Round RAG Stop? Structured Stopping Judgments in Search-R1** — Weimeng Luo · https://arxiv.org/abs/2608.13237
  Deciding when to stop searching is framed as sequential selection — the deployed policy is set by the first STOP on a trajectory — not independent state classification. A Qwen3.5-2B judge trained on 3,009 states from 900 disjoint HotpotQA questions is bolted onto a frozen Search-R1 pipeline, with checkpoint and threshold picked on grouped validation and frozen before confirmatory evaluation. It cuts retrieval calls 3.70% for a 0.625-point Exact Match drop; the authors explicitly disclaim any accuracy or total-cost win. **Why it matters:** Rare, honestly reported study of the stop-decision that governs cost in every multi-round agentic RAG loop.

- **Structure then Query: Precise Analytical Queries over Unstructured Documents (AnnoIndex)** — Teng Lin, Yuyu Luo, Nan Tang · https://arxiv.org/abs/2608.13384
  AnnoIndex replaces fuzzy vector matching with an Annotation Index: SchemaLoop auto-derives hierarchical annotation schemas from a raw corpus and a lightweight LM extracts values, turning scattered text into a materialized structured index. A Structured Query Engine compiles questions into SQL-extension plans, filters via the index first, applies extraction operators in ascending cost order, and calls LLMs only for the residual fraction — with results merged back to cheapen future queries. It leads baselines on three real datasets at 0.87 average F1. **Why it matters:** Amortizing extraction into an index is a strong alternative to per-query LLM reading over enterprise document piles.

- **TTT-Embed: Test-Time Optimization of Query Embeddings with Ranking-Aware Reward Maximization** — Tianyu Chen, Jiaxing Wu · https://arxiv.org/abs/2608.12569
  TTT-Embed distills reranker/LLM-judge ranking rewards into a lightweight learned vector inside a frozen encoder's output embedding space — no weight access, no ground-truth labels, no index changes, so it works on closed-source embedding APIs. A single scope parameter trades reusability against specificity, and the optimal scope shifts global → task → query as the reward budget grows. Across five embedding models and 15 MTEB tasks it gains up to +8.36 nDCG@10, generalizes to unseen queries and tasks, and recovers capabilities lost to catastrophic forgetting. **Why it matters:** Makes reranking signal a reusable asset instead of a per-query throwaway.

- **Knowledge Synthesis Review Framework: Task-Level Benchmarking of LLM Systems for Evidence Synthesis** — Wafa Shafqat, Mark Patterson, Steven N. Liss · https://arxiv.org/abs/2608.12741
  KSR decomposes evidence synthesis into screening, extraction, analysis, and synthesis, benchmarks systems per task against expert standards, then routes each task to the best performer under continuous expert validation. GPT-5, Claude Sonnet 4, Gemini 2.5 Pro, and NotebookLM were tested on a 244-document subset of a 1,893-document corpus (92.2% inter-rater agreement, κ = 0.80). No system led everywhere: Claude Sonnet 4 took screening accuracy (82.8%), GPT-5 took recall (91.8%) at lower specificity, and all models degraded most on interpretive analysis and cross-source synthesis. **Why it matters:** Concrete evidence that per-task model routing beats picking one model for a whole workflow.

- **A Comprehensive Empirical Evaluation of Vector Database Systems for ANN Search** — Ashen Rashmiks, Tiroshan Madushanka · https://arxiv.org/abs/2608.12812
  A reproducible benchmark of FAISS, Qdrant, Milvus, Weaviate, Chroma, pgvector, and LanceDB across six datasets (SIFT, GIST, MS MARCO, GloVe; 4M+ vectors, 96–960 dims) and 15 metrics covering recall, latency percentiles, QPS, cold start, build time, memory, and storage. On SIFT1M, FAISS leads throughput (866 QPS) but lacks database operations; Weaviate has the best out-of-the-box recall (>99%); Qdrant the best latency among full databases (4.55 ms median); LanceDB trades quality for much faster index builds. The benchmarking framework is released open-source. **Why it matters:** Fills a real gap — most vector DB comparisons measure recall or latency, not both plus resource cost.

- **PlayWorld: Benchmarking World Models with Agent Players over Long-Horizon Objectives** — Kaixin Ding et al. · https://huggingface.co/papers/2608.13552
  Fixed action-conditioned evaluation is unfair across world models because the actions needed to reach the same goal differ per model, so PlayWorld uses multimodal Agent Players that interact toward specified long-horizon objectives instead. The benchmark provides 171 scenarios scored on geometry consistency, interaction fidelity, out-of-sight evolution, and insight evolution, plus basic video-quality and controllability metrics. Across nine state-of-the-art world models, all remain unreliable on long-horizon goals, especially spatial consistency and persistent state evolution. **Why it matters:** Goal-driven agent probing is a more honest world-model eval than replaying canned action sequences.
