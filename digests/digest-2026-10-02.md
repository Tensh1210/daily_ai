## 📄 Research Papers — Top Picks
- **SE-GoS: Self-Evolving Graph-of-Skills for Skill Library at Scale** — Fu et al. · https://arxiv.org/abs/2609.08228
  At thousands of skills, retrieval is the bottleneck. SE-GoS keeps the model, skill library, and retriever fixed and instead evolves the skill-retrieval graph from execution traces via topology, edge-weight, and node-description updates. On SkillsBench one evolution round lifts reward from 52.4% to 59.4%, beating full-library loading, vector retrieval, GoS, and SkillDAG at ~2/3 the input tokens, and transfers to a held-out split (52.9% → 58.3%). **Why it matters:** Skill routing can be improved from experience with no training or skill edits — directly applicable to large SKILL.md libraries.
- **Chaining Skills to Hijack LLM Agents** — Dong et al. · https://arxiv.org/abs/2610.01564
  APEX builds adversarial skill chains where an upstream skill makes the agent write a genuine-looking progress record carrying a false claim of user approval, and a downstream skill uses it to trigger an attacker-chosen action. Across six models on SkillsBench, chains succeed in 74.2% of attempts; on GPT-5.4 the full chain hits 84.3% vs 17.4% when merged into one skill. A prompting defense cuts success to 59.1% but also drops benign task pass rate from 86.7% to 56.3%. **Why it matters:** Per-skill vetting misses cross-skill attacks; third-party skill ecosystems need flow-level defenses.
- **PACE: Provenance-Aware Capability Enforcement for Tool-Using LLM Agents** — Li et al. · https://arxiv.org/abs/2610.01349
  PACE mediates every tool call right before execution, combining path confinement over influence paths with capability/effect verification against authority compiled from the authenticated request. Across eight agent-security benchmarks and three model families it gives strictly lowest attack success in 62 of 79 attack columns (ties in 14) while losing at most three points of utility; adaptive search succeeds 0/30 on out-of-authority targets. **Why it matters:** A practical execution-time gate against poisoned tool metadata, memory, and skills with small utility cost.
- **DeFA: Dependency-Guided Failure Attribution for LLM Agents** — Deng et al. · https://arxiv.org/abs/2610.01256
  DeFA builds an event dependency graph over an agent trajectory, then a failure propagation graph, to pinpoint the decisive error step, responsible agent, and error category; segment summaries let it handle long runs. It achieves top responsible-agent and exact-step accuracy on Who&When / Who&When Pro and also works on multimodal trajectories. Feeding its diagnoses into Trace2Skill skill evolution improves downstream accuracy by 6–15 points. **Why it matters:** Better automatic blame assignment turns failed agent runs into usable signal for skill improvement.
- **VeriHarness: Scaling Agentic Verification for Long-Horizon Tasks** — Zhang et al. (Google) · https://arxiv.org/abs/2610.00972
  Turns the base LLM into an agentic verifier with a workspace, evidence tools, and reusable verification skills: a disagreement resolver checks competing claims against evidence, and a consensus challenger probes shared claims for errors and omissions. Across five long-horizon benchmarks it gives the best selection scores, and evidence-backed revision adds ~6.2–6.4 points over a single rollout with Gemini 3.5 Flash and Claude Opus 4.8. Releases ~26k rollouts (>$100k compute). **Why it matters:** Verification without rubrics or references makes extra test-time compute pay off on long agent tasks.
- **MemFit: Efficient Long-Term Agentic Memory** — Piehl, Ye · https://arxiv.org/abs/2610.00872
  MemFit stores every conversation turn verbatim in an append-only store with LLM-free insertion, indexing turns by segment summaries rather than replacing them. Retrieval is also LLM-free, mixing lexical and semantic signals with cross-encoder reranking, including for multimodal episodes. It reaches state of the art on LoCoMo, MemGallery, and LongMemEval-S while cutting memory construction time and cost several-fold. **Why it matters:** Expensive LLM-driven memory consolidation is not necessary for strong long-term memory.
- **OmniSeek: Native Tool Integration for Multi-turn Audio-Visual Reasoning** — Wang et al. · https://huggingface.co/papers/2610.02181
  OmniSeek turns an Omni-LLM into a multi-turn agent that decides when to look or listen and over which time window, appending retrieved raw audio/visual segments back into context. It is cold-started on the synthesized OmniTraj-170K trajectories, then trained with two-stage RLVR plus an Audio-Visual Necessity reward that discourages single-modality shortcuts. It consistently improves audio-visual reasoning across benchmarks. **Why it matters:** Active, tool-driven evidence seeking replaces brute-force processing of long audio-video inputs.
- **LLM-Driven Multi-Agent Control for Skill-Based Smart Manufacturing** — Köhle et al. (Siemens) · https://arxiv.org/abs/2610.01364
  Each factory module gets an LLM agent plus an MCP tool server exposing its skills via OPC UA, with agents coordinating over MQTT and fed real-time factory state. Comparing orchestrator, peer-to-peer, and monolithic architectures on nine challenges in a six-module factory simulation, monolithic and peer-to-peer reach a 93% solve rate, while only the orchestrator resolves a silent conveyor fault in all runs. **Why it matters:** A concrete industrial MCP deployment pattern with an architecture comparison for agent control of physical systems.
- **Beyond Memory: Harnessing Long-Horizon Agents with Explicit Belief States** — Luo et al. · https://arxiv.org/abs/2610.01415
  PoS is an inference-time framework that maintains explicit belief states — a current world-state estimate plus unresolved task requirements — as the agent's decision context. It validates belief consistency and detects "Belief Trapping" (acting without progress), with recovery tailored to the trap type. It tops all four benchmarks across three LLM backbones. **Why it matters:** Structured state beats raw history replay for keeping long-horizon agents on track.
- **Selection-Based Structured Reasoning: Toward Efficient Multimodal Search Agents** — Zhu et al. (CMU) · https://arxiv.org/abs/2610.01892
  SSR replaces free-form reasoning before each action with selecting among pre-specified reusable reasoning candidates, scored in parallel via teacher-forced prefill over a shared KV cache. On seven multimodal search benchmarks with 2B/4B models it matches same-scale search agents while cutting per-turn reasoning latency by over 90% and total latency by 28–54%. **Why it matters:** Cheap structured reasoning makes small-model agents far faster without losing accuracy.
- **Safety in Self-Evolving Agents: A Survey** — Chen et al. · https://arxiv.org/abs/2610.00093
  Surveys safety for agents that update parameters, memories, tools, skills, and workflows from experience, introducing the SAVER framework (Substrate, Adaptation, Violation, Exposure, Response). It finds that legitimate state can become unsafe when adaptation expands its persistence, authority, or scope, and that research on repair and post-adaptation evaluation is thin. **Why it matters:** Maps the new risk surface created when agents persist and reuse learned state.
- **LawCompass: Navigating from Legal QA to Multi-Agent Deep Research with Grounded Evidence** — Cheng et al. · https://arxiv.org/abs/2610.01027
  LawCompass is an evidence-grounded legal assistant with three functions: Legal QA, professional statute/case retrieval via query rewriting, and a multi-agent Deep Research workflow that decomposes complex tasks into report-level synthesis. Explicit citation links are kept across all modules so users can verify outputs against sources. **Why it matters:** A reference design for citation-grounded deep research in a high-stakes domain.
- **Reconstruct, Practice, Go Real: Guided Self-Improvement for Embodied Agents** — Wang et al. (Berkeley) · https://arxiv.org/abs/2610.02204
  RPG builds practice tasks in simulation from an offline dataset, diagnoses failures using simulator state and videos, and evolves symbolic skills plus the system prompt — with no weight updates. On 22 manipulation tasks success rises from 28.6% to 95.0% over 15 rounds, beating ASPIRE (75.5%) and a GPT-6 Astra Pro agent (60.0%), and the frozen system succeeds in all 30 physical trials. **Why it matters:** Skill-library and prompt evolution transfers to real robots without fine-tuning.
- **InterEvolve: Test-Time Evolution of Reward Programs for Humanoid Loco-Manipulation** — Lin et al. (UIUC) · https://huggingface.co/papers/2610.02196
  An LLM agent evolves staged reward programs for a frozen object-aware forward-backward behavioral foundation model, with a numerical optimizer tuning constants and a library of verified programs. This unlocks loco-manipulation competence that human-designed rewards leave untapped, and evolved skills run on a physical Unitree G1. **Why it matters:** LLM-written reward programs act as a test-time interface for repurposing robot controllers without retraining.
- **Spatial Strategies, Not Actions: Vector-Quantized Geodesics as Tools for LLM-Driven Agents** — Turinici · https://arxiv.org/abs/2610.00613
  Geodesic trajectories are vector-quantized into a small set of behaviors, each given a natural-language description and exposed as a tool the LLM selects online. With Qwen3.6-35B-A3B in a dynamic grid world, a fast non-reasoning setup matches a costly chain-of-thought version's goal-reaching rate, cutting decision time from minutes to seconds. **Why it matters:** Unsupervised tool discovery offloads spatial skill from the LLM to geometry.
