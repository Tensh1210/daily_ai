## 📄 Research Papers — Top Picks
- **SPADE: Self-Play in Adaptive Synthetic Executable Environments** — Bo Liu, Simon Yu, Yiding Jiang et al. · https://arxiv.org/abs/2608.19197
  SPADE is a self-play RL framework where one LLM plays two roles: an Environment Designer that writes complete long-horizon training environments as executable code with a Gym-style reset()/step() interface, and a Reasoning Agent that learns inside them. Agent regret is estimated from the reward gap with and without privileged hints, so the Designer learns to target tasks right at the edge of feasibility. Grounding the Designer on sampled pretraining documents plus an accumulated environment memory proved critical. At 30B scale it beats the strongest fixed-environment baseline by +5.3 average across eight held-out math, science, code and reasoning benchmarks. **Why it matters:** Training environments stop being a hand-curated bottleneck and start scaling with the model itself.
- **Co-RL: Unsupervised Reasoning Emerges from Diverse Cohort in Multi-agent RL** — Yunhao Yang, Yuexin Bian, Yunjie Tian et al. · https://huggingface.co/papers/2608.17253
  Self-rewarding RL removes the need for ground-truth labels but tends to reinforce a model's own biases, collapsing response diversity. Co-RL instead optimizes several decoupled models simultaneously, each rewarded by its peers rather than by itself. Increasing cohort diversity — different model families, sizes, and rephrased samples — reduces the correlated errors that drive self-reinforcing feedback loops. Across text and multimodal domains it beats base models and prior label-free methods, matching or surpassing supervised training with zero ground-truth labels. **Why it matters:** A practical route to keep scaling reasoning RL past the point where humans can still grade the answers.
- **Harness Continual Learning: Continual Adaptation Beyond Model Parameters** — Borui Kang, Jinrui Gu, Junhan Lv et al. · https://arxiv.org/abs/2608.19013
  The paper formalizes Harness Continual Learning: the agent's prompts, memories, tools, skills and routing rules evolve while the foundation model stays frozen, and it names the resulting regression "harness-level forgetting." HCL is instantiated with four execution-facing components (Task Interface, Experience Memory, Capability Map, Adaptive Router) plus guarded harness evolution that separates proposing an update from committing it. A Continual Optimizer proposes candidate harnesses from post-execution feedback; a Continual Evaluator commits only after checking current improvement, historical retention, and validity. Gains exceed 10% relative over baselines on textual reasoning, multimodal perception, and open-world interaction. **Why it matters:** Names and measures the failure mode every agent-framework maintainer hits — a prompt or tool tweak silently breaking behavior that used to work.
- **SkillNet: Create, Evaluate, and Connect AI Skills** — Yuan Liang, Ruobin Zhong, Haoming Xu et al. · https://arxiv.org/abs/2603.04448
  SkillNet is open infrastructure for creating, evaluating and organizing agent skills under a unified ontology, with multi-dimensional scoring across Safety, Completeness, Executability, Maintainability and Cost-awareness. It ships a repository of 600,000+ skills, an interactive platform, and a Python toolkit, plus SkillNet-Gym for benchmarking skill retrieval/utilization/composition and SkillNet-Fabric for task-specific routing via lightweight Wikis. On ALFWorld, WebShop and ScienceWorld it delivers 40% higher average reward with 30% fewer execution steps across backbones. **Why it matters:** Treats skills as durable, versioned, evaluable assets instead of prompt snippets that get reinvented every session.
- **SkillForge: Self-Distilling Agents for Project-Specific Issue Resolution** — Silin Chen, Han Li, Xiaodong Gu et al. · https://huggingface.co/papers/2608.18933
  Coding agents underperform on a specific repo because they lack project-specific knowledge, and existing self-evolving methods either need historical issue-resolution signals or pay heavy per-issue exploration cost. SkillForge instead synthesizes project-specific issues up front by re-implementing test-covered core functionality of the repository. Solving those synthetic issues distills reusable knowledge into entity-grounded skills tied to concrete repository entities. It improves issue resolution over strong baselines with both open- and closed-source models. **Why it matters:** Repo onboarding for coding agents becomes an offline, cacheable step rather than an expensive per-ticket search.
- **FACET: Preserving Source Intent and Executable State in Terminal Task Synthesis** — Kou Shi, Zun Wang, Qisheng Su et al. · https://huggingface.co/papers/2608.18580
  A terminal-agent training task couples an instruction, an initialized environment, a reference solution and an executable verifier — generate these from inconsistent assumptions and the task becomes unsolvable or wrongly graded. FACET reconstructs related agent skills into coherent scenarios, then realizes and repairs the execution environment before emitting task artifacts, so the container state grounds instruction, solution and verifier alike. Execution-based validation repairs only the broken artifact instead of regenerating everything. Fine-tuning on trajectories from these tasks consistently improves Terminal-Bench 2.1 across model scales. **Why it matters:** Makes synthetic agent training data trustworthy by construction rather than by post-hoc filtering.
- **DART-SD: Diamond-topology Aware Retrieval and Tuning for Self-Distillation of Multi-Turn Tool-Calling Agents** — Hangrui Xu, Jiarui Wang, Yang Yang et al. · https://arxiv.org/abs/2608.18524
  When a task has multiple order-independent sub-goals, the optimal solution space is a combinatorial "diamond lattice," and forcing it into full-trajectory imitation causes topological collapse that punishes valid alternative orderings. DART-SD models execution as an Interaction-State Transition Graph, locates the Critical Topological Breakpoint where a rollout goes wrong, and retrieves success-supported recovery references. Training loss is applied only to the generated recovery steps, protecting the valid reasoning prefix from destructive gradients. It improves on complex multi-turn tool-calling benchmarks. **Why it matters:** Explains why naive trajectory imitation kills tool-calling policy diversity, and fixes it with localized correction.
- **How Do Agents Fail on AutoResearch: End-to-End Diagnostic Evaluation on 100 Real-World Frontier Research Tasks** — Yanlin Fei, Nazhou Liu, Xinmiao Yu et al. · https://arxiv.org/abs/2608.14905
  AutoResearchEval spans 100 tasks grounded in published frontier science across 7 domains and the full research lifecycle — ideation, retrieval, execution, analysis, writing, review. Evaluating 8 harness-model combinations produced 800 annotated trajectories, distilled into ARFT, a taxonomy of 45 empirically-grounded failure patterns, using a human-calibrated agent-as-a-judge over complete trajectories and intermediate artifacts. The patterns converge on one root limitation: agents lack a metacognitive loop to check output against evidence, revise, and question their own path. **Why it matters:** Shifts the agent-eval conversation from final-score benchmarks to where in the process things actually break.
- **Beyond LLM-Based Reasoning: Lightweight GNNs for Agent Failure Attribution** — Ting-Wei Li, Yuanchen Bei, Xiao Lin, Hanghang Tong · https://arxiv.org/abs/2608.18575
  Attributing a multi-agent failure to the faulty agent and error type is normally done by prompting or fine-tuning LLMs over long trajectories — expensive, and even SOTA models score poorly. AFANet instead models the trajectory as a graph over step-level semantic signals and agent-level relationships. With far fewer parameters and near-zero inference cost it matches or beats LLM baselines including in-domain fine-tuned models, holds up across GNN architectures, and improves further with cheap test-time adaptation on OOD data. **Why it matters:** Multi-agent debugging may be a cheap structured-prediction problem, not another job for a frontier model.
- **MemFuse: Multi-Source Memory Fusion from Fragmented Observations** — Chao Li, Yuanfa Li, Wenhao Wu et al. · https://arxiv.org/abs/2608.18704
  Real agent memory is fragmented across apps, devices, users and time, but existing memory benchmarks assume a single textual history. MemFuseBench uses a Scene-to-Sensor pipeline to synthesize source-tagged observations, evidence-grounded questions and adversarial distractors, testing temporal reasoning, cross-source fusion and noise robustness. MemFuse itself keeps source-level evidence in an event-layer atomic memory and clusters related events into a causal fusion graph, so retrieval stays traceable to originating sources. It leads all evaluated memory systems under three LLM settings, especially on cross-source questions. **Why it matters:** Provenance-preserving memory is what makes long-running personal agents auditable instead of just confident.
- **CTIFoundry: An Agent-Native Corpus Scaffold for Cyber Threat Intelligence** — Yutong Cheng, Changze Li, Qian Cui et al. · https://arxiv.org/abs/2608.18613
  The authors argue that for agentic threat-intel work the bottleneck is the corpus substrate, not model capability — CTI is still packaged as opaque RAG chunks. CTIFoundry materializes latent structure at build time: a deterministic ontology graph over CVE, CWE, CAPEC and ATT&CK whose official cross-references become typed traversable edges, plus a span-grounded, alias-resolved report layer and hybrid dense+lexical retrieval. At query time it exposes seven typed tools and three procedural skills on a stock open-source harness. On CTIConnect, swapping only the action surface lifts overall F1 by +0.19 to +0.28 across four models and two providers — a small model on CTIFoundry beats a flagship on the flat substrate, without extra search effort. **Why it matters:** Strong evidence that investing in structured tool surfaces beats upgrading the model.
- **From Multi-Agent to Single-Agent: When Is Skill Distillation Beneficial?** — Binyan Xu, Dong Fang, Haitao Li, Kehuan Zhang · https://arxiv.org/abs/2604.01608
  Distilling a multi-agent workflow into a single-agent skill cuts orchestration overhead, but which workflow parts should cross that boundary is unclear. The paper separates capability resources (expanding what an agent can do) from pipeline guidance (constraining which solutions it explores), and shows the same guidance helps method-selection accuracy by +19.6 points while hurting numerical error by -10.3. It introduces Behavior-Outcome Freedom (F) as a pre-synthesis diagnostic for this reversal, and AdaSkill, which keeps validated capability resources, drops runtime orchestration, and inherits pipeline guidance only when F says to. **Why it matters:** Gives a testable rule for when collapsing your multi-agent system into one agent is an upgrade versus a regression.
- **Can David Beat Goliath? On Multi-Hop Reasoning with Resource-Constrained Agents** — Hojae Han, Heeyun Jung, Jongyoon Kim, Seung-won Hwang · https://arxiv.org/abs/2601.21699
  Under realistic compute limits, an RL batch for a retrieval agent contains only a handful of useful reasoning paths, and existing fixes (SFT init, retrieval-level rewards, naive expansion) each waste that budget. David-GRPO injects a few off-policy expert trajectories into RL updates and converts on-policy partial successes into evidence-coverage scores that seed additional continuations. On agents up to 1.5B trained on four RTX 3090s it beats prior low-budget RL baselines on six multi-hop QA benchmarks. Behaviorally, it stops the baseline habit of skipping retrieval or halting after a shallow search. **Why it matters:** Competent multi-hop search agents trainable on consumer GPUs, not a cluster.
- **EgoMemReason: A Memory-Driven Reasoning Benchmark for Long-Horizon Egocentric Video Understanding** — Ziyang Wang, Yue Zhang, Shoubin Yu et al. · https://arxiv.org/abs/2605.09874
  Smart glasses and always-on assistants must reason over days of continuous video, but existing week-long benchmarks test perception (localization, summarization) rather than cross-day reasoning. EgoMemReason probes three memory types — entity (object state over days), event (recall and ordering across hours/days), and behavior (abstracting recurring patterns) — via 500 questions over six core challenges, averaging 5.1 evidence segments and 25.9 hours of backtracking per question. Across 17 MLLMs and agentic frameworks, even the best model falls well short. **Why it matters:** Isolates memory, not perception, as the blocker for always-on multimodal assistants.
- **Hybrid LLM-Augmented Reinforcement Learning Agents for Complex Sequential Decision Tasks** — Christophe D. Hounwanou, John Emeka Eze, Yaé Ulrich Gaba · https://arxiv.org/abs/2608.03502
  LLM agents plan and use tools well but fumble long-horizon tasks needing precise action optimization; RL is the reverse, strong at control and weak at abstraction. This architecture has the LLM emit subgoals, structured plans and contextual guidance while an RL agent refines low-level actions through environment interaction. Experiments show better sample efficiency, higher success rates and more coherent trajectories than RL-only or LLM-only baselines. **Why it matters:** A clean division of labor for embodied and control tasks where pure LLM agents plateau.
