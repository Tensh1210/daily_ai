## 📄 Research Papers — Top Picks
- **Gamer: A Generalist Vision-Language-Action Foundation Model for Long-Horizon Real-Time Game Agent** — Run Luo et al. · https://arxiv.org/abs/2611.18397
  Gamer is a generalist agent framework for long-horizon tasks in 2D GUIs and 3D simulated worlds, combining perception, memory management, and multi-step reasoning end to end. It is pre-trained on tens of thousands of hours of keyboard-and-mouse interaction, then tuned with sparse-thinking instructions and multi-turn RL that handles finite context and sparse rewards. A cloud-edge inference engine serves many game environments concurrently for real-time play. **Why it matters:** Shows a recipe for training computer-use-style agents on raw device input with RL that copes with long horizons.
- **When Agent Skills Go Stale: Runtime Behavior and Selective Maintenance in Evolving Environments** — Omer Faruk Akgul, Shuli Jiang, Yuting Zhang et al. · https://arxiv.org/abs/2611.22525
  The paper tests agent skills reused after the environment changes, finding previously helpful skills can cut task performance by over 10 points or raise execution cost by nearly 40% versus no skill. It proposes selective maintenance, which replays checks from successful runs without extra model calls to detect conflicts, repair skill state, and rebuild when repair is not enough. **Why it matters:** Skill libraries rot silently, and cheap validation-and-repair is a practical way to keep them useful.
- **What Does an Agent Need? Bundle-Aware Agent Resource Composition** — Yunxiao Shi, Tingwei Chen, Dannong Xu et al. · https://arxiv.org/abs/2611.22030
  The authors formulate AgentComposition: jointly choosing a backbone model and a tool-skill bundle to maximize end-to-end execution utility. A retrieval-grounded generator recombines candidate resources through constrained beam search, and a bundle-aware critic ranks whole configurations using an LLM teacher and past successes. AgentSelect-Exec, with real execution, is used to evaluate it. **Why it matters:** Treats tool and skill selection as a joint, bundle-level problem rather than scoring each resource independently.
- **From Relevance to Utility: Rubric Alignment in Yuanbao Search** — Yu Lu, Lixin Zou, Yangqi Chen et al. · https://arxiv.org/abs/2611.22503
  For agentic search, the paper replaces per-document relevance with rubric-aligned supervision across the whole pipeline. A rubric of weighted positive and negative criteria trains a dual-encoder retriever, a multi-task ranker, and a GRPO-based set-level selector that assembles documents for downstream LLM reasoning. **Why it matters:** Retrieval for agents should optimize utility to the reasoner, and this gives a unified training signal for it.
- **Towards Reliable Local Security Agents: Verifiable Post-Training for Linux Privilege Escalation** — Philipp Normann, Andreas Happe, Jurgen Cito · https://arxiv.org/abs/2603.17673
  A two-stage recipe turns a small 4B local model into a security agent: SFT on traces from procedural privilege-escalation environments, then RL with verifiable rewards. On 12 held-out Linux privilege-escalation scenarios, SFT nearly doubles the baseline success rate. The setup is designed to avoid benchmark leakage. **Why it matters:** Shows small local models can be trained into capable agents on automatically verifiable tasks, useful when data cannot go to the cloud.
- **Do LLM Agents Still Need to Be Told How to Self-Improve?** — Shobhita Sundaram, Cansu Sancaktar, Phillip Isola · https://arxiv.org/abs/2611.23219
  A frozen LLM agent gets a compute budget and tools to collect experience and edit text documents, with no externally imposed loop, using gameplay as the testbed. Sufficiently capable models do self-improve, showing strategies similar to self-regulated learning and self-generated curricula. The authors also study how well the learned text artifacts transfer. **Why it matters:** Suggests hand-designed self-improvement loops may matter less as models get stronger.
- **JET: Just-Enough Exploration Tuning for Efficient Tool-Calling Agents in Repository-Level Question Answering** — Yoonho Choi, Taehyeon Han, Seonghyeon Lee et al. · https://arxiv.org/abs/2611.22539
  Agents often keep calling tools after they already have enough information, and SFT on expert trajectories propagates this over-exploration. JET truncates each training trajectory where the information becomes sufficient, inserts a rationale for answering there, and up-weights that rationale in the loss. On two repository QA benchmarks with 8B models it cuts tool calls by 11 to 33%. **Why it matters:** Fewer redundant tool calls means lower latency and cost for code-exploring agents.
- **ANCHOR: Assessing Naturalistic Constraint Hierarchies and Ordering in Repository-Grounded Agentic Coding** — Wenqiang Zhu, Xinping Lei, Zhiyi Lai et al. · https://arxiv.org/abs/2610.16859
  ANCHOR benchmarks whether coding agents follow developer constraints such as modification scope, workflow order, validation, tool use, and reporting, not just whether the patch works. It has a 10-category, 78-type taxonomy and a trajectory-grounded evaluation of both diff and execution across 358 tasks, 19 agent configurations, and 10 models. **Why it matters:** Measures the gap between a correct patch and an acceptable one, which current coding evals largely ignore.
- **TeleChat to Xing4: Advancing Frontier Agentic Models on Domestic Chips and Frameworks** — Xingchen AGI Lab et al. · https://arxiv.org/abs/2611.22115
  A technical report on the Xing 4 LLM series, including pretraining a 285B-parameter model on 8,192 Ascend 910C cards with MindSpore HyperParallel. It covers architecture choices such as sparse activation, attention design, and speculative decoding, plus agentic post-training on TeleGym, a unified agent execution platform. **Why it matters:** A rare detailed look at frontier-scale training and agentic post-training on a non-Nvidia stack.
- **RAG in a Trenchcoat: When Minimal Memory Is Enough for Agentic Systems, and When It Isn't** — Jingyu Liu, Zongze Li, Zach Xu et al. · https://arxiv.org/abs/2611.22179
  BRIDGE, a deliberately minimal RAG memory with hybrid BM25 plus cosine retrieval and one LLM call per ingest or query, matches prior SOTA on LongMemEval-S and BEAM and beats the best baseline on EverMemBench by 5.7-6.3 points. The authors argue benchmarks score what memory retrieves, not what it enables, and add five adversarial probes that need applying a remembered rule or pattern. **Why it matters:** Questions whether elaborate agent-memory machinery earns its cost and proposes harder tests of memory use.
- **Thinking Harder Doesn't Lead to Better Choices: Reasoning Effort Increases the Confidence but Not the Correctness of LLM Shopping Agents** — Adi Krishnamoorthy, X. Y. Han · https://arxiv.org/abs/2611.22033
  Ten frontier models were benchmarked on product choice across WebShop, Amazon SQID, and Wayfair WANDS. Raising reasoning effort did not improve decision quality in a statistically meaningful way, but it did raise stated confidence significantly. The paper also measures calibration of that confidence. **Why it matters:** More reasoning budget buys confidence, not correctness, which matters for agents that spend money on a user's behalf.
- **Long-Context Generation Is a Sampling Problem (When You Turn Up the Heat)** — Allen G. Roush, Minh Nhat Nguyen, Ravid Shwartz-Ziv et al. · https://arxiv.org/abs/2611.22148
  Across 29 open-weight models (1B to 122B) and ten benchmarks including SWE-bench Verified, samplers that keep the candidate pool small and steady hold accuracy as temperature rises. At temperature 2, coding agents with top-p, top-k, or Top-H resolve 0 of 100 issues while top-nsigma resolves 46 to 62. Top-nsigma keeps a median 100% of its temperature-1 score versus 26% for top-p. **Why it matters:** Choice of sampler, not more training, can decide whether long agentic generation survives high temperature.
- **ToolFlood: Beyond Selection -- Hiding Valid Tools from LLM Agents via Semantic Covering** — Hussein Jawad, Nicolas J-B Brunel · https://arxiv.org/abs/2603.13950
  ToolFlood attacks the retrieval stage of tool-augmented agents by injecting a few attacker-controlled tools whose metadata is crafted to span many user queries in embedding space. They dominate the top-k results and push all benign tools out of the agent's context. Tool generation uses an LLM plus an iterative greedy coverage selection. **Why it matters:** Shows embedding-based tool retrieval, common in MCP-style setups, is itself an attack surface.
- **The Resolution Hypothesis: Agent Evolution's Key Is Identifying Improvements** — Yuanhao Zeng, Shaocheng Lan, Ao Lu et al. · https://arxiv.org/abs/2611.23068
  Over seven evolution methods, six models, and 10M+ LLM calls, the authors find helpful candidate artifacts (prompts, skills, memories) exist but selection is no better than random at telling them from harmful ones. Typical margins of a few points between methods are smaller than the gap between two runs of the same method. **Why it matters:** Suggests agent-evolution gains are limited by noisy evaluation, and many published rankings rest on luck.
- **FLARE: A Full-Lifecycle Dense Supervision Paradigm for Long-Horizon Coding Agents via Generative Reward Model** — Jingxuan Xu, Gang Wu, Yanan Wu et al. · https://arxiv.org/abs/2609.23808
  FLARE replaces sparse pass/fail rewards for long-horizon software-engineering agents with step-level feedback from a lightweight Generative Reward Model distilled via causal-chain backtracking (RADAR). At inference it acts as an active scaffold that intercepts high-risk steps and re-executes locally, and it also supports post-training. **Why it matters:** Dense, step-level credit assignment could cut wasted compute on failed coding-agent trajectories.
