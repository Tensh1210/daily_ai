## 📄 Research Papers — Top Picks
- **Skill Following: Evaluating Actual Skill Use in Retrieval-Enabled LLM Agents** — arXiv cs.CL · https://arxiv.org/abs/2609.00549
  Standard agent evaluations compare retrieved vs non-retrieved tasks, which bakes in selection bias and hides whether retrieving a skill actually helped. The authors formalize Skill Following and introduce the Retrieval-Invoked Actual-Use Effect (RAE), a matched same-task comparison between skill-enabled and skill-disabled runs, conditioned only on tasks where the agent did retrieve a skill. They evaluate 17 LLM agents under this protocol. **Why it matters:** Gives a causal-style metric for whether a skill/tool library earns its context cost.

- **Making Prospective Memory SLM-Shaped: Typed Intention Stores for Small-Model Agents** — arXiv cs.AI · https://arxiv.org/abs/2609.01272
  Prospective memory — firing a deferred intention at the right future cue — remains hard for frontier models, with the best PM-Bench scaffold at 65.1% Set-F1. The paper argues the loop is schema-constrained state tracking, not open-ended reasoning, and proposes the Prospective Intention Store (PIS), which keeps lifecycle logic in code and gives the model only scoped language work. The scaffold is training-free: no selector fine-tuning, no trajectory distillation. **Why it matters:** Typing the action space lets small models handle agent memory tasks assumed to need frontier scale.

- **Learning What to Retain: Gated-Memory Routing for Efficient Collaboration in Multi-Agent LLM Systems** — arXiv cs.CL · https://arxiv.org/abs/2609.00237
  Routing multi-agent collaboration from the query alone cannot adapt to mid-run progress or errors, but routing from full execution history forces every later decision to reprocess redundant steps. The authors propose gated memory routing that keeps a compact, high-utility state instead of the whole trace. This targets the cost blowup of history-conditioned orchestration. **Why it matters:** Practical answer to context bloat in multi-agent orchestration without losing adaptivity.

- **Evaluating Multimodal LLMs as Generalist Vision-Language-Action Agents for Drone Control** — HF Papers · https://huggingface.co/papers/2609.01404
  DroneCATS-Agent drops an MLLM directly into a drone control loop with the entire action space declared in the prompt — no fine-tuning, no function-calling schema. The companion DroneCATS benchmark treats the model itself as the independent variable across commanding, approaching, tracking, and searching. The agent must yaw, search, deliberate under uncertainty, and self-declare arrival. **Why it matters:** Clean measurement of how much embodied control comes from the model versus the scaffold.

- **Compile, Don't Memorize: A Context Compilation Architecture (CCA) for In-Context Learning** — arXiv cs.CL · https://arxiv.org/abs/2609.00759
  On benchmarks graded against every detail of a long context, strong open-weight models pass only 12–16% of tasks — one overlooked rule fails the whole response. The paper blames the single-pass "read-and-reason" paradigm and tests explicit context compilation against long-context strategies like gist retrieval. **Why it matters:** Reframes long-context brittleness as an architecture problem, not a scale problem.

- **SkillRet: A Large-Scale Benchmark for Skill Retrieval in LLM Agents** — arXiv cs.AI · https://arxiv.org/abs/2605.05726
  As skill libraries grow, invoking skills by name stops working and retrieval becomes the bottleneck under tight context and latency budgets. SkillRet supplies 16,129 public agent skills as a realistic large-scale retrieval benchmark. It targets a gap where practical importance far exceeds existing evaluation coverage. **Why it matters:** Directly relevant to anyone running a large skill/MCP library — selection quality is now measurable.

- **Explore More, Drift Less: Outcome-Only Reinforcement Learning Can Suffice for Long-Horizon Interactive Agents** — arXiv cs.AI · https://arxiv.org/abs/2609.01245
  Common wisdom says outcome-only RL hits a ceiling on small open models, prompting denser rewards, SFT priors, skill libraries, or multi-agent scaffolds. The authors argue the ceiling is an artifact of signal starvation: group-relative RL with sparse outcome rewards only yields gradient when a rollout group mixes successes and failures, so under-scaled exploration silences exactly the informative tasks. Fixing exploration scale recovers the learning signal. **Why it matters:** Suggests much agent-RL complexity compensates for a fixable exploration bug.

- **Harness-of-Harness: Multi-Day Autonomous Software Development with Continual Improvement** — HF Papers · https://huggingface.co/papers/2609.01481
  HoH wraps existing coding-agent harnesses in iterative planning-coding-testing loops so agents can build complete software from high-level requirements without human intervention. It balances repair against capability growth, scopes development into small verifiable increments, and separates implementation-time testing from independent evaluation. The target is multi-day autonomous runs that keep improving rather than plateauing. **Why it matters:** Structure for long-horizon coding agents that avoids the usual drift-and-regress failure mode.

- **HiDiffTIR: Hierarchical Difficulty-Aware Policy Optimization for Multi-Turn Tool-Integrated Reasoning** — arXiv cs.CL · https://arxiv.org/abs/2608.21863
  Existing RL for tool-integrated reasoning assigns uniform trajectory-level advantages and treats every correct tool call as equally valuable, ignoring difficulty differences across trajectories and steps. HiDiffTIR adds hierarchical difficulty-aware policy optimization to sharpen the learning signal. The result better discriminates trivial from challenging tool-use patterns. **Why it matters:** Credit assignment for tool calls is where multi-turn agent RL currently loses most of its signal.

- **Delegation Without Trust: An Empirical Gap Analysis of Identity, Authorization, and Runtime Governance in Multi-Agent LLM Systems** — arXiv cs.AI · https://arxiv.org/abs/2609.00267
  Agents hold credentials, call services, and spawn sub-agents, turning "who is authorized on whose authority" into an urgent open problem — made worse because the deciding component can be hijacked. The paper argues for evaluating agent security under an untrusted-model assumption: a fully prompt-injected agent still must not exceed explicitly delegated authority. It presents an empirical gap analysis against that standard. **Why it matters:** The right threat model for anyone giving agents real credentials.

- **Dr. Claw: An AI Scientist Workspace for Vibe Research** — arXiv cs.CL · https://arxiv.org/abs/2609.00365
  CLI coding agents can already sustain long file-editing sessions, but research still fragments across chat, IDEs, terminals, and writing tools, losing the decisions that make it auditable. Dr. Claw is an open-source workspace wrapping existing coding-agent executors in a human-in-the-loop, auditable workflow, with persistent state objects, a reusable skill library, and multi-executor coordination. It deliberately avoids adding another autonomous agent. **Why it matters:** Auditability and reusable skills as first-class workspace features, not agent afterthoughts.

- **Control-Data Flow Separation: Stable Prompt Optimization in Multi-Agent LLMs** — HF Papers · https://huggingface.co/papers/2609.00621
  Prompts in multi-agent systems entangle two roles: generating task content and specifying execution-critical protocol (routing, output format, termination) that the surrounding code depends on. A content-focused prompt edit can silently corrupt the protocol and break the whole pipeline. The authors separate the two by exploiting that protocols are structured while task content is unstructured language. **Why it matters:** Explains a common, confusing class of multi-agent failures after "harmless" prompt tweaks.

- **MemoryWalker: Stop Training Agents on Contexts They Never Saw** — arXiv cs.CL · https://arxiv.org/abs/2609.00865
  Production harnesses like Claude Code and Qwen-Agent compress context during rollout, so training under compression turns the learning object into a tree of branched histories rather than a sequence. Existing linearizations either retain the rightmost path (time-travel leakage) or replay depth-first (train-inference mismatch). The paper offers two exact, gradient-equivalent corrections: LogitTree segmented traversal and a packed 4D attention mask. **Why it matters:** Makes RL training consistent with the context compression agents actually run with in production.

- **Learning to Remember: End-to-End Training of Memory Agents for Long-Context Reasoning** — arXiv cs.AI · https://arxiv.org/abs/2602.18493
  Long-context LLMs and RAG defer state tracking and evidence consolidation to query time, which breaks when facts evolve or answers depend on latent state. Unified Memory Agent builds query-agnostic external memory once from a stream and reuses it across future QA sessions, maintaining a structured Memory Bank via CRUD operations. Task-Stratified GRPO supervises memory maintenance using the mean reward of QA trajectories branching from each sampled memory state. **Why it matters:** Trains the memory-writing policy itself instead of hoping retrieval compensates later.

- **AgentProv: Auditing Agentic LLM API Providers via Tool-use Policy Probes** — arXiv cs.CL · https://arxiv.org/abs/2609.00052
  Commercial LLM APIs may silently substitute, quantize, or wrap the advertised backbone, and existing audits infer identity from the text output channel. That is fragile for agentic APIs, since modern serving stacks discard text and expose only structured actions on tool calls, and provider-injected system prompts can make honest providers look dishonest. AgentProv probes tool-use policy as the identifying signal instead. **Why it matters:** A verification method for whether the model you pay for is the model actually serving your agent.
