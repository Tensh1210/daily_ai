## 📄 Research Papers — Top Picks
- **ToolSpace: Scaling Tool-Centric Environment Synthesis for Long-Horizon Agents** — Guanting Dong et al. · https://arxiv.org/abs/2611.05036
  ToolSpace reverses the usual MCP environment pipeline: it mines data, state and retry dependencies from real MCP execution traces using deterministic rules, then clusters the tool-composition graph into environments. Tasks come from state-aware random walks and are kept only if they replay successfully. Harder benchmark versions drop 7 frontier models by up to 38.2 points, and across seven long-horizon benchmarks it raises Qwen3.6-35B-A3B from 23.0 to 41.0. **Why it matters:** environments grounded in real tool traces train and test agents better than LLM-judged ones.
- **MCPGuard: Finding Conformance Gaps in MCP SDKs via Dual-Track Analysis and Dynamic Adjudication** — Xikai Sun et al. · https://arxiv.org/abs/2611.03662
  MCPGuard checks whether MCP SDKs actually enforce the specification, combining a JSON Schema structural track with LLM audits of normative prose, then validating candidates with PoCs. It confirms 13 findings in the official Python 1.26.0 SDK and 19 in TypeScript 1.29.0, none exposed by two black-box baselines. Tests on open MCP servers show the gaps can propagate downstream. **Why it matters:** anyone building on MCP inherits SDK validation gaps that endpoint tests do not reveal.
- **SLATE: A Large-Scale Benchmark for Long-Horizon API Selection in E-commerce Tool Use** — Rongzhe Wei et al. · https://arxiv.org/abs/2611.03982
  SLATE tests API selection over a roughly 1,000-tool e-commerce library, using a deterministic simulator and an end-to-end success metric that credits any valid trajectory. Across six open decision models and their base language models (3B to 12B parameters), the best model completes only 5.0% of tasks. The benchmark, simulator and harness are released. **Why it matters:** small-model tool use remains far from reliable once toolsets reach enterprise size.
- **Voluntary Servitude: Weaponized Safety Warning Mechanisms for Controlling AI Agents** — Ilan Zendel et al. · https://arxiv.org/abs/2611.04393
  A single fabricated hazard written as an ordinary review can steer an agent through its own harm-avoidance, with no command for a detector to catch. These payloads work about as often as instruction injection (60.4% vs. 66.0%), and behind a filter they are 1.7–4.4x more effective; they also transfer to production browser agents. Adding a corroboration requirement to the agent's instructions removes roughly 95% of exposure against a non-adaptive attacker. **Why it matters:** injection detectors miss this attack class, but a simple instruction change largely mitigates it.
- **D-Skill: Distilling Teacher Knowledge through Agent Skills** — Shuo Yuan, Dacheng Li, Joseph E. Gonzalez · https://arxiv.org/abs/2610.28914
  D-Skill treats a strong teacher model as a black box and turns the differences in paired rollouts into a natural-language skill document for a smaller student, built offline with no weight updates. It closes 75%–95% of the teacher-student gap across SpreadsheetBench-Verified, ALFWorld and chess puzzles. Within a model family, the student costs 5.7x–8.3x less per task than the teacher. **Why it matters:** cheap models can inherit frontier behavior through a readable document rather than retraining.
- **From Watching to Steering: Enabling Human-Coding Agent Collaboration through Execution Traces** — Xiaoke Yan et al. · https://arxiv.org/abs/2611.04466
  Vibetrace, built on OpenCode, shows agent runs as interactive traces, lets users fork from earlier steps with targeted corrections, and distills traces plus feedback into reusable skills. On SWE-bench Verified, distilled skills cut input tokens by 23.0% and cost by 15.5% while raising pass rate from 65.0% to 68.0%. User studies report better accuracy and efficiency than log-based interaction. **Why it matters:** forking from a good step beats restarting a long coding-agent run, and the corrections become reusable.
- **MEMORY Wins All: Indirect Bias Injection Attacks via Social Media Content** — Minjae Seo et al. · https://arxiv.org/abs/2608.22061
  SBIA poisons personal-agent memory using ordinary-looking social media comments plus a distributed summarization skill whose curation rule admits them, so the agent writes the memory itself. On BiasBench with seven LLMs on OpenClaw, it reaches at least 96% attack success across models and 91% on GPT-5.5 in four downstream tasks. The skill passes all eight evaluated malicious-skill scanners and ClawHub's scanning pipeline; a proposed memory boundary defense detects 82.1% of entries at 5.6% FPR. **Why it matters:** third-party skill marketplaces and agent memory together form an attack surface current scanners do not cover.
- **MDSKILL: Learning to Internalize Skill Memory through Multi-View Distillation for Efficient Dynamic Agent Self-Evolution** — Dian Jin et al. · https://arxiv.org/abs/2611.05313
  MDSKILL organizes noisy self-generated skill memories into state grounding, action planning and execution control views, then uses on-policy self-distillation to consolidate them into one policy. It improves on state-of-the-art by up to 7.1% on ALFWorld and 8.1% on WebShop without additional computational overhead. **Why it matters:** self-evolving agents need to clean conflicting memories before learning from them, not just store more.
- **EvoMemState: Evolving Memory State for Personal Agents** — Zhishang Xiang et al. · https://arxiv.org/abs/2611.03743
  EvoMemState adds two states to stored facts: Relational States tracking validity, scope and relations between facts, and a Reasoning State generated per request by an RL policy. Experiments on long-term dialogue and memory-use benchmarks show improved retrieval completeness and memory-grounded accuracy over existing memory systems. **Why it matters:** treats how facts update and conflict as first-class, which plain fact stores miss in long-term assistants.
- **EMBERS: Empirically Motivated Robustness Testing of Deep Research Systems via Defect-Guided Fuzzing** — Shuochuan Li et al. · https://arxiv.org/abs/2611.03723
  From 1,932 execution trajectories of three Deep Research systems, the authors identify nine recurring defect categories across subquestions, search and final reasoning. EMBERS uses them to generate stage-targeted test inputs, reaching 3.21x the failure-discovery throughput of the strongest baseline across 16 settings. **Why it matters:** gives a practical way to stress-test multi-stage research agents rather than only measuring task success.
- **Axion 1.0: Open Agent Foundation Models, Simplified** — Yuqi Jia et al. · https://arxiv.org/abs/2611.03233
  Axion 1.0 is an open agent foundation model trained in three stages: two supervised fine-tuning stages, then reinforcement learning, without mid-training, DPO or on-policy distillation. It is reported as competitive with leading commercial models on several agentic benchmarks. The full recipe is released, including data construction, verification, prompts and training code. **Why it matters:** a reproducible recipe, beyond open weights, for training agent-capable models.
- **CacheBridge: Efficient Cross-Model KV Transfer for Multi-Model LLM Serving** — Xingyu Qu et al. · https://arxiv.org/abs/2609.00891
  CacheBridge transfers KV caches between different models so a switch does not need to re-prefill history. In Qwen3 14B→32B agent serving on τ-bench, it cuts mean TTFT by 30–98% versus re-prefill at 1–24 QPS with comparable task success. It also uses 8–12x less mapper memory than a closed-form mapper. **Why it matters:** routers and model cascades get cheaper when switching models no longer costs a full prefill.
- **Route Anything: A Study of Model and Policy Routing for General-Purpose AI Systems** — Pengfei Zhou et al. · https://huggingface.co/papers/2611.05275
  This study builds a trajectory matrix of 374,401 scored runs from 452 candidate configurations across 25 benchmarks, covering language, image, video, speech, coding agents and robotics. Per-input oracle routing beats the best fixed candidate by 5.4 points, while learned routers beat it by 0.3 points across 16 benchmarks. Routing raises efficiency 8.82x on average against the reference model. **Why it matters:** quantifies what routing gains on cost versus quality, and the large gap between oracle and learned routers.
- **From Logs to Faults: Reference-Free Fault Localization for Retrieval-Augmented Generation Pipelines** — Hira Naveed et al. · https://arxiv.org/abs/2611.03725
  RAGLog finds faulty RAG stages from execution logs alone, with no reference answers or code instrumentation, using rule-based, embedding-based and LLM checks. With Claude Haiku 5.5 it reaches F1 0.73 on natural faults versus 0.58 for Claude Code and 0.52 for Codex, at about five seconds and US$0.005 per run. It is released as open source alongside a dataset of 3,134 labeled runs. **Why it matters:** a cheap way to debug RAG pipelines without test sets or code changes.
- **RecoAtlas: A Benchmark and RL Environment for LLM Recommendation Agents Optimizing Set-Level Utility** — Imad Aouali et al. · https://arxiv.org/abs/2605.18805
  RecoAtlas gives shopping agents a toolkit for retrieval, complementarity and diversity, evaluating their recommendation reports against behavioral reference sets and a learned bundle-level reward. Performance scales with model capacity and improves with stronger tools, but semantic plausibility does not necessarily translate into behavior-grounded utility. **Why it matters:** a recommendation that sounds reasonable may not be one users act on, so evaluation needs behavioral ground truth.
