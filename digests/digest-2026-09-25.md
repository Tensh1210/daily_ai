## 📄 Research Papers — Top Picks
- **World Action Agent: Harnessing VLMs for Robot Manipulation via World Action Rehearsal** — Yehang Zhang, Haojian Huang et al. (HF trending) · https://huggingface.co/papers/2609.29964
  WAA is a multi-agent harness that lets general-purpose VLMs pilot robots with basic tools inside a visual "action workspace": auto-selected contact views, editable action rehearsal (optionally via an Imagination Agent), and in-view correction. It evolves multimodal skills from expert videos and human teaching, consulted through a Skill Agent, and its traces train smaller VLMs. It reaches a SOTA 75.6% average on LIBERO-Pro, beating end-to-end VLAs and code-as-policy agents. **Why it matters:** the harness plus evolved skills, not a bespoke action model, is what drives manipulation performance here.
- **Progressive Skill Discovery as Access Control for Tool-Using LLM Agents (skilder)** — Michael Stettler, Benjamin Girardet et al. · https://arxiv.org/abs/2609.28693
  skilder packages capabilities into "roles" (skills, tools, instructions, plus limits). Agents start from a minimal role catalog and learn the roles a task needs, receiving tools only inside learned skills via a single MCP server that enforces scope deterministically. Across 13 tasks, 6 models and 10 runs each, no unauthorized tool call or parameter violation (e.g. spending-limit breach) executed once a governed call was issued. **Why it matters:** it moves agent governance from prompt "advice" to hard MCP-level enforcement, which matters for large enterprise toolsets.
- **Qwen-Planner-Agent: A Closed-Loop AI-for-AI Framework for Real-World Mobile Planner Agents** — Tingyu Qu, Weigao Sun et al. (HF trending) · https://huggingface.co/papers/2609.29892
  A closed-loop framework where agents build the mobile planner agent: a human-gated agentic data flywheel (task construction, trajectory collection, curation), SFT cold start plus hybrid-environment online agentic RL, and model–harness co-evolution over memory and skills. It introduces CARE (Competence-Aware Reward-and-Advantage Engineering) to cut reasoning and tool-use cost without losing performance. **Why it matters:** it is a concrete blueprint for AI-for-AI development of long-horizon, device-grounded agents.
- **A Wrong Turn Does Not Ruin the Journey: Deviation-Guided Skill Self-Evolution for LLM Agents** — Yichun Feng, Jiawei Wang, Haozhe Sun · https://arxiv.org/abs/2609.29154
  SkillPivot finds the point where a failed trajectory turns from a useful prefix into an erroneous suffix, using execution validity, goal progress and action diversity. A stronger teacher continues from that same prefix, and the contrast between suffixes yields localized skill updates that keep the guidance that already works. It beats other skill-evolution methods on ToolQA, LogicBench and WildClawBench. **Why it matters:** targeted, compact skill edits beat coarse whole-trajectory reflection for self-improving agents.
- **HEXIS: Compiling Skills into Extended Finite State Machines** — Minghao Li · https://arxiv.org/abs/2609.30123
  HEXIS compiles agent skills into extended FSMs, separating skill knowledge (local per-state instructions) from control flow (explicit transitions). An incremental compiler maps skill clauses and tool interfaces to states, aligns development traces to add missing operations, and accepts updates only after static checks and replay of all accepted traces. It averages +16.1 pp success over Skill + ReAct across 4 benchmarks and 4 executors, and cuts execution tokens 38–89% with Qwen3.8-27B. **Why it matters:** it makes skill execution deterministic and cheap, so prescribed steps can no longer be silently skipped.
- **Persistent Billable State: Denial-of-Wallet Attacks and Defenses in Tool-Calling LLM Agents** — Jinqian Zhang et al. · https://arxiv.org/abs/2609.28585
  A malicious or compromised tool can plant content that the agent runtime re-feeds on every later turn, so the victim is billed again each time. The paper derives six denial-of-wallet vectors, builds DOW-BENCH across six model families, and finds cumulative input reaching 14,293× the first call, with raw history retention adding 21–36% cost. Compression plus four host-side invariants (prompt mass, context growth, recursion, cumulative spend) contain the recurring attacks. **Why it matters:** cost is an attack surface for agent hosts, and history policy is the lever that controls it.
- **Pistis Technical Report** — Heyun Chen, Xiaohan Lan et al. · https://arxiv.org/abs/2609.28554
  Pistis is a family of 27B and 9B multimodal LLMs (on Qwen3.6 and Qwen3.5) trained with IDRL, which alternates on-policy distillation and RL in one loop for better stability and credit assignment on long agentic trajectories. It ships Thinking and Agentic variants; Pistis-Agentic is especially strong at multimodal search. **Why it matters:** interleaving distillation with RL is a practical recipe for open multimodal agent models.
- **HarnessPAI: An Evolving Harness for Physical AI** — Xin Wang, Wenhao Wu et al. · https://arxiv.org/abs/2609.29166
  HarnessPAI treats code as the evolvable interface over action primitives. It runs a fixed program open-loop within a rollout and evolves the program closed-loop across rollouts, distilling failures into reusable skills. Without retraining, it gains +61.6 points over π0.5 on LIBERO-PRO and +27.2 over WorldDreamer on RoboCasa, across arms, household robots, a vacuum and a legged agent. **Why it matters:** another strong data point that harness engineering, not just action models, drives embodied robustness.
- **Rufus-Air: An Open LLM Post-Training Recipe** — Chia-Yuan Chang, Renyuan Cheng et al. · https://arxiv.org/abs/2609.29421
  This is a fully documented, reproducible 8-stage post-training pipeline on GLM-4.5-Air-Base (106B-A12B): SFT, then reasoning, coding and instruction-following RL, then general, coding and search agent stages, then RLHF, using only open data and components. Key lessons: diverse SFT sets the floor, difficulty filtering keeps RL productive, and reward reliability should order the stages. It beats the official GLM-4.5-Air post-train. **Why it matters:** it is a rare end-to-end open recipe for building agentic capabilities.
- **IterSynth: Rethinking Deep Search Agents via Role-Decoupled Iterative Synthesis** — Xingyu Wu, Yuchen Yan et al. (HF trending) · https://huggingface.co/papers/2609.29444
  IterSynth splits deep search into a Planner (information needs) and a Synthesizer (an evolving summary state), which avoids role coupling and context bloat in ReAct agents. It is trained with RDPO, which combines outcome rewards, turn-level rubrics and role-specific advantages. IterSynth-8B averages 50.7 on five benchmarks including BrowseComp, +4.2% over the best ≤8B agent, and gives zero-shot gains as a prompting pattern on frontier models. **Why it matters:** a summary-as-state design is a cheap, model-agnostic fix for long search contexts.
- **Scope Before You Persist: Preventing Cross-Family Interference in Agent Memory** — Yezhou Cheng, Runjia Du et al. · https://arxiv.org/abs/2609.29144
  Persistent skill edits validated on one task family can harm others when retrieved globally: in the authors' experiments, global memory (0.713) drops below the static agent (0.775). Scoping retrieval to each edit's originating family raises utility to 0.816, accepts 63 vs 12 updates, and produces zero harmful acceptances. **Why it matters:** for agent memory, where an edit applies matters as much as whether it was verified.
- **iCoder-27B: Recursive AI-Led Development of Frontier Industrial Coding Model** — Cheng Yang, Jiayang Lyu et al. · https://arxiv.org/abs/2609.29626
  Experts encode objectives, scaffolds, permission boundaries and procedures as reusable "research skills". An agent then runs the data evolution, SFT, on-policy self-distillation and RLVR to produce iCoder-27B for RTL design and GPU kernels. It leads RTLLM (above GPT-5.5 and Claude-Opus-4.8), ranks 2nd on CVDP and KernelBench L2, and ties for best on TritonBench. **Why it matters:** it shows agent-led model development producing a frontier-competitive specialist with minimal human input.
- **Asymmetric Dynamic Routing: Balancing Reasoning Depth and Computational Efficiency in Hypergraph RAG** — Qi Sun, Yijia Zhang et al. · https://arxiv.org/abs/2609.29282
  ADR uses a lightweight classifier to route each query to one of three traversal operators over a hierarchical knowledge graph: local fact anchoring, bottom-up diffusion, or top-down insight grounding. This replaces one-size-fits-all static traversal. On five domain corpora it keeps reasoning quality while cutting prompt tokens by up to 48.7% and latency by 45.3%. **Why it matters:** query-adaptive retrieval depth is a clean efficiency win for graph RAG in production.
- **Agent Memory with Episodic Retrieval for Financial Decision-Making** — Nuoyue Xu, Jiang Liu et al. · https://arxiv.org/abs/2609.28771
  META combines specialized indicator agents (Trend, MACD, RSI, etc.) with a Decision Agent and an episodic memory. The memory retrieves past trading episodes, stored as market-state embeddings with their outcomes and reflections, and reweights signals under similar regimes. It improves short-horizon directional accuracy and robustness; code is released. **Why it matters:** it is a practical, interpretable pattern of RAG-style episodic memory for multi-agent decision systems.
- **An Empirical Study of VLM Pipelines for Long-Document QA** — Kenan E. Ak, Jay Mohta et al. · https://arxiv.org/abs/2609.29933
  On MMLongBench-Doc and LongDocURL, a six-tool document agent only beats static page input once the reader VLM is large (it trails with Qwen3.5-4B/9B and leads with Sonnet 4.5). Retrieval modality matters more than the specific retriever; image top-k is the most token-efficient input (about ¼ to ⅐ of all-pages tokens), and one cross-encoder rerank matches heavy LLM pipelines. **Why it matters:** these are concrete deployment defaults: go agentic only with strong readers, and prefer image retrieval.
