## 📄 Research Papers — Top Picks
- **Buried in Textual Debt: Context Pruning with Visual Evidence Preservation for MLLM Agents** — Huang, Li, Zhang, Fung · https://arxiv.org/abs/2608.22963
  Multimodal agents accumulate self-generated reasoning text over long trajectories until it crowds out the visual evidence in context ("textual debt"). SPARE is a KL-guided pruning framework that uses a compact task-state summary as privileged diagnostic context and replays the model per candidate segment to decide which reasoning can be dropped. It removes redundant text while keeping grounded visual evidence intact. **Why it matters:** Context hygiene, not bigger windows, is what keeps long-horizon multimodal agents on task.
- **TRACE: A Self-Evolving Skill Bank for Consistent, Limit-Aware LLM Agents** — Wu, Zhang, Wang, Wang, Shao, Luan · https://arxiv.org/abs/2608.22793
  Product-grade agents fail on consistency (Pass@3 far above Pass^k) and on recognizing when a request cannot be safely fulfilled. Using CAR-bench (in-car assistant, ambiguous multi-turn requests, strict domain policies), TRACE iteratively improves a skill-based agent's behavioral knowledge via trajectory-contrastive evolution, with no weight updates. The skill bank evolves by contrasting successful and failed trajectories. **Why it matters:** Reliability gains without fine-tuning — skills and memory are the cheaper deployment lever.
- **MCP-Universe RL: A Framework for Training MCP Tool-Use Agents via Reinforcement Learning** — Luo, Yang, Jian, Shi, Lin, Liew, Savarese, Li · https://arxiv.org/abs/2608.22167
  Most RL frameworks stop at the policy update, leaving users to build isolated environments for hundreds of concurrent trajectories and to schedule rollouts around slow tool calls. MCP-U RL uses the Model Context Protocol as the environment interface, so any tool already exposed as an MCP server plugs into training with no RL-specific integration code. It supplies the two missing layers — environment provisioning and rollout scheduling — reusable across domains. **Why it matters:** MCP is turning into a training substrate, not just a runtime integration standard.
- **When Not to Imitate: Boundary-Aware Skill Memory for Reliable Tool-Use LLM Agents** — Lin, Chen, Wei, Wang, Cao, Chai, Lin, Yin, He · https://arxiv.org/abs/2608.22339
  Self-evolving agents assume more retrieved skills monotonically help, but probes reveal a "Skill Imitation Trap": on tasks resembling past successes that require different tools, retrieved procedure skills raise the wrong-tool margin by 47% over a memory-free baseline. BASM augments each skill with explicit boundary information about where it does and does not apply. Retrieval then respects applicability instead of surface similarity. **Why it matters:** Skill memory without boundary conditions actively makes tool selection worse.
- **Physical Agentic AI: An Architecture for Orchestrating a Robot Crew with LLMs** — Liu, Sadikoglu, Chatterjee, Senanayake · https://arxiv.org/abs/2608.22657
  Semantic planners still emit infeasible, mistimed, or unsafe physical actions even when given richer embodiment context. This framework has each robot expose a typed library of executable skills while a foundation-model planner decomposes a task into phases and assigns each phase to a robot-skill pair. A Robot Orchestration layer verifies every planned action against robot capabilities, system state, and workflow constraints before actuation. **Why it matters:** The typed-skill plus pre-execution verification interface is the same pattern software agents need before irreversible actions.
- **Prime Agent: A Self-Improving RLM Harness** — Karten, Zhang, Thomas, Müller et al. (Prime Intellect) · https://huggingface.co/papers/2608.23552
  Prime Agent is an open-source harness for long-horizon agent work: a persistent IPython REPL implements the Recursive Language Model abstraction for programmatic context processing and test-time compute, while a Continual Harness preserves histories, memories, skills, prompts, and subagent specifications across trajectories. Recursive subagents coordinate through direct agent-to-agent communication, and an Agents View lets humans inspect daemon-backed sessions. It reports ARC-AGI-3 RHAE Best@1 rising from 30% to 95.5%, matching or beating native and popular harnesses on long-context coding, GPU-kernel generation, emulator construction, and nanoGPT speedruns. **Why it matters:** Much of what looks like model failure is harness failure — and this harness is open source.
- **Apodex 1.1: Scaling Agentic Intelligence for Complex Work** — Apodex Team · https://huggingface.co/papers/2608.23283
  Apodex 1.1 scales along two axes: Environment Scaling (more diverse, verifiable file, search, and code environments) and Agentic Coordination Scaling (decompose long-horizon tasks, delegate parallel work, integrate asynchronous results, replan). A shared execution harness plus AgentOS maintains task state and provenance across tools and agents, and training converts environment trajectories and coordination traces into behavior. It claims leading-band performance across finance, scientific research, math, coding, and search with a substantially smaller model, plus a 35B locally deployable Mini. **Why it matters:** Coordination quality and environment verifiability are being treated as first-class scaling axes alongside parameter count.
- **Task-CoEvolve: Efficient Harness Optimization via Adaptive Validation Task Selection** — Miyai, Aizawa, Yamasaki · https://huggingface.co/papers/2608.20169
  Harness optimization rewrites agent scaffolding based on validation performance, but re-running the full validation set every iteration is expensive. Task-CoEvolve co-evolves validation tasks with the harness, using variance-weighted sampling to focus on tasks where candidate harnesses disagree — the capability frontier — then estimates full-set scores from the sampled subset by accounting for sampling probabilities. On online text classification and Terminal-Bench 2.1 it beats subset baselines and tracks full-set evaluation at lower cost. **Why it matters:** Makes iterative prompt/harness self-improvement cheap enough to run continuously.
- **MobilePA-Bench: Benchmarking Mobile Planner Agents on Complex Real-World Tasks** — Zhu, Wu, Wang, Qu, Liu, Cao, Chen, Sun, Zhu, Zhong et al. · https://huggingface.co/papers/2608.23035
  GUI benchmarks test screen manipulation and function-calling benchmarks do offline API matching; neither captures a stateful mobile runtime. MobilePA-Bench runs an executable sandbox with live application databases and structured feedback across 13 functional domains and 212 realistic mobile tools. It scores a central planning agent on three advanced dimensions — sub-agent collaboration, memory usage, and skill usage (invoking pre-packaged composite skills instead of replanning every step). Frontier LLMs remain unreliable under these conditions. **Why it matters:** Benchmarks are converging on the sub-agent/memory/skill triad that real agent stacks actually run on.
- **Training Agents to Evolve with Their Harness: TaoLive Digital Avatar Agent Technical Report** — TaoLive AIGC LLM Team · https://arxiv.org/abs/2608.15763
  Evolvable harnesses — skills, hooks, prompts, and tools updated independently of model weights — allow rapid iteration but expose a trade-off: large models adapt zero-shot yet are too slow, while compact models hit latency targets but overfit to one harness configuration. Harness-Aware Training trains compact models to tolerate harness change, with Harness-State Augmentation applying task-preserving transformations to skill identifiers, tool schemas, prompt structures, and hook functions. Training runs in three stages beginning with HSA-SFT. **Why it matters:** If prompts and tool schemas change weekly, the model should be trained to expect that.
- **MCite-RL: Towards Reliable Multimodal RAG via Citation-enhanced Agentic Reinforcement Learning** — Zhao, Liu, Lei, Sun, Gao, Li · https://arxiv.org/abs/2608.21808
  Multimodal RAG needs visual citations for traceability, but RAG and SFT baselines produce imprecise citations or citations decoupled from the generated answer. MCite-RL adds an Agentic Refinement module that iteratively retrieves, reasons, and recursively crops to narrow the visual search space, making citation an evidence-driven reasoning process rather than a static step. A citation-enhanced reward combines process-level and outcome-level signals. **Why it matters:** Verifiable evidence pointers are becoming a trained objective, not a formatting convention.
- **ATP-Bench: Towards Agentic Tool Planning for MLLM Interleaved Generation** — Liu, Qian, Zhou, Zhang, Zhang, Li, Zhou et al. · https://arxiv.org/abs/2603.29902
  Interleaved text-and-image generation currently treats image generation and retrieval augmentation as mutually exclusive paths, trading factuality against creativity. ATP-Bench frames the next milestone as Agentic Tool Planning — the model autonomously decides when, where, and which tools to invoke — and evaluates it over 7,702 QA pairs (including 1,592 VQA pairs) across eight categories and 25 visual-critical intents with human-verified queries. **Why it matters:** Tool routing, not raw generation quality, is becoming the bottleneck for multimodal output.
- **FinAcumen: Financial Multimodal Reasoning via Self-Evolving Experience Memory Harness** — Guo, Zhou, Jian, Chen, Yang, Zhou · https://arxiv.org/abs/2606.17642
  Tool-augmented financial agents are largely stateless across episodes, rediscovering the same reasoning strategies and repeating the same failure patterns. FinAcumen distills successful strategies and failure-derived cautionary rules from prior trajectories into a persistent memory bank, retrieved selectively at inference. The targeted failure modes are unreliable tool routing, noisy retrieval, and hallucination-prone reasoning in high-stakes settings. **Why it matters:** Persisting failures — not just successes — is the memory design most agent stacks skip.
- **Soft-NBCE: Entropy-Weighted Chunk Fusion for Long-Context** — Ji, Li, Song · https://arxiv.org/abs/2606.01101
  NBCE parallelizes long-context inference by chunking documents and routing each decoding step to the lowest-entropy chunk, but hard selection fragments cross-chunk reasoning when routing flips between adjacent tokens. Soft-NBCE replaces discrete selection with a temperature-scaled softmax over predictive entropies, aggregating all chunk-conditioned distributions in log space. It adds a correction for the conditional-independence assumption the method introduces. **Why it matters:** A cheap decoding-time alternative to paying quadratic attention for ultra-long contexts.
- **Better Retrieval, Worse Robustness: How Multi-hop RAG Amplifies Upstream ASR Errors** — Bao · https://huggingface.co/papers/2608.22872
  Speech pipelines pass ASR output straight into retrieval, so transcription errors enter as a fixed upstream constraint. Testing entity-graph linking and iterative reformulation across four synthesized accents and three multi-hop QA benchmarks, the structurally richer configurations keep higher absolute F1 but amplify the error: the clean-to-worst-accent F1 gap is 36–67% larger than naive dense retrieval on all three benchmarks. Corrupted query entities account for 87–96% of degradation, and lightweight surface-form fixes leave most of the gap intact. **Why it matters:** Adding retrieval structure can magnify upstream noise instead of absorbing it — measure end-to-end, per accent.
