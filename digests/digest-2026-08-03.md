## 📄 Research Papers — Top Picks
- **Frontier AI performance across the business disciplines: a case-grounded benchmark of knowledge work and analytical reasoning** — Patel, Hosanagar, Krishnan, Callison-Burch, Lakhani · https://arxiv.org/abs/2607.16057
  Argues current benchmarks over-index on factual recall, narrow QA, math, coding and agentic tool-use, leaving analytical white-collar knowledge work unmeasured. Introduces a case-grounded benchmark spanning business disciplines that tests synthesis of complex information, judgment under uncertainty, adversarial multi-stakeholder reasoning, and production of defensible structured analyses. Evaluates frontier models on tasks closer to what professionals actually do daily. **Why it matters:** Gives a realistic yardstick for whether agents can do real knowledge work rather than pass exam-style tests.

- **TransMem: Transforming Hidden States into Memory for Large Language Models** — Lei, Liu, Chen, Cai, Shi, Wang, Wang · https://arxiv.org/abs/2607.29032
  Lightweight inference-time parametric memory that converts sparse historical hidden states from a frozen LLM backbone into reusable memory representations. A gating network decides when to apply the latent intervention to current generation, so evidence spread across long agent histories stays usable. Requires no backbone retraining. **Why it matters:** Cheap long-horizon memory for agents without touching model weights or ballooning the context window.

- **OpenClaw and Ollama in Agentic AI: Toward Fully Autonomous and Scalable AI Agent Systems** — Roumeliotis, Sapkota · https://arxiv.org/abs/2607.28629
  Presents a layered reference architecture for agentic AI that cleanly separates inference, orchestration, and execution layers. Traces the evolution from reactive LLM interfaces to persistent goal-driven agents with memory, planning, and continuous execution, using OpenClaw and Ollama as concrete case studies. Highlights gaps in full-stack agentic system design and evaluation. **Why it matters:** A vocabulary and layering model for anyone building local-first, always-on agent stacks.

- **Chain-of-Models: Cross-Model Auditing for Bias-Robust LLM Judges** — Wang, Lou, Tang, Chen, He · https://arxiv.org/abs/2607.28636
  Studies an automated audit pipeline where a second model inspects the first model's reasoning trace before the final judgment is emitted. Tests whether the auditor should be the same model, a same-family model, or a cross-family model across 9 models, 6 families, 4 cognitive biases, and 4 factual datasets. Finds auditor identity materially changes debiasing effectiveness. **Why it matters:** Practical recipe for making LLM-as-judge eval pipelines less brittle without human raters.

- **SciToolAgent-Evo: An Ontology-Aware Self-Evolving Agent for Open-World Scientific Tool Acquisition** — Tang, Zhou, Wang, Ding, Zhang, Chen · https://arxiv.org/abs/2607.28692
  Targets the limitation that scientific LLM agents assume a predefined, static tool space. Uses an evolving memory of skills and experiences plus an ontologized tool graph, distilling generalizable knowledge from contrastive trajectories so the agent can acquire and organize new tools at runtime. Aimed at open-world scientific workflows where tool boundaries shift. **Why it matters:** Moves tool-calling agents from fixed registries toward runtime tool discovery — directly relevant to MCP-style ecosystems.

- **Self-Play Meets Skill Evolution: Self-Evolving Search Agents that Pose, Solve, and Remember (SESA)** — Fu, Li, Ai, Wu, Wu, Zhao, Wang, He, Wang · https://arxiv.org/abs/2607.29468
  Makes procedural memory an evolving state of tool-augmented search self-play: a challenger poses problems while a separately parameterized solver retrieves skills to solve them. Informative failures are distilled into reusable skills and written back to memory, so curricula carry persistent state instead of only affecting gradients. **Why it matters:** Shows agent skill libraries can be grown autonomously from self-play failures, no target benchmark needed.

- **M3MAD-Bench: Multi-Dimensional Evaluation of Multi-Agent Debate Across Domains and Modalities** — Li, Zhang, Li, Duan, Gao, Chen et al. · https://arxiv.org/abs/2601.02854
  Unified, extensible benchmark for multi-agent debate spanning multiple domains, modalities, and metrics, addressing the fragmented and text-only evaluations that dominate the MAD literature. Enables apples-to-apples comparison of debate protocols including in multimodal settings. **Why it matters:** Finally lets teams check whether multi-agent debate actually beats a single strong model on their task type.

- **Benchmarks Are Not Validation: A System-Level View of Financial LLM Applications** — Payzun, Demirtaş, Scala, Ferretti, Arslan · https://arxiv.org/abs/2607.28840
  Position paper arguing financial LLM systems must not be production-approved on benchmark scores alone. Proposes system-level validation evidence across the whole stack — data, model design, retrieval and generation quality, agent behavior, governance, monitoring, and human escalation. Framed for regulated deployment contexts. **Why it matters:** A concrete validation checklist for shipping agentic LLM systems into high-stakes domains.

- **Learning Stateful Predictive Knowledge From Experience** — Song, Feng, Liu, Cui, Fu, Liu, Yang, Deng, Zhao, Wang · https://arxiv.org/abs/2607.28638
  Argues trajectory-level reflection gives agents episodic hindsight, producing brittle path-dependent heuristics. Stateful Knowledge Learning (SKL) instead maintains explicit declarative predictive assessments anchored to state, shifting from summarizing what happened to predicting what will happen next. **Why it matters:** A sharper alternative to "reflect on the transcript" memory that generalizes across runs.

- **Self-Supervised Skill Optimization** — Peng, Yang, Fu, Zhang, Zhang, Zhao et al. · https://arxiv.org/abs/2607.28777
  Learns reusable agent skills from unlabeled task instances alone — no ground truth, task scores, rewards, or task-specific evaluators. Each step runs the current skill on an unlabeled batch, generates skill probes from a subset of executions, reruns probes on the same batch, and uses an LLM judge to compare results and update the skill. **Why it matters:** Lets skill libraries improve in real deployments where labeled feedback simply doesn't exist.

- **Zero-Mem: Zero-Token Memory Operations for LLM Agents** — Xiao, Zhu, Zhang, Chen, Hong, Zhuang et al. · https://arxiv.org/abs/2607.29377
  Asks whether structured memory access needs generation at all: no step outside final question answering invokes an LLM or consumes LLM tokens, with encoder compute accounted separately. Preserves original interaction traces as the source of record rather than lossy LLM-written summaries. **Why it matters:** Cuts the recurring token and latency tax of memory-management LLM calls while avoiding summary-induced evidence loss.

- **ViSAGE: Constructing Self-Correcting Memories for Long-Form Video Understanding** — Zhao, Chen, Zhang, Liu, Cheng, Wang, Xu · https://arxiv.org/abs/2607.28678
  Multimodal agentic memory framework building self-correcting, entity-centric memories for long-horizon video. Addresses how aggressive compression and segment-wise processing discard fine-grained identity cues, and how pure vector-similarity retrieval surfaces semantically related but identity-mismatched evidence. **Why it matters:** Attacks entity confusion and hallucination — the dominant failure mode in long-video agents.

- **NeSyFS: A Neuro-symbolic Fast-Slow Thinking Framework for LLM Agent under Partial Observability** — Xu, Fekri · https://arxiv.org/abs/2607.28942
  Handles agents acting on limited observations rather than full environment state, tackling belief-state inference, objective misalignment, and planning under uncertainty. Replaces conditioning on full or summarized action-observation histories — whose redundancy misleads decisions — with a fast-slow neuro-symbolic split. **Why it matters:** Most real agent environments are partially observable; this targets that gap directly.

- **Code Is the Body: Agent-Owned Software Bodies for Recursive Evolution and Descent** — Zhao (UW), Zhao · https://arxiv.org/abs/2607.28691
  OurArk gives a persistent personal agent an identity-bearing, inspectable, versioned "software body" containing behavior-defining code, prompts, tools, skills, policies, tests, and evolution mechanisms, all under human custody. Memories and credentials stay private instance state; model inference is a replaceable external service. Defines governed self-evolution and recursive descent over that same body. **Why it matters:** A concrete governance model for self-modifying agents that keeps humans in control of the artifact.

- **Validation Evidence in LLM Repair Agents: How Much of What Passes Actually Tests the Bug?** — Xu, Wu · https://arxiv.org/abs/2607.28871
  Measures whether a passing test in an automated repair agent is real evidence about the reported defect. BSG-VA captures each validation command at its exact working-tree state, extracts a test-only patch, and replays it on buggy, candidate, and gold-fix states to assign each event an evidence role. Across 3,730 events in 643 rollouts on 110 tasks, 46.0% fall short of gold-aligned bug-discriminating evidence. **Why it matters:** Hard data that coding agents' "tests pass" signal is often not testing the bug at all.
