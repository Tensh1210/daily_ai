## 📄 Research Papers — Top Picks
- **SkillFlow: Scalable and Efficient Agent Skill Retrieval System** — Li, Tagkopoulos, Tagkopoulos · https://arxiv.org/abs/2504.06188
  SkillFlow treats skill acquisition as retrieval over ~35K community SKILL.md files indexed from GitHub, narrowing candidates through dense retrieval, two cross-encoder rerank rounds, and a final LLM selection. On SkillsBench, retrieved skills raise Pass@1 from 9.2% to 16.4%, reaching 84.1% of the oracle ceiling. On Terminal-Bench, agents use the retrieved skills 70.1% of the time but gain nothing, because the corpus lacks good executable skills for that domain. **Why it matters:** Skill libraries need retrieval, not bulk loading, and retrieval only pays off when the corpus itself is good.
- **Cartograph: Federated Tool Discovery with Operator-Attested Retrieval for AI Agents** — Owusu Agyemang et al. · https://arxiv.org/abs/2609.30293
  Cartograph is a federated MCP proxy that swaps full-catalog loading for progressive disclosure. It ranks servers before tools and uses Ed25519-signed, operator-generated capability cards instead of publisher descriptions. On a 22-server, 374-tool deployment it exposes 3 proxy tools, reaches R@5 0.816 (vs. 0.592 keyword baseline), and a top-5 discovery exchange uses 475 tokens instead of 42,450, at about 5ms added latency. **Why it matters:** A concrete design for MCP catalogs that have outgrown the context window, with a trust layer on tool descriptions.
- **Analyzing and Mitigating Cost-Inefficient Behaviors in Coding Agents** — Hu et al. · https://arxiv.org/abs/2609.30725
  The study analyzes 1,200 Claude Code and Mini-SWE-Agent trajectories on SWE-bench Verified and finds three wasteful behaviors: subsumed retrieval, generating near-duplicate scripts, and re-running tests. These affect 79–98% of tasks and account for up to 22.75% of cost. Developer-designed skills cut cost by up to 41.73%, about twice the gain from agent-synthesized skills, which tend to be low-level and trace-specific. **Why it matters:** Hand-written, high-level skills are the cheapest lever for coding-agent cost today.
- **Stealth Apart, Harm Together: Skill Cascading Attacks on Skill-Based Agent Systems** — Zhu, Lyu, Bibi, Wu · https://arxiv.org/abs/2609.30383
  The paper introduces skill cascading attacks, where a malicious goal is split across several skills that each look benign alone but are harmful when chained, e.g. a drug-interaction warning quietly disappearing across three pipeline steps. SkillCascade is an automated multi-agent red-teaming framework, and SkillCascade-Bench has 213 validated cases. It is evaluated against agents including OpenClaw, Claude Code, and Codex. **Why it matters:** Per-skill audits miss cross-skill threats; third-party skill ecosystems need composition-level review.
- **Up and Down the Abstraction Ladder: Code-Based Skills for Language Agents** — Cupiał et al. · https://arxiv.org/abs/2609.31076
  Using CodeHack, a library of code-based NetHack skills with natural-language descriptions, the authors compare agents with primitives only, skills only, and both, across zero-shot, SFT, and RL. Zero-shot, skills nearly triple game progression while cutting inference cost per episode by 86%. Mixing skills with primitives keeps most of the gain while leaving a path back to low-level actions when abstractions leak. **Why it matters:** Strong evidence that code-as-skill abstraction improves both capability and cost in long-horizon agents.
- **CODESKILL: Learning Self-Evolving Skills for Coding Agents** — Li et al. · https://arxiv.org/abs/2605.25430
  CODESKILL turns skill extraction and skill-bank maintenance into a learned policy, extracting multi-granularity procedural skills from coding-agent trajectories and evolving them with new experience. It is trained with RL using dense rubric-based skill-quality rewards plus sparse execution feedback from a frozen downstream agent. On EnvBench, SWE-Bench Verified, and Terminal-Bench 2 it improves average pass rate by 11.03 over no skills and 5.10 over the best prompt or memory baseline. **Why it matters:** Moves skill curation from heuristic prompts to a trainable component.
- **SkillEvoReg: Regularizing Agent Skill Evolution Against Overfitting** — Nie et al. · https://arxiv.org/abs/2609.30861
  Repeated skill updates can pile up redundant or task-specific instructions and break behavior that used to work, which the authors call skill-evolution overfitting. SkillEvoReg adds skill dropout during updates, complexity-aware regularization against structural growth, and causal counterexample validation to catch regressions. Across SkillOpt, SkillEvolBench, and ContinualSkillBench it keeps skill state compact while preserving downstream capability. **Why it matters:** Self-improving skill systems need regularization, like any other learner.
- **RecToolBench: Benchmarking Recommendation-Specific Tool Orchestration under Fuzzy User Intent** — Chen et al. · https://arxiv.org/abs/2609.30717
  RecToolBench is an MCP-based benchmark with 1,200+ executable tasks across three recommendation domains, 13 MCP servers, and 32 tools, covering single, parallel, sequential, and hybrid tool calls under deliberately fuzzy instructions. Tasks are built by a synthesize–fuzzify–judge pipeline and scored with rule-based checks plus rubric LLM evaluation. Syntactically valid tool calls often still fail, with models struggling on semantic parameter grounding and multi-step evidence integration. **Why it matters:** Valid tool-call syntax is a weak proxy for agent success when user intent is vague.
- **ToolSearcher: Optimizing Tool Selection at Scale via Reinforcement Learning** — Dai et al. · https://arxiv.org/abs/2609.30906
  ToolSearcher frames large-scale tool selection as an agentic RL problem: multi-turn search over large tool repositories under context limits. It adds category-constrained discrimination for functionally similar tools, event-level search modeling to reward discovering target tools, and trajectory-aligned credit allocation across search and selection stages. It reports consistent gains on large-scale tool-selection benchmarks. **Why it matters:** Complements proxy-based tool discovery with a trained searcher for huge tool catalogs.
- **ActKV: Efficient LLM Agents through Action-Guided KV Cache Management** — Wang et al. · https://arxiv.org/abs/2609.31395
  ActKV compresses the KV cache that builds up across agent observe-reason-act loops by keeping entries that matter for future action generation. It combines action-oriented eviction, confidence-driven adaptive budgets, and page-aware compression with custom kernels. On long-trace tasks it keeps 98.53% of full-KV accuracy with 25.98% of peak KV memory and delivers 3.97x token and 3.58x task throughput. **Why it matters:** Agent serving has different cache needs than chat; this targets them directly.
- **Learning What to Skip: Counterfactual Credit Assignment for Efficient Multi-Agent LLM Workflows** — Xu et al. · https://arxiv.org/abs/2609.30734
  LW2S treats skipping workflow components (planning, verification, summarization) as counterfactual credit assignment, learning per-action safety models from controlled skip interventions. Calibration and domain-native guards decide which skips are safe, and rejected early skips can be reconsidered later. Across math, multiple-choice QA, and code generation it cuts token cost while matching or beating full-workflow accuracy. **Why it matters:** Not every agent stage earns its tokens; this learns which ones to drop per state.
- **Not All Memories Are Equal: Hierarchical Collaborative Memory for Validity-Aware Retrieval in LLM Agents** — Shi et al. · https://arxiv.org/abs/2609.30289
  HiCoMER separates team memories (decisions, consensus) from individual memories (traces, progress) and tracks whether each is still valid before retrieval. Its three parts are a hierarchical conflict updater, a validity-aware retriever, and a memory-grounded answer generator. The authors build two new collaborative memory-QA datasets for evaluation. **Why it matters:** Flat memory pools surface stale, conflicting facts; validity tracking fixes a real multi-agent failure.
- **DeepEdu-v1: Efficient and Scalable Agentic LLMs for Vietnamese Education** — Nguyen et al. · https://arxiv.org/abs/2609.31568
  DeepEdu-v1 is a self-hosted AI tutor for Vietnamese education, designed to keep student data on-premise under Vietnam's Decree 53 and to follow the national curriculum. Its SCALE framework pairs a long-context engine that selects tokens per cluster (7.7x fewer retrieval calls, ~35% lower TTFT) with an agentic layer that curates a verified playbook from past interactions instead of fine-tuning. It targets consumer GPUs where KV cache and prefill limit quantized models. **Why it matters:** A local-first blueprint for Vietnamese education AI that respects data-sovereignty law.
- **Bridging LLM Agents and Data Spaces: An Architectural Mediation Approach using the Model Context Protocol** — Alonso Ruiz et al. · https://arxiv.org/abs/2609.30341
  The Eunomia Agent exposes governed data-space services (catalog discovery, metadata, data service invocation) as schema-driven MCP tools while keeping policy constraints intact. A prototype validates end-to-end interaction without modifying existing data-space components. **Why it matters:** Shows MCP as a governance-preserving adapter layer for regulated enterprise data.
- **A Safety-Bounded SDC-to-MCP Gateway for Medical AI Agents** — Gerlach, Fischer · https://arxiv.org/abs/2609.31358
  This gateway maps IEEE 11073 SDC medical-device data to MCP, exposing metrics, alarms, and context as read-only resources and device actions only as policy-validated dry-run tools, so no agent request triggers a device operation. Experiments cover faults, cross-implementation protocol paths, and multi-model agents. Explicit semantic metadata improved conformity of structured alarm outputs versus a generic representation. **Why it matters:** A concrete no-execution pattern for letting agents read safety-critical systems without acting on them.
