## 📄 Research Papers — Top Picks
- **Evolving with Open Worlds: Towards Recursive Self-Improvement for Future Forecasting** — Zhipeng Chen et al. · https://arxiv.org/abs/2610.29784
  DeepEvolve is an agent system that keeps getting better by forecasting future events. A living environment generates tasks that can be checked against what actually happens, and a recursive-evolution engine feeds each prediction's reasoning trajectory back into the model, both as weight updates and as distilled reusable skills. The self-improved forecaster ranked first on the live FutureX leaderboard for three weeks running, improving its rating by up to 195%. **Why it matters:** A concrete, contamination-resistant testbed for recursive self-improvement, with results checked against real-world outcomes.
- **Measure First, Then Allocate: Calibrated Rollout Budgets for MCP Agents in Reinforcement Learning** — Hieu Tran et al. · https://arxiv.org/abs/2610.28785
  This paper uses reward disagreement to decide where to spend RL rollouts when training tool-using models in MCP environments. Discord compares harness edits through exact paired inference with early stopping, and BRACE uses historical task evidence plus a correlated reward model to predict which rollout groups will have mixed rewards before spending generation budget on them. Across three Qwen3-VL scales, BRACE beats the strongest baseline peaks while using fewer new training rollouts. **Why it matters:** Cuts the dominant cost of agent RL by not spending rollouts on groups that teach the model nothing.
- **D-Skill: Distilling Teacher Knowledge through Agent Skills** — Shuo Yuan et al. · https://arxiv.org/abs/2610.28914
  D-Skill treats a strong teacher agent as a black box. It compares paired teacher and student rollouts, finds where their behavior diverges, and condenses the lessons offline into a natural-language skill document that the student reads at inference time. On SpreadsheetBench-Verified, ALFWorld and chess puzzles it closes 75–95% of the teacher-student gap with no weight updates, beats one-epoch SFT, and runs 5.7–8.3x cheaper than the teacher. **Why it matters:** Skill files can stand in for fine-tuning when you want to move frontier-agent behavior into a cheaper model.
- **Combining Long-Term Memory and LLMs Comes at a High Cost: From Prompt Injection to Persistent Compromise** — Pedro H. Barcha Correia et al. · https://arxiv.org/abs/2610.28810
  This paper lays out a general threat model for memory injection: prompt-injection payloads that persist across sessions through long-term memory in ChatGPT, Claude and Gemini. All NIST attack goals were achievable on every platform tested, and the paper shows attack vectors through personal memories, projects, skills, org instructions and MCP-connected resources, including spreading to other users through Claude's shared memory. It also derives defenses from the threat model. **Why it matters:** Persistent memory and MCP turn a one-off prompt injection into a lasting, multi-user compromise. Agent builders need to treat memory writes as untrusted input.
- **Agentic World Action Models** — Zhuoyang Liu et al. · https://huggingface.co/papers/2610.30136
  AW-0 combines code-based planning with joint video and action prediction. Code, future video and robot actions are three coupled streams in a single mixture-of-transformers. A code expert writes parameterized skill routines, while video and action experts predict future frames and motor commands. An automated pipeline labels robot and human videos with matching programs and builds skill libraries from recurring routines. It beats VLA and WAM baselines on RoboTwin 2.0 and on real bimanual manipulation tasks. **Why it matters:** Brings agentic code-as-skills into world models and connects planning, prediction and execution.
- **VeriEvolve: Evaluator-First Evolution for Tool-Using Agents** — Yueshen Li et al. · https://arxiv.org/abs/2610.29005
  VeriEvolve builds the evaluator before it optimizes the agent. From each task instruction it synthesizes challenge states and an executable checker, keeps that checker fixed as the fitness signal during workflow evolution, and refines it between rounds using counterfactual tests built from strong and weak runs. On all 30 MCPMark Filesystem tasks, externally verified success rose from 6/30 to 18/30 for GLM-5.2 and from 27/30 to 30/30 for Claude. **Why it matters:** Self-improving agents are only as good as their fitness signal, and this shows a practical way to build that signal for stateful tool tasks.
- **Environment Duels: A Microcosm of LLM Co-Evolution** — Shibo Jin et al. · https://arxiv.org/abs/2610.30116
  Environment Duels is a dynamic agentic benchmark in which each LLM writes interactive environments with a privileged hint, aiming for tasks that solvers fail without the hint and pass with it. Across nine frontier models, solving and authoring turn out to be separate skills: the best solvers are not the best authors, and smaller models write the hardest environments. In an RL study with Qwen3.8-27B, the hint lift on an author's environments tracks how much training on those environments helps on held-out benchmarks. **Why it matters:** A way to measure models as creators of training environments, which matters as synthetic environments feed the next generation of models.
- **Steering Black-Box Large Language Model Agents with Pitfall Anticipation World Model** — Jiongxiao Wang et al. · https://arxiv.org/abs/2610.29139
  PAWM is a world model for black-box LLM agents that steps in only when it foresees a pitfall within a bounded multi-step horizon, rather than predicting every next observation. It is trained with SFT on synthetic pitfall-labeled data and then co-trained with GRPO alongside the black-box agent. It improves Claude Sonnet 4.5 by 24.3% on ScienceWorld and 7.7% on WebArena-Lite. **Why it matters:** A cheap, plug-in way to give closed frontier agents knowledge of a specific environment.
- **Deep Reasoning in General Purpose Agents via Structured Meta-Cognition** — Dean Light et al. · https://arxiv.org/abs/2605.11388
  Deep Reasoning builds task-specific scaffolds at inference time, using a formal meta-reasoning language that breaks tasks into associative inference, formal computation and recursive subproblems. Its agent, DOLORES, spreads work across controlled lower-load reasoning threads and beats the strongest scaffold baseline by 24.8% on average across multi-hop, long-chain QA, long-context aggregation and deep-research benchmarks. **Why it matters:** Moves agent scaffolds from hard-coded to constructed per task, which reduces premature stopping and hallucination.
- **HarnessPAI: An Evolving Harness for Physical AI** — Xin Wang et al. · https://arxiv.org/abs/2609.29166
  HarnessPAI is a model- and embodiment-agnostic harness for physical AI that uses code as the executable, evolvable layer over action primitives. Within a rollout a fixed program guides and checks execution. Across rollouts, execution feedback revises the program and distills failures into reusable skills. It improves results on robot arms, household robots, a robot vacuum and a legged agent, and the converged programs also produce expert data for fine-tuning VLA and WAM models. **Why it matters:** Applies the harness-engineering pattern from software agents to robotics.
- **Signals and Queries: Token-Efficient Agentic Context Discovery** — Yam Marcovitz · https://arxiv.org/abs/2610.29326
  Signals and Queries (S&Q), built for Parlant 4.0, is a first-stage filter that decides which behavioral policies apply at each turn without calling an LLM. Offline, an LLM writes activating examples and hard negatives for each policy, and a per-policy logistic classifier on embeddings scores relevance. On 254 τ²-bench prefixes and 36 airline policies it removes at least 30% of candidates while keeping recall high, with better precision than top-K or cosine-threshold retrieval. **Why it matters:** A cheap way to scale guideline and policy context for production customer-facing agents.
- **Real PMIDs, Wrong Papers: Harness Design for Biomedical Claim-Verification Agents** — Mohammed Saqlain · https://arxiv.org/abs/2610.29812
  A controlled ablation of harnesses for biomedical claim verification on SciFact, with the live PubMed API as the only tool. Single-shot retrieval using the claim as the query finds the gold paper for only 6% of claims. A ReAct-style agent that writes its own queries triples gold recall and reaches the best accuracy (62% vs 49–59%), though the differences are not significant at this sample size and agents use less than half their search budget. **Why it matters:** Evidence that query formulation is the part of a literature agent's harness that matters most.
- **Code Comprehensor: Hierarchical Documentation and Cross-Modal Retrieval for Large Repositories** — Sujoy Roychowdhury et al. · https://arxiv.org/abs/2610.30016
  Code Comprehensor combines a code call graph, CodeScribe (LLM-generated hierarchical documentation across the graph) and CodeContrast, a CLIP-style text-code dual encoder trained on that documentation. It retrieves relevant code neighborhoods as grounded evidence for an MCP-based LLM orchestrator that answers questions about a repository. It was evaluated on OpenCV and on a proprietary 5M-LOC repository. **Why it matters:** A concrete retrieval stack for coding agents working in very large codebases.
- **Multimodal Embodied Agents: A Unified Capability-centric Perspective from Computer-Use to Robot-Use** — Yanzhe Chen et al. · https://arxiv.org/abs/2610.30108
  This survey defines multimodal embodied agents and proposes PAPAV, a capability framework with five functions: Perceive, Anticipate, Plan, Act, Verify. It uses PAPAV to compare computer-use agents with robotic systems. It identifies five physical constraints, from partial observability to unverifiable outcomes, that shrink the design space, and analyzes 64 benchmarks. **Why it matters:** A shared vocabulary for moving agents from computer use to robot use.
- **SpatialBrain: Spatial Intelligence Growing from Experience** — Yifan Zhou et al. · https://arxiv.org/abs/2610.29317
  SpatialBrain keeps a vision-language backbone frozen and accumulates experience about how to reason spatially: when direct observation is enough and when to reconstruct, measure or change reference frames. It combines 3DFusionMemory, a Spatial Skill Library and a Spatial Cognition module that consolidates completed trajectories into process records between task blocks. It improves on direct answers from the same backbone on four of five spatial benchmarks and ties on the fifth. **Why it matters:** Experience-driven skill and memory reuse applied to spatial reasoning, without retraining.
